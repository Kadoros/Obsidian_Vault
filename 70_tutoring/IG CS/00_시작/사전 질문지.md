1. 자기소개
    1. 간단하게 이름, 학교, 학년, 좋아하는 과목이나 취미 등을 적어주세요.
2. CS에 대해 어떻게 느끼고 있나요?
    1. 예: 재밌다 / 어렵지만 도전할 만하다 / 너무 어렵다 등
3. 최근에 학교에서 어떤 내용을 배우고 있나요
    1. 예: **Data Representation**
4. 지난 시험에서 어떤 점이 가장 어려웠나요?
    1. 코딩문제, 이론문제, 계산문제
5. 과외를 통해 기대하는 점이 있다면 무엇인가요?
    1. 예: 시험 성적 향상 / 개념 확실히 정리 / 질문 편하게 할 수 있는 환경 등
6. 학생은 숙제 양이 어느 정도가 적당하다고 생각하나요?
    1. 예: 매 수업마다 조금씩 / 시험 기간 외에는 최소한으로 / 많이 풀어야 실력이 느는 것 같아요
7. **학교 교육과정 및 환경**
    1. **시험 주관사:** (예: CIE / Edexcel / OxfordAQA 중 어느 것인가요?)
    2. **사용 중인 프로그래밍 언어:** (예: Python  / Java / 없음 )
8. **현재 학습 상태 (1~10점 척도)**
    1. **이론(Theory) 이해도:** (예: 7점 - 내용은 알겠는데 암기가 힘들어요)
    2. **문제 해결 및 코딩(Problem Solving) 자신감:** (예: 4점 - 알고리즘이나 코드 짜는 게 막막해요)
9. **가장 어렵게 느껴지는 '블랙박스' 구간**
    1. 예시:
        1. **Data Representation:** 2진수 계산이나 이미지/사운드 데이터 변환
        2. **Computer Architecture:** CPU 작동 원리(Fetch-Execute) 및 하드웨어
        3. **Algorithm & Logic Gates:** 흐름도(Flowchart) 그리기나 논리 회로 설계
        4. **Programming:** 실제 코드 작성 및 Trace Table 작성
10. **이번 시범 수업에서 중점적으로 다루고 싶은 주제**
    1. 위 항목 중 하나를 골라주시거나, 최근 학교에서 배우고 있는데 이해가 안 가는 단원을 말씀해 주세요.)
11. **기타 요청 사항**
    1. (예: 시험 답안 작성법이 궁금해요, 특정 기출문제를 같이 풀고 싶어요 등)
