지금 코드를 보면 N_row, N_column, K_row, K_column 처럼 기물마다 위치 변수를 따로 만들어서 관리하고 있습니다. 이 방식은 나중에 폰, 룩, 비숍 등 기물이 32개로 늘어나면 코드가 감당할 수 없을 정도로 길어지고 복잡해집니다.

이제 Boards라는 8x8 2D 배열 자체를 유일한 데이터 저장소로 써서 코드 구조를 완전히 바꿔 봅시다.

[과제] 아래 세 가지 조건에 맞춰서 코드를 수정해 오세요.

1. 대소문자로 진영 구분하기 A, B 대신 대소문자를 활용해서 화이트 기물과 블랙 기물을 배열 안에 저장하세요. (예: 화이트는 대문자, 블랙은 소문자)
    
2. 위치 변수 전부 삭제하기 N_row, N_column 같은 기물 위치 변수를 싹 다 지우세요. 기물의 현재 위치를 따로 변수에 저장하지 말고, Boards 배열을 뒤져서 파악하거나 좌표를 직접 입력받는 방식으로 구조를 바꿔야 합니다.
    
3. 배열 기반으로 이동 로직 수정하기 위치 변수가 사라졌으니 moving 함수도 배열 좌표 기반으로 작동해야 합니다. 변수 갱신 대신, 배열 안의 값을 직접 지우고 쓰는 방식으로 코드를 수정해 보세요.
