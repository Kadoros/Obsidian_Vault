**Question 1: Diagonal Symmetry (Matrix Transpose)**

  

- Fold an N x N 2D array along its main diagonal (top-left to bottom-right) and swap the values on opposite sides.
    
      
    
- State the new coordinates for data originally located at `(0, 1)`.
    
      
    
- Provide the general mathematical formula for the destination of any coordinate `(r, c)`.
    
      
    
- Write both **pseudocode** and executable **Python code (using VS Code)** to perform this matrix transpose.
    
      
    

**Question 2: N x N Tic-Tac-Toe Win Check**

  

- Given an N x N 2D array named `Board`, check if either of the two main diagonals contains a winning sequence (all 'X's or all 'O's).
    
      
    
- You must use a loop and the variable N. Do not hardcode indices.
    
      
    
- Write both **pseudocode** and executable **Python code (using VS Code)** for this generalized logic.
    
      
    

**Question 3: The Bishop's Path** 


  

- An 8 x 8 chessboard is represented as a 2D array. A Bishop is currently positioned at coordinate `(r, c)`.
    
      
    
- Find and store all valid diagonal coordinates the Bishop can move to in a single turn.
    
      
    
- Write both **pseudocode** and executable **Python code (using VS Code)** for this algorithm.
    
      
    

**Question 4: Comparing Diagonal Sums**

  

- Given an N x N 2D array populated with integers, calculate the sum of the elements on the main diagonal (top-left to bottom-right) and the sum of the elements on the anti-diagonal (top-right to bottom-left).
    
      
    
- Return the absolute difference between these two sums.
    
      
    
- Constraint: You must calculate both sums concurrently using only a **single loop**.
    
      
    
- Write both **pseudocode** and executable **Python code (using VS Code)** for this function.
