**[문제 1]** 다음 식의 값을 구하시오.
$$\sin 30^\circ + \cos 60^\circ$$

**[문제 2]** 다음 식의 값을 구하시오.
$$\tan 60^\circ \times \cos 30^\circ - \sin 45^\circ \times \cos 45^\circ$$

**[문제 3]** 다음 식의 값을 구하시오.
$$\frac{\sin 60^\circ}{\cos 30^\circ} + \tan 45^\circ$$

**[문제 4]** $\angle B = 90^\circ$인 직각삼각형 $ABC$에서 $\sin A = \frac{3}{5}$일 때, $\cos A \times \tan A$ 의 값을 구하시오.

**[문제 5]** $\angle C = 90^\circ$인 직각삼각형 $ABC$에서 $\tan A = \frac{4}{3}$일 때, $\sin A - \cos A$ 의 값을 구하시오.

**[문제 6]** 직각삼각형 $ABC$에서 $\cos A = \frac{1}{3}$일 때, $\sin A \times \tan A$ 의 값을 구하시오. (단, $\angle A$는 예각)

**[문제 7]** $\angle A = 90^\circ$인 직각삼각형 $ABC$에서 꼭짓점 $A$에서 빗변 $BC$에 내린 수선의 발을 $H$라 하자. $AB = 15$, $AC = 20$이고 $\angle BAH = x$일 때, $\sin x + \cos x$ 의 값을 구하시오.

**[문제 8]** $\angle C = 90^\circ$인 직각삼각형 $ABC$에서 $AC = 5$, $BC = 12$일 때, $\tan A + \tan B$ 의 값을 구하시오.

**[문제 9]** 다음 식의 값을 구하시오.
$$(\sin 30^\circ + \cos 45^\circ)^2 + (\sin 30^\circ - \cos 45^\circ)^2$$

**[문제 10]** $\angle B = 90^\circ$인 직각삼각형 $ABC$에서 $\sin A = \frac{\sqrt{2}}{2}$일 때, $\tan A$ 의 값을 구하시오.
