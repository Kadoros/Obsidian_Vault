1. Simplify the following expression: $\sqrt{7 - \sqrt{40}}$
    
      
    
2. Simplify the following expression: $\sqrt{11 + 6\sqrt{2}}$
    
      
    
3. Simplify the following expression: $\sqrt{14 - 6\sqrt{5}}$
    
      
    


4. Given $x = 1 - \sqrt{2}$, find the value of $x^2 - 2x + 3$.

5. Given $x = \frac{\sqrt{3} + 1}{2}$, find the value of $4x^2 - 4x + 5$.

6. Given $x = 2 + \sqrt{5}$, evaluate the polynomial $x^3 - 4x^2 - 3x + 10$ using polynomial division.

7. Given $x = \sqrt{2} - 1$, find the value of $x^3 + 3x^2 + 3x + 1$.

  


8. Simplify the following expression (assume $x \neq 0, y \neq 0$): $\frac{(2x^2y^{-1})^3}{x^{-2}y^2}$

9. Simplify the following expression (assume $a > 0, b > 0$): $(81a^8b^{-4})^{\frac{1}{4}}$

10. Simplify the following expression and write it with positive exponents: $\left(\frac{a^{-2}b^3}{a^3b^{-1}}\right)^{-2}$
