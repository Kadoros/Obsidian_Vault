For these problems, find two numbers that add up to the first number and multiply to the number inside the inner root.

  

1. $\sqrt{4 + 2\sqrt{3}}$
    
      
    
2. $\sqrt{8 + 2\sqrt{15}}$
    
      
    
3. $\sqrt{9 + 2\sqrt{14}}$
    
      
    


Remember, when there is a minus sign, you must place the larger number first to ensure the final value is positive.

4. $\sqrt{6 - 2\sqrt{5}}$

5. $\sqrt{10 - 2\sqrt{21}}$

6. $\sqrt{12 - 2\sqrt{35}}$

  



For these questions, the essential '2' is missing or modified. You will need to take numbers out of the inner root (or put numbers in) to create the exact $2\sqrt{b}$ format before solving.
