1. Given $a>0$, $b>0$, $a+b=15$, and $ab=9$, find the value of $\sqrt{\frac{b}{a}} + \sqrt{\frac{a}{b}}$.
    
      
    
2. Given $\frac{2a+b}{a-b} = 3$, find the value of $\frac{\sqrt{27a^2}}{\sqrt{12b^2}}$ (where $a$ and $b$ are positive numbers).
    
      
    
3. For two rational numbers $a$ and $b$, if both the sum and the product of $3+a\sqrt{2}$ and $b-4\sqrt{2}$ are rational numbers, find the values of $a$ and $b$.
    
      
    
4. Find the rational number $k$ such that the result of $\sqrt{3}\left(2\sqrt{3} - \frac{k}{\sqrt{2}}\right) + \sqrt{2}\left(\frac{3}{\sqrt{3}} + \sqrt{2}\right)$ is a rational number.
    
      
    
5. Evaluate $(\sqrt{5}+\sqrt{2}-1)(\sqrt{5}-\sqrt{2}+1)$.
    
      
    
6. Where $n$ is a natural number, evaluate:
    
      
    
    $$\{(\sqrt{3}-\sqrt{2})^n + (\sqrt{3}+\sqrt{2})^n\}^2 - \{(\sqrt{3}-\sqrt{2})^n - (\sqrt{3}+\sqrt{2})^n\}^2$$
    
7. Find the rational number $a$ such that the result of $(4 - 3\sqrt{2})(a + \sqrt{2})$ is a rational number.
    
      
    
8. Given $x = \sqrt{3}+\sqrt{2}$ and $y = \sqrt{3}-\sqrt{2}$, find the value of $x^2 - y^2$.
    
      
    
9. Evaluate $\frac{\sqrt{5} - 2}{\sqrt{5} + 2} + \frac{\sqrt{5} + 2}{\sqrt{5} - 2}$.
    
      
    
10. Given $x = \frac{\sqrt{3}-1}{2}$, find the value of $4x^2 + 4x + 3$.
