1. For the statement "For a real number $x$, if $x > 3$, then $x^2 > 9$":
    
      
    - Write the converse, inverse, and contrapositive.
        
          
        
    - Determine whether each new statement is True or False.
        
          
        
    - Provide a counterexample for any statement that is False.
        
          
        
2. Prove the following statement using proof by contraposition:
    
    "For any integer $n$, if $7n - 2$ is even, then $n$ is even."
    
      
    
3. Prove the following statement using proof by contraposition:
    
    "For any integers $a$ and $b$, if $a \times b$ is odd, then both $a$ and $b$ are odd."
    
      
    
4. Prove by contradiction that $\log_2 3$ is irrational.
    
      
    
5. Prove the following statement using proof by contraposition:
    
    "For real numbers $x$ and $y$, if $x + y > 100$, then $x > 50$ or $y > 50$."
    
      
    
6. Prove the following statement using proof by contraposition:
    
    "For any integer $n$, if $n^3 + n + 5$ is odd, then $n$ is even."
    
      
    
7. Prove the following statement using proof by contraposition:
    
    "For any integers $a, b,$ and $c$, if $a^2 + b^2 = c^2$, then at least one of $a$ and $b$ is even."
