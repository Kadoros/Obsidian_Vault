빈칸 채우기

| Any integer                   | n       |
| ----------------------------- | ------- |
| **Consecutive** integers      | n,  n+1 |
| Any two integers              | n,  m   |
| An **even** integer           |         |
| Consecutive even integers     |         |
| Any two even integers         |         |
| An **odd** integer            |         |
| A **multiple** of 5           |         |
| A multiple of k               |         |
| One more than a multiple of 3 |         |
| A **square** number           |         |
| A **cube** number             |         |
| A **rational** number         |         |

1. Prove that the following equation holds for all real numbers $x$:
    
    $$(x+3)(x-3) = x^2 - 9$$
    
2. Prove that the following equation holds for all real numbers $x$:
    
    $$(2x-2)(x-3) + 2(x-1) = 2(x-2)(x-1)$$
    
3. Prove that the sum of any two odd integers is always even.
    
4. Prove that the following equation holds for all real numbers $a$ and $b$:
    
    $$(a+b)^2 - (a-b)^2 = 4ab$$
    
5. Prove that $x^3 = x$ for all elements $x$ in the set $S = \{-1, 0, 1\}$.
    
6. Prove that $n^2 - n$ is always an even integer for any integer $n$.
    
7. Prove that the inequality $x^2 - 5x + 7 > 0$ always holds for any integer $x$ such that $1 \le x \le 4$.
    
8. Determine whether the following statement is true or false. If false, provide a counterexample to prove it: "All prime numbers are odd."
    
9. Prove that the product of two consecutive integers is always even.
    
10. Determine whether the following statement is true or false, and prove your answer: "For all real numbers $x$, $x^2 \ge x$."
