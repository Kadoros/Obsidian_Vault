Using the rules of logical negation, write the correct negation for each of the following statements. 

_(Hint: Remember how to negate "all/every", "or", and "if A then B" statements)._

1. Every student in the class completed the assignment.
    
2. The number $n$ is a multiple of 4 or a multiple of 7.
    
3. If I study hard, then I will pass the math exam.
    

 Construct truth tables for the following logical expressions.

1. Create a truth table for: $\text{not } (P \text{ or } Q)$
    
2. Use a truth table to prove De Morgan's Law. Show that the following two statements are logically equivalent:
    
    - $\text{not } (P \text{ and } Q)$
        
    - $(\text{not } P) \text{ or } (\text{not } Q)$
        

Prove each of the following statements using mathematical induction.

Prove that for all positive integers $n$:

$$1 + 2 + 3 + \dots + n = \frac{n(n+1)}{2}$$

Prove that for all integers $n \ge 4$:

$$2^n > n^2$$

Prove that for any real number $x > -1$ and all integers $n \ge 1$, the following inequality holds:

$$(1+x)^n \ge 1+nx$$

Prove that for all positive integers $n$, the following inequality holds:

$$1 + \frac{1}{2} + \frac{1}{3} + \dots + \frac{1}{2^n} \ge 1 + \frac{n}{2}$$
