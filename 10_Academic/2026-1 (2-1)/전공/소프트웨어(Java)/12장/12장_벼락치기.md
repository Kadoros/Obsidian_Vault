# 12장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> 추상화 = 사용/구현 분리. **this**는 hidden field·다른 생성자 호출. immutable은 **참조 리턴까지 막아야** 성립.

## 무조건 외울 것
1. **this** ① `this.radius=radius` ② `this(1.0)` 생성자 호출
2. 설계 지침: **통일성 · 책임분리 · 재사용 · 표준요소(no-arg/equals/toString) · 스타일**
3. **immutable 함정**: private+setter없음만으로 안 됨 → **mutable 참조 리턴 accessor도 없어야**
4. **protected** = 상속 관계 접근 허용
5. 구현 Bottom-up / 설계 Top-down

## immutable 조건
1. 모든 field private
2. setter 없음
3. 변경가능 객체 참조를 리턴하는 accessor 없음

## 설계 지침 한 줄씩
- 통일성: 한 class = 한 entity
- 책임분리: String/StringBuilder/StringBuffer
- 재사용: 지나친 최적화 금지
- 표준: no-arg constructor, equals, toString
- 순서: data → constructor → method

## local 변수
- 사용 전 **명시적 초기화 필수**
