# 15장. 예상문제 ✏️

> 답은 `> [!success]- 정답` 토글 안에 숨김.

## ⭕❌ OX 문제

**1.** Swing component는 AWT component보다 플랫폼 의존이 크다. (   )
> [!success]- 정답
> ❌ — Swing은 Java로 직접 그려 플랫폼 의존이 적은 lightweight, AWT가 heavyweight.

**2.** JPanel의 기본 layout manager는 BorderLayout이다. (   )
> [!success]- 정답
> ❌ — JPanel의 기본은 FlowLayout. (JFrame의 content pane 기본이 BorderLayout)

**3.** Color, Font는 GUI component의 하위 클래스이다. (   )
> [!success]- 정답
> ❌ — component가 아니라 속성을 설명하는 helper class다.

**4.** BorderLayout은 다섯 영역으로 나뉜다. (   )
> [!success]- 정답
> ⭕ — North, South, East, West, Center.

## 🔤 빈칸 채우기

**5.** BorderLayout의 5개 영역은 ____, ____, ____, ____, ______ 이다.
> [!success]- 정답
> North, South, East, West, Center

**6.** 프레임을 화면에 보이게 하려면 `setVisible(____)`를 호출한다.
> [!success]- 정답
> true

**7.** `new Color(r, g, b)`에서 각 값의 범위는 ____ ~ ____ 이다.
> [!success]- 정답
> 0 ~ 255

## 📝 단답·서술형

**8.** Layout Manager가 필요한 이유와 종류 3가지를 쓰시오.
> [!success]- 정답
> 모든 component를 손으로 좌표 지정할 수 없으므로, 일정 규칙에 따라 자동 배치하기 위해 필요하다. FlowLayout(순서대로 흐름), GridLayout(격자), BorderLayout(5영역).

**9.** Panel을 sub-container로 사용하는 권장 절차를 설명하시오.
> [!success]- 정답
> 먼저 panel에 관련 component들을 묶어 배치하고, 그 panel을 frame에 add한다. 복잡한 화면을 panel 단위로 그룹화해 관리하기 쉽다.

## 💻 코드 분석

**10.** 다음 코드가 하는 일을 설명하시오.
```java
JFrame frame = new JFrame("Test Frame");
frame.setLayout(new FlowLayout());
frame.add(new JButton("Ok"));
frame.add(new JButton("Cancel"));
frame.pack();
frame.setVisible(true);
```
> [!success]- 정답
> "Test Frame" 제목의 프레임을 만들고 FlowLayout으로 설정한 뒤 Ok/Cancel 버튼을 순서대로 추가한다. pack()으로 내용에 맞게 크기를 조정하고 setVisible(true)로 화면에 표시한다. 두 버튼은 흐르듯 가로로 배치된다.
