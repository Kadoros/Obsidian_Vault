# 15장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> Frame(JFrame) 위에 Panel·component를 **Layout Manager** 규칙으로 배치하고 `setVisible(true)`로 보인다. Swing은 J로 시작하는 lightweight.

## 무조건 외울 것
1. **Swing(J, lightweight) vs AWT(heavyweight)**
2. Layout 3종: **FlowLayout / GridLayout / BorderLayout(5영역)**
3. BorderLayout 5영역: **North, South, East, West, Center**
4. JFrame 필수: `setSize`, `add`, `setVisible(true)`, `setDefaultCloseOperation(EXIT_ON_CLOSE)`
5. JPanel 기본 layout = **FlowLayout**

## Color / Font
- `new Color(r,g,b)` 0~255, `setBackground/Foreground`
- `new Font("SansSerif", Font.BOLD, 16)`, style 합 `BOLD+ITALIC`

## Container vs Helper
- Container = 담음(Frame, Panel) / Helper = 속성(Color, Font, Dimension)

## Panel
- 그룹화 → 먼저 panel에 모으고 frame에 add

## 화면 갱신
- `setText` / `repaint()` / `revalidate()`

## Border/Icon
- `setBorder(new TitledBorder("..."))`, `new ImageIcon("path")`
