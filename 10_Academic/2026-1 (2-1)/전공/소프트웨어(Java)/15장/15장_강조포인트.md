# 15장. 강조포인트 ⭐

## 🔴 Swing vs AWT
- Swing = **J 접두사, lightweight**(Java로 직접 그림, 플랫폼 의존 적음)
- AWT = **heavyweight**(기본 GUI 의존)
- JButton인 이유: Button이 이미 java.awt에 있음

## 🔴 Layout Manager 3종 (★ 단골)
- **FlowLayout**: 순서대로 흐름 (JPanel 기본)
- **GridLayout**: 격자(행, 열)
- **BorderLayout**: **North/South/East/West/Center** 5영역
- `add(comp, BorderLayout.EAST)`처럼 constraint 지정

## 🔴 JFrame 필수 4종
```java
setSize(400,300);
add(...);
setVisible(true);
setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE);
```

## 🔴 Panel
- 그룹화 sub-container, **먼저 panel에 모으고 frame에 add** 권장
- `new JPanel()` 기본 layout = **FlowLayout**

## 🔴 Container vs Helper
- Container = 담는 것(JFrame, JPanel)
- Helper = 속성 설명(Color, Font, Dimension) — component 아님

## 🔴 Color = RGB 0~255
- `new Color(r,g,b)`, `setBackground/setForeground`

## 🔴 Font
- `new Font("SansSerif", Font.BOLD, 16)`
- style 합치기: `Font.BOLD + Font.ITALIC`

## 🟥 화면 갱신
- 값 바뀌면 `setText` / `repaint()` / `revalidate()`
