# 15장. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **AWT** | Java 초기 GUI toolkit. 기본 GUI에 의존 → heavyweight |
| **Swing** | Java 2부터의 GUI. Java로 직접 그림 → lightweight, J로 시작 |
| **Container** | 다른 GUI component를 담는 class (JFrame, JPanel …) |
| **Helper class** | component가 아니라 속성을 설명하는 class (Color, Font, Dimension) |
| **Layout Manager** | container 안 component를 규칙대로 자동 배치 |

## Swing vs AWT (★)
- Swing: J 접두사, lightweight, 플랫폼 의존 적음
- AWT: heavyweight, 기본 GUI 의존
- 왜 JButton? Button은 이미 java.awt에 있어서

## Frame
- 최상위 창, 다른 component 담는 컨테이너 → **JFrame**
- 필수 호출: `setSize`, `add`, `setVisible(true)`, `setDefaultCloseOperation(JFrame.EXIT_ON_CLOSE)`
- 1.5+: `frame.add()` (이전 `getContentPane().add()`)

## Layout Manager 3종 (★)
| | 배치 |
|---|---|
| **FlowLayout** | 순서대로 흐르게(JPanel 기본) |
| **GridLayout** | 격자(행×열) |
| **BorderLayout** | North/South/East/West/Center 5영역 |
- `container.setLayout(new XxxLayout())`
- BorderLayout: `add(comp, BorderLayout.EAST)`

## Panel
- 그룹화용 sub-container
- 권장: panel에 모은 뒤 frame에 panel을 add
- `new JPanel()` 기본 = FlowLayout, `new JPanel(layout)`

## 화면 갱신
- `setText()`, `repaint()`, `revalidate()`

## Color (RGB)
- `new Color(r,g,b)` 0~255
- `setBackground`, `setForeground`
- `Color.red`(소문자) / `Color.RED`(1.4+ 대문자)

## Font
- `new Font(name, style, size)`
- 표준글꼴: SansSerif/Serif/Monospaced/Dialog/DialogInput
- style: PLAIN(0)/BOLD(1)/ITALIC(2), 합치기 `Font.BOLD+Font.ITALIC`

## Border / Icon
- `setBorder(new TitledBorder("..."))`, `new LineBorder(color, width)`
- `new ImageIcon("path")`, `setIcon(icon)`
