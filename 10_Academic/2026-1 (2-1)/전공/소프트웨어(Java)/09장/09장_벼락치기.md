# 9장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> data는 **private**로 숨기고, **getter/setter**로만 통하게 한다. 그래야 보호·검증·유지보수가 된다.

## 무조건 외울 것
1. **public / default / private** = 전체 / 같은 package / 같은 class
2. 객체 변수로 **private 접근 불가**, 단 같은 class 안에선 가능
3. private 이유 3개: **보호 · 임의접근 차단 · 유지보수**
4. setter에서 **검증** 가능 `(x>=0)? x : 0`
5. **객체 배열 = 참조 배열**, `new T[10]`은 칸만(=null), 각각 `new T()` 필요

## getter/setter 모양
```java
public double getRadius() { return radius; }
public void setRadius(double r) { radius = (r>=0)? r : 0; }
```

## Passing
- primitive → 값 복사 (원본 안 바뀜)
- object → 참조값 전달 (원본 바뀜)

## Package / import
- package = namespace = 관리 단위 (폴더 비유)
- `import java.util.*;`

## 함정
- `myCircle.radius` ❌ (private) → `myCircle.getRadius()` ⭕
- `circleArray[1].getArea()` = **2단계 참조**
