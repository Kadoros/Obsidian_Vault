# 9장. 예상문제 ✏️

> 답은 `> [!success]- 정답` 토글 안에 숨김. 먼저 풀고 펼쳐서 확인.

## ⭕❌ OX 문제

**1.** private member는 객체 변수를 통해 다른 class에서 접근할 수 있다. (   )
> [!success]- 정답
> ❌ — private는 선언된 그 class 안에서만 접근 가능. 같은 class 내부면 객체 변수로도 가능하지만, 외부 class에서는 불가.

**2.** modifier를 아무것도 안 붙이면 같은 package 안에서 접근 가능하다. (   )
> [!success]- 정답
> ⭕ — 그것이 default(package-private).

**3.** `new Circle[10]`을 하면 Circle 객체 10개가 바로 생성된다. (   )
> [!success]- 정답
> ❌ — 참조 변수 칸 10개만 생긴다(전부 null). 각 칸을 `arr[i] = new Circle();`로 채워야 한다.

**4.** 객체를 method에 넘기면 객체 전체가 복사되어 전달된다. (   )
> [!success]- 정답
> ❌ — reference type은 by value지만 **참조값(주소)**이 복사된다. 같은 객체를 가리키므로 내용 변경은 원본에 반영된다.

## 🔤 빈칸 채우기

**5.** data field를 외부로부터 읽게 해주는 method를 ____, 값을 바꾸게 해주는 method를 ____라 한다.
> [!success]- 정답
> getter(accessor) / setter(mutator)

**6.** 다른 package의 class를 쓰려면 ________ 문을 사용한다.
> [!success]- 정답
> import (예: `import java.util.Date;`)

## 📝 단답·서술형

**7.** Data field를 private로 선언하는 이유 3가지를 쓰시오.
> [!success]- 정답
> ① 데이터 보호 ② 사용자의 임의 접근 차단 ③ class의 유지/보수를 쉽게. (추가로 setter에서 검증 가능)

**8.** `myCircle.radius *= 1.1;`이 컴파일 에러인 이유와 올바른 대안을 쓰시오.
> [!success]- 정답
> radius가 private이라 외부 객체 변수로 접근 불가. 대안: `myCircle.setRadius(myCircle.getRadius() * 1.1);`

**9.** `circleArray[1].getArea()` 실행 시 일어나는 참조 과정을 설명하시오.
> [!success]- 정답
> 두 단계 참조. `circleArray`가 배열 전체를 참조하고, `circleArray[1]`이 그 칸의 Circle 객체를 참조한 뒤 그 객체의 getArea()를 호출한다.

## 💻 코드 분석

**10.** 아래 setter가 단순 대입(`radius = newRadius;`)보다 나은 점은?
```java
public void setRadius(double newRadius) {
  radius = (newRadius >= 0) ? newRadius : 0;
}
```
> [!success]- 정답
> 음수 같은 잘못된 값을 걸러내는 **검증**이 들어간다. private + setter 조합이라야 이런 통제가 가능하다.
