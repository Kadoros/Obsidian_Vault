# 9장. 시험노트 📝 (개념 정밀 정리)

## 용어 정의 (서술형 대비)

| 용어 | 정의 |
| --- | --- |
| **public** | 모든 package, 모든 class에서 접근 허용 |
| **default** | 같은 package 안에서만 접근 (아무 modifier도 안 붙인 상태) |
| **private** | 선언된 그 class 안에서만 접근 |
| **getter/setter** | private data를 읽고(get)/바꾸기(set) 위해 제공하는 public method. accessor/mutator |
| **package** | 관련 class/interface를 묶는 namespace, 즉 프로그램 관리 단위 |
| **import** | 다른 package의 class 등을 사용하기 위한 선언 |

## private로 해야 하는 이유 (3가지, 자주 출제)

1. data를 **보호**
2. 사용자의 **임의 접근 차단**
3. class **유지/보수**를 쉽게

추가: setter 안에서 **검증(validation)** 가능 → `radius = (newRadius >= 0) ? newRadius : 0;`

## 접근 규칙 핵심

- 객체 변수(`obj.field`)로는 **private member 접근 불가**
- 같은 class 안에서는 private 접근 **가능**
- 그래서 일반적으로 외부에서 쓰려면 **getter/setter**가 정답
- `myCircle.radius` ❌ (private) / `myCircle.getRadius()` ⭕

## Passing Objects

| 전달 대상 | 방식 | 효과 |
| --- | --- | --- |
| primitive | pass by value | 값 복사, 원본 안 바뀜 |
| reference(object) | pass by value(참조값 전달) | 같은 객체 가리킴 → method에서 바꾸면 원본도 바뀜 |

## Array of Objects

- **객체 배열 = 참조 변수 배열**
- `new Circle[10]` → 칸만 생성, 내용은 null → `arr[i] = new Circle()`로 채워야 함
- `circleArray[1].getArea()` → **2단계 참조**(배열 참조 → 객체 참조)

## C vs Java (Stack 예)

- C: structure + function 따로, `push(s1,data)`, 데이터 임의 접근 가능
- Java: class(data + method), `s1.push(data)`, 임의 접근 차단 가능
- → 접근 보호 그 이상, object-oriented의 이점

## 설계 방식 비교

- 자판기/Stack 모두 procedure-oriented, object-oriented 둘 다 가능
- **크고 복잡해질수록** 객체지향이 관리에 유리 (작은 예제에선 차이 안 느껴짐)
