# 14장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> abstract class = 미완성 base class(new 불가, 생성자는 있음). interface = behavior 규정(전부 public abstract, 다중 구현).

## 무조건 외울 것
1. abstract class: **new 불가**, 생성자 O, **data type O**(`new T[10]` 가능)
2. abstract method = signature만, **abstract class 안에만**, 1개라도 있으면 class도 abstract
3. interface: data=**public static final**, method=**public abstract**, **다중 구현**, `implements`
4. class **단일상속** / interface **다중구현**
5. strong(is-a)→class, weak(특성)→interface

## Interface vs Abstract (핵심)
| | 변수 | 생성자 | 메소드 |
|---|---|---|---|
| abstract | 자유 | O | concrete 가능 |
| interface | 상수만 | X | 전부 abstract |

## Comparable
- `compareTo` 같0/큼+/작−. String·Date 구현

## Cloneable / 마커
- 빈 interface. `implements Cloneable` 안 하고 clone → CloneNotSupportedException

## Wrapper
- Integer/Double… **no-arg 없음**, **immutable**, Comparable 구현
- `Integer.parseInt(s)`, autoboxing/unboxing

## BigInteger/BigDecimal
- immutable, 연산은 method(`a.multiply(b)`)

## 함정
- `new int[10] instanceof Object` → true, 그러나 int[] ≠ Object[] 대입 불가
