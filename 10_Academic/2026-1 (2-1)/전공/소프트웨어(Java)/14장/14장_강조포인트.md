# 14장. 강조포인트 ⭐

## 🔴 abstract class new 불가, 그러나 생성자는 있음
- `new GeometricObject()` ❌
- 생성자는 정의 가능 → subclass 생성자가 chaining으로 호출
- **data type으로는 사용 가능** (`new GeometricObject[10]` ⭕ — 배열 칸일 뿐)

## 🔴 abstract method 규칙
- body 없이 signature만
- **abstract class 안에만** 존재 가능
- 하나라도 있으면 class는 **무조건 abstract**
- subclass가 다 구현 안 하면 subclass도 abstract

## 🔴 interface = behavior 규정
- 모든 data = **public static final**, 모든 method = **public abstract** (생략됨)
- `implements`로 구현, **다중 구현 가능**
- new 불가, data type 사용·casting 가능

## 🔴 Interface vs Abstract Class (표 암기)
- 변수: interface는 **상수만**(public static final) / abstract는 제한 없음
- 생성자: interface **없음** / abstract **있음**(new는 둘 다 불가)
- 메소드: interface **전부 abstract** / abstract는 **concrete 가능**

## 🔴 class vs interface 선택
- **strong(is-a)** → class 상속
- **weak(특성 보유)** → interface
- 다중상속 → 하나 class + 나머지 interface

## 🔴 Marker Interface
- 빈 interface (Cloneable, Serializable)
- clone(): `implements Cloneable` + override 안 하면 `CloneNotSupportedException`

## 🔴 Comparable
- `compareTo`: 같으면 0, 크면 +, 작으면 −
- `o instanceof Comparable` 이면 compareTo 보장

## 🟥 Wrapper
- **no-arg constructor 없음**, **immutable**
- numeric wrapper + Character는 Comparable 구현
- autoboxing/unboxing

## 🟥 배열 instanceof
- `new int[10] instanceof Object` → true
- 단 **int[]는 Object[]로 대체 불가** (primitive 배열)
