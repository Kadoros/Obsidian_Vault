# 14장. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **abstract class** | 일부를 의도적으로 미완성한 class. abstract method 포함 가능. base class 역할 |
| **abstract method** | body 없이 signature만 있는 메소드. abstract class에만 존재 가능 |
| **interface** | constant와 abstract method만 갖는 construct. 객체의 behavior를 규정 |
| **marker interface** | 내용 없는 빈 interface (예: Cloneable, Serializable) |
| **wrapper class** | primitive를 객체로 감싼 class (Integer, Double …) |

## Abstract Class 규칙 (★★)
1. abstract method는 **abstract class 안에만**
2. abstract method 1개라도 있으면 → class는 **무조건 abstract**
3. `new`로 인스턴스 **불가**, 단 **생성자는 정의 가능**(subclass가 사용)
4. abstract method 없는 abstract class도 가능
5. subclass가 abstract method를 다 구현 안 하면 → subclass도 abstract
6. superclass가 concrete여도 subclass는 abstract 가능
7. **data type으로는 사용 가능**: `GeometricObject[] g = new GeometricObject[10];` ⭕

## Interface 핵심
- `implements`로 구현
- modifier 생략: data = **public static final**, method = **public abstract**
- new 불가, data type 사용 가능
- 상수 접근: `InterfaceName.CONST`
- 충돌 interface는 컴파일러가 탐지

## Interface vs Abstract Class (표)

| | 변수 | 생성자 | 메소드 |
|---|---|---|---|
| Abstract class | 제한 없음 | 있음(new 불가) | concrete 가능 |
| Interface | 모두 public static final | 없음 | 모두 public abstract |

- class는 root가 Object 하나, interface는 단일 root 없음
- class **단일 상속**, interface **다중 구현 가능**

## 언제 class? 언제 interface?
- strong relationship(is-a, parent-child) → **class 상속**
- weak relationship(특성 보유) → **interface**
- 다중상속 필요 시 → 하나만 class, 나머지 interface

## Comparable
- `public int compareTo(Object o)` — 같으면 0, 크면 양수, 작으면 음수
- String, Date가 구현 → 비교/정렬 가능

## Cloneable
- marker interface(빈 interface)
- clone 지원: `implements Cloneable` + `clone()` override(`return super.clone()`)
- clone()은 protected, 기본 shallow copy

## Wrapper Class
- no-arg constructor **없음**, instance **immutable**
- numeric wrapper + Character → Comparable 구현
- Number class 상속: `intValue()`, `doubleValue()` …
- `MAX_VALUE`, `MIN_VALUE`
- `Integer.parseInt(s)`, `Integer.valueOf(s)`
- autoboxing/unboxing (JDK 1.5+)

## BigInteger / BigDecimal
- immutable, Number 상속, Comparable 구현, 연산은 method(`multiply`, `divide`)
