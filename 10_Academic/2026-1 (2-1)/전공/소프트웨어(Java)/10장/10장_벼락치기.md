# 10장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> **static = 클래스 소속(모두 공유)**, instance = 객체 소속. static 메소드에선 instance를 **객체 통해서만** 쓴다.

## 무조건 외울 것
1. static 안 붙으면 **전부 instance**
2. static 변수 = **모든 instance 공유**, 클래스로 접근이 원칙
3. static 메소드에서: static은 바로, **non-static은 객체(reference) 통해서**
4. `main()` static이라고 **다 static 만들면 최악** → Error
5. local 변수는 **final만** 가능 (static·public·private ❌)

## static으로 할까 말까
- 객체마다 달라야 함 → instance
- 객체와 무관 (예: 만든 객체 수) → static
- 공유는 **꼭 필요할 때만**

## class 가시성
- 한 파일 여러 class O, **public class는 1개**
- top-level class **private ❌**
- **inner class private ⭕**

## 함정 코드
```java
public static void main(String[] a){
  int n = numberOfObjects;  // static OK
  getArea();                // ❌ instance를 static에서 직접 호출
  Circle2 c = new Circle2();
  c.getArea();              // ⭕
}
```
