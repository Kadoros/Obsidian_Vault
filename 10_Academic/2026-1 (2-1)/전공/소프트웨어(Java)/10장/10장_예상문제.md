# 10장. 예상문제 ✏️

> 답은 `> [!success]- 정답` 토글 안에 숨김.

## ⭕❌ OX 문제

**1.** static 변수는 객체마다 따로 만들어진다. (   )
> [!success]- 정답
> ❌ — static은 클래스당 하나, 모든 instance가 공유한다.

**2.** static 메소드 안에서 instance 변수에 reference 없이 바로 접근할 수 있다. (   )
> [!success]- 정답
> ❌ — instance member는 객체(reference)를 통해서만. static만 바로 접근 가능.

**3.** 한 파일에 public class를 두 개 둘 수 있다. (   )
> [!success]- 정답
> ❌ — public class는 파일당 하나. 단 비-public class는 여러 개 가능.

**4.** local 변수에는 final을 붙일 수 있다. (   )
> [!success]- 정답
> ⭕ — local 변수에 허용되는 modifier는 final뿐이다(메소드 내 상수).

**5.** inner class는 private으로 선언할 수 있다. (   )
> [!success]- 정답
> ⭕ — top-level class와 달리 inner class는 private 가능.

## 🔤 빈칸 채우기

**6.** 클래스로부터 만들어진 객체를 클래스의 ________ 라고 한다.
> [!success]- 정답
> instance

**7.** 모든 객체가 공유하는 변수는 ________ 키워드로 선언한다.
> [!success]- 정답
> static

## 📝 단답·서술형

**8.** static 메소드에서 instance member에 접근하는 규칙을 설명하시오.
> [!success]- 정답
> static 메소드는 특정 객체에 묶이지 않으므로 instance member에 직접 접근할 수 없다. 반드시 객체(reference 변수)를 만들어 그것을 통해 접근해야 한다. static member는 reference 없이 바로 접근 가능.

**9.** 어떤 속성을 static으로 선언해야 하는지 기준을 쓰시오.
> [!success]- 정답
> 개별 객체에 종속된 속성은 non-static, 개별 객체와 무관하고 클래스를 통해 접근하는 게 자연스러운 속성(예: 생성된 객체 수)은 static. 공유 여부는 고려사항 중 하나이며 꼭 필요할 때만 공유한다.

## 💻 코드 분석

**10.** 아래 코드의 문제와 해결책은?
```java
public static void main(String[] args) {
  Circle2 c1 = new Circle2();
  double d = getArea();   // getArea()는 instance 메소드
}
```
> [!success]- 정답
> static인 main에서 instance 메소드 getArea()를 reference 없이 호출 → 컴파일 에러. 해결: `double d = c1.getArea();`처럼 객체를 통해 호출.
