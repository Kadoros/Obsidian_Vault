# 10장. 강조포인트 ⭐

## 🔴 static = 클래스 소속, 모두 공유
- static 변수는 class의 **모든 instance가 공유**
- 접근은 **클래스를 통해서**가 원칙 (`Circle2.getNumberOfObjects()`)
- static 안 붙으면 **전부 instance**

## 🔴 static 메소드에서의 접근 (★시험 단골)
- static → reference 변수 **없이** 접근
- non-static → reference 변수(객체) **통해서**

## 🔴 잘못된 static 사용 (빨강 경고)
- `main()`이 static이라고 **모든 메소드를 static**으로 만드는 것 = **최악**
- static 메소드에서 instance 메소드 직접 호출 → **Error**
- "Error 해결 방법은?" → 객체 생성 후 호출, 또는 static 제거

## 🔴 무엇을 static으로?
- 개별 instance 속성이면 **non-static**
- 개별 instance 속성 아니면 **static** (instance 지정하면 오히려 이상)
- **공유는 고려사항 중 하나일 뿐** — 공유 꼭 필요할 때만

## 🔴 Visibility of Classes
- 한 파일에 여러 class O, 단 **public class는 단 하나**
- top-level class에 **private 안 됨** (Why?)
- **inner class는 private 가능**

## 🔴 Local variable
- static ❌ / public·private ❌ / **final만 ⭕**
- final local = method 안에서 상수

## 🟥 헷갈림 주의
- `Circle2.radius` ❌ (instance 변수를 클래스로 접근 불가)
- 붕어빵 비유: 객체 = instance, 틀 = class
