# 17장. GUI (2) — 전체정리

> 15장에서 큰 그림(Frame·Layout)을, 16장에서 동작(Event)을 봤다면, 이 장은 **자주 쓰는 GUI component들의 세부 사용법** 카탈로그다. 외울 게 많지만 **공통 상위(AbstractButton)**와 **"무엇으로 무엇을 입력/표시하나"**의 분류만 잡으면 정리된다.

## 1. Buttons & AbstractButton

- Button = click 됐을 때 action을 유발하는 component.
- Swing의 regular button, toggle button, **check box button, radio button**은 모두 **`javax.swing.AbstractButton`**에서 일반화(generalized)된다. → 이 공통 상위가 시험 포인트.
- 그래서 text, icon, mnemonic, alignment 등 많은 property를 셋이 **공유**한다.

### JButton
`AbstractButton`을 상속. 생성자:
```java
JButton()
JButton(String text)
JButton(String text, Icon icon)
JButton(Icon icon)
```
주요 property: text, icon, mnemonic, horizontalAlignment, verticalAlignment, horizontalTextPosition, verticalTextPosition, iconTextGap.

### 3가지 icon
한 버튼이 상태에 따라 다른 아이콘을 가질 수 있다.
- **default icon**: 평소 (보통 이것만 씀)
- **pressed icon**: 버튼이 **눌렸을 때**
- **rollover icon**: 마우스가 버튼 **위에 있지만 안 눌렸을 때**

### Alignment / Text Position
- Horizontal **alignment**: LEADING, LEFT, CENTER, RIGHT, TRAILING (default = **TRAILING**)
- Vertical **alignment**: TOP, CENTER, BOTTOM (default = **CENTER**)
- Horizontal **text position**: default = **RIGHT** (아이콘 기준 텍스트 위치)
- Vertical **text position**: default = **CENTER**

## 2. JCheckBox

- AbstractButton의 property(text, icon, mnemonic, alignment 등)를 상속.
- **서로 독립적** → 여러 개를 **동시에 선택** 가능 (Centered, Bold, Italic 각각 켜고 끄기).
```java
private JCheckBox jchkBold = new JCheckBox("Bold");
jchkBold.addActionListener(new ActionListener() {
  public void actionPerformed(ActionEvent e) { setNewFont(); }
});
// 선택 여부: jchkBold.isSelected()
```

## 3. JRadioButton

- check box의 변형. 보통 **group으로 묶어 한 번에 하나만** 선택할 때 쓴다.
- 묶으려면 **ButtonGroup**을 쓴다. (이걸 안 하면 라디오버튼도 따로따로 켜진다 — 시험 포인트.)
```java
ButtonGroup btg = new ButtonGroup();
btg.add(jrbRed);
btg.add(jrbGreen);
btg.add(jrbBlue);   // 이제 셋 중 하나만 선택됨
```

## 4. JLabel

- 짧은 text, image, 또는 **둘 다**를 보여주는 **표시 전용** component (입력은 못 받음).
```java
JLabel()
JLabel(String text)
JLabel(String text, int horizontalAlignment)
JLabel(Icon icon)
JLabel(String text, Icon icon, int horizontalAlignment)
```
- property는 JButton과 유사: text, icon, alignment, textPosition, iconTextGap.
```java
ImageIcon icon = new ImageIcon("image/grapes.gif");
JLabel jlbl = new JLabel("Grapes", icon, SwingConstants.CENTER);
jlbl.setHorizontalTextPosition(SwingConstants.CENTER);
jlbl.setVerticalTextPosition(SwingConstants.BOTTOM);
jlbl.setIconTextGap(5);
```

## 5. JTextField

- user가 **한 줄** 문자를 입력하는 공간. 이름·짧은 값 입력에 유용.
```java
JTextField(int columns)            // 빈 필드 + 열 수
JTextField(String text)            // 초기 텍스트
JTextField(String text, int columns)
```
- property: text, horizontalAlignment, **editable**, columns.
- method:
  - `getText()` — 입력된 문자열 얻기
  - `setText(String)` — 텍스트 설정
  - `setEditable(boolean)` — 수정 가능 여부 (default **true**)
  - `setColumns(int)` — 열 수 설정

## 6. JTextArea

- **여러 줄** text 입력. (JTextField로는 여러 줄을 못 받는다.)
```java
JTextArea(int rows, int columns)
JTextArea(String s, int rows, int columns)
```
- property: text, editable, columns, **lineWrap**, **wrapStyleWord**, rows, lineCount, tabSize.
- 보통 **JScrollPane**으로 감싸 스크롤을 제공한다.
```java
JScrollPane scrollPane = new JScrollPane(jtaDescription);
add(scrollPane, BorderLayout.CENTER);
```

## 7. JComboBox

- 항목 목록에서 **하나**를 고르는 드롭다운. list와 기능은 비슷하나 **한 값만** 얻는다.
```java
jcbo.addItem(Object item);           // 항목 추가
Object sel = jcbo.getSelectedItem(); // 선택 항목 얻기
```
- 항목을 선택하면 **ItemEvent의 `itemStateChanged()`와 ActionEvent의 `actionPerformed()`가 둘 다** 호출된다(★).
```java
public void itemStateChanged(ItemEvent e) {
  if (e.getSource() instanceof JComboBox)
    String s = (String)e.getItem();
}
```

## 8. JList

- combo box와 비슷하나, user가 **하나 또는 여러 값**을 선택할 수 있다.
```java
JList()
JList(Object[] stringItems)
```
- property: selectedIndex, selectedIndices, selectedValue, selectedValues, **selectionMode**, visibleRowCount.
- → ComboBox(하나만) vs JList(하나 또는 여럿)의 차이를 기억.

## 9. JScrollBar

- user가 값의 **범위에서 값을 정하는** 막대. **horizontal / vertical** 두 방향.
- 예: 메시지를 좌우(horizontal)·상하(vertical) scrollbar로 움직이기.

## 10. JScrollPane

- 스크롤 영역을 제공하는 컨테이너. JTextArea 같은 component를 감싼다.
```java
public class DescriptionPanel extends JPanel {
  private JTextArea jtaDescription = new JTextArea();
  public DescriptionPanel() {
    JScrollPane scrollPane = new JScrollPane(jtaDescription);
    add(scrollPane, BorderLayout.CENTER);
  }
}
```

## 11. JSlider

- JScrollBar와 유사하지만 **property가 더 많고** 다양한 형태(눈금, 라벨 등)로 나타날 수 있다.
- scroll bar 대신 slider로 값(예: 메시지 위치)을 조절하는 예제.

## 정리 — component 한눈에

| component | 용도 | 핵심 |
| --- | --- | --- |
| **AbstractButton** | 버튼류 공통 상위 | JButton/JCheckBox/JRadioButton의 부모 |
| JButton | 클릭 액션 | icon 3종, default alignment=TRAILING |
| JCheckBox | **독립적 다중** 선택 | isSelected() |
| JRadioButton | group 내 **단일** 선택 | **ButtonGroup 필수** |
| JLabel | 표시 전용(text/icon) | 입력 불가 |
| JTextField | **한 줄** 입력 | getText/setText/setEditable |
| JTextArea | **여러 줄** 입력 | lineWrap, +JScrollPane |
| JComboBox | 목록에서 **하나** | itemStateChanged + actionPerformed |
| JList | 목록에서 **하나/여럿** | selectionMode |
| JScrollBar / JSlider | 범위 값 조절 | 가로/세로 |

## 정리 — 이 장의 핵심 한 줄
> 버튼류는 **AbstractButton** 공통 상위. **RadioButton은 ButtonGroup으로 단일 선택**, CheckBox는 독립 다중 선택. 입력은 **TextField(한 줄)/TextArea(여러 줄)**, 선택은 **ComboBox(하나)/JList(하나~여럿)**.
