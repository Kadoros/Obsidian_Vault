# 17장. 예상문제 ✏️

> 답은 `> [!success]- 정답` 토글 안에 숨김.

## ⭕❌ OX 문제

**1.** JButton, JCheckBox, JRadioButton은 모두 AbstractButton을 상속한다. (   )
> [!success]- 정답
> ⭕ — javax.swing.AbstractButton에서 일반화된다.

**2.** JTextField로 여러 줄의 텍스트를 입력받을 수 있다. (   )
> [!success]- 정답
> ❌ — 한 줄만. 여러 줄은 JTextArea.

**3.** JRadioButton은 ButtonGroup으로 묶지 않아도 자동으로 하나만 선택된다. (   )
> [!success]- 정답
> ❌ — ButtonGroup으로 묶어야 한 번에 하나만 선택된다.

**4.** JComboBox 항목 선택 시 ItemEvent와 ActionEvent가 모두 발생할 수 있다. (   )
> [!success]- 정답
> ⭕ — itemStateChanged와 actionPerformed가 둘 다 호출된다.

## 🔤 빈칸 채우기

**5.** 여러 라디오버튼을 묶어 하나만 선택되게 하려면 ____________ 를 사용한다.
> [!success]- 정답
> ButtonGroup

**6.** JTextArea를 스크롤 가능하게 하려면 ____________ 로 감싼다.
> [!success]- 정답
> JScrollPane

**7.** 콤보박스에서 선택된 항목을 얻는 메소드는 ________________ 이다.
> [!success]- 정답
> getSelectedItem()

## 📝 단답·서술형

**8.** JCheckBox와 JRadioButton의 차이를 설명하시오.
> [!success]- 정답
> JCheckBox는 서로 독립적이어서 여러 개를 동시에 선택할 수 있다. JRadioButton은 보통 ButtonGroup으로 묶어 한 번에 하나만 선택되게 쓴다.

**9.** JTextField와 JTextArea의 차이를 쓰시오.
> [!success]- 정답
> JTextField는 한 줄 입력, JTextArea는 여러 줄 입력. TextArea는 lineWrap 등 property가 있고 보통 JScrollPane으로 감싸 스크롤을 제공한다.

## 💻 코드 분석

**10.** 다음 코드의 의미를 설명하시오.
```java
ButtonGroup btg = new ButtonGroup();
btg.add(jrbRed);
btg.add(jrbGreen);
btg.add(jrbBlue);
```
> [!success]- 정답
> 세 라디오버튼을 하나의 그룹으로 묶는다. 이렇게 하면 사용자가 한 번에 하나의 색만 선택할 수 있다(하나를 누르면 나머지는 해제됨).
