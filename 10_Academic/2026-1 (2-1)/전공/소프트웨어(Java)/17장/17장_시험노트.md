# 17장. 시험노트 📝 (개념 정밀 정리)

## component 분류 (★ 표 암기)

| component | 핵심 |
| --- | --- |
| **AbstractButton** | JButton/JCheckBox/JRadioButton의 공통 상위 |
| **JButton** | 클릭 시 action |
| **JCheckBox** | 독립적으로 여러 개 선택 가능, `isSelected()` |
| **JRadioButton** | ButtonGroup으로 묶어 **하나만** 선택 |
| **JLabel** | text/icon 표시 전용(입력 X) |
| **JTextField** | **한 줄** 입력 |
| **JTextArea** | **여러 줄** 입력, lineWrap |
| **JComboBox** | 목록에서 **하나** 선택 |
| **JList** | 목록에서 **하나 또는 여럿** |
| **JScrollBar / JSlider** | 범위 값 조절 |

## JButton
- 상위: AbstractButton
- icon 3종: **default / pressed / rollover**
- alignment: default horizontal = TRAILING, vertical = CENTER
- text position: default horizontal = RIGHT

## JRadioButton 그룹화 (★)
```java
ButtonGroup btg = new ButtonGroup();
btg.add(jrb1); btg.add(jrb2);   // 한 번에 하나만 선택
```
- ButtonGroup으로 안 묶으면 라디오버튼도 따로 선택됨

## JTextField vs JTextArea
- TextField: 한 줄, columns
- TextArea: 여러 줄, rows/columns, lineWrap, wrapStyleWord
- TextField method: `getText`, `setText`, `setEditable`(기본 true), `setColumns`

## JComboBox
- `addItem`, `getSelectedItem`
- 선택 시 **itemStateChanged(ItemEvent)** + **actionPerformed(ActionEvent)** 둘 다 호출

## JList
- 단일/다중 선택 (selectionMode)
- selectedIndex / selectedValue 등

## JScrollPane
- 다른 component(TextArea 등)를 감싸 스크롤 제공
- `new JScrollPane(comp)`

## JSlider vs JScrollBar
- Slider가 property 더 많고 형태 다양(눈금 등)
