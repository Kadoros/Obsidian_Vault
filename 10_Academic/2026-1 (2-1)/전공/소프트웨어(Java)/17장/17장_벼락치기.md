# 17장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> 버튼류는 **AbstractButton** 공통 상위. RadioButton은 **ButtonGroup**으로 단일 선택. TextField(한 줄) vs TextArea(여러 줄).

## 무조건 외울 것
1. **AbstractButton** = JButton/JCheckBox/JRadioButton 공통 상위
2. **JRadioButton + ButtonGroup** → 하나만 선택
3. **JCheckBox** → 독립적 다중 선택
4. **JTextField 한 줄 / JTextArea 여러 줄**(+JScrollPane)
5. **JComboBox** 선택 시 itemStateChanged + actionPerformed 둘 다

## component 한 줄 정리
- JButton: 클릭 액션
- JLabel: 표시 전용(text/icon)
- JComboBox: 하나 선택 / JList: 하나~여럿
- JScrollBar/JSlider: 범위 값

## 코드 조각
```java
ButtonGroup g = new ButtonGroup(); g.add(jrb1); g.add(jrb2);
jcbo.addItem("Red"); String s = (String)jcbo.getSelectedItem();
JScrollPane sp = new JScrollPane(jtaDescription);
```

## 함정
- 여러 줄 입력은 TextField ❌ → **TextArea**
- 라디오 단일선택은 **ButtonGroup 필수**
