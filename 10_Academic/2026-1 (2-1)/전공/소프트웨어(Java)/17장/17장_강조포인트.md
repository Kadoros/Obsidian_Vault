# 17장. 강조포인트 ⭐

## 🔴 AbstractButton
- JButton, JCheckBox, JRadioButton의 **공통 상위 클래스**
- text/icon/mnemonic/alignment 등 공통 property 제공

## 🔴 JRadioButton은 ButtonGroup으로 (★)
```java
ButtonGroup btg = new ButtonGroup();
btg.add(jrb1); btg.add(jrb2);
```
- group으로 묶어야 **한 번에 하나만** 선택됨

## 🔴 JCheckBox vs JRadioButton
- CheckBox: 독립적, **여러 개 동시 선택** 가능
- RadioButton: group 내 **단일 선택**

## 🔴 JTextField(한 줄) vs JTextArea(여러 줄)
- 여러 줄 입력 = **JTextArea** (TextField로는 안 됨)
- TextArea는 보통 **JScrollPane**으로 감쌈

## 🔴 JComboBox 이벤트
- 항목 선택 시 **itemStateChanged + actionPerformed 둘 다** 호출
- `addItem`, `getSelectedItem`

## 🔴 JLabel = 표시 전용
- text/icon 보여주기만, 입력 불가

## 🔴 JButton icon 3종
- default / pressed / rollover

## 🟥 JComboBox vs JList
- ComboBox: 하나만
- List: 하나 또는 여럿(selectionMode)
