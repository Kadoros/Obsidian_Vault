# 11장. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **regular expression(regex)** | 특정 패턴의 문자열. matching/replacing/splitting에 사용하는 강력한 도구 |
| **valueOf** | String의 static 메소드. char/숫자 등을 String으로 변환 (overloading) |
| **palindrome** | 앞뒤로 읽어도 같은 문자열(회문) |
| **StringBuilder/StringBuffer** | String을 대체하는 **가변** 문자열 클래스. append/insert/delete 가능 |
| **Character** | char를 감싸는 wrapper class |

## regex 핵심 기호

| 패턴 | 의미 |
| --- | --- |
| `.*` | 임의 문자 0개 이상 |
| `[$+#]` | $,+,# 중 하나 |
| `\\d` | 숫자, `\\w` 단어문자 |

- `matches(regex)` : 패턴에 맞나?
- `replaceAll(regex, s)` / `replaceFirst(regex, s)` / `split(regex)`

```java
"a+b$#c".replaceAll("[$+#]", "NNN");  // aNNNbNNNNNNc
"Java,C?C#,C++".split("[.,:;?]");      // [Java, C, C#, C++...]
"Java1HTML2Perl".split("\\d");         // [Java, HTML, Perl]
```

## indexOf 규칙

- 못 찾으면 **-1**
- 두 번째 인자 = 검색 시작 위치
- **대소문자 구분** (`indexOf("java")` ≠ "Java")
- `lastIndexOf` = 뒤에서부터

## String vs StringBuilder vs StringBuffer

| 클래스 | 가변성 | 특징 |
| --- | --- | --- |
| String | **불변(immutable)** | 한번 만들면 고정 |
| StringBuilder | **가변** | append/insert/delete/reverse |
| StringBuffer | **가변 + 동기화** | StringBuilder와 유사하나 synchronized |

→ 책임 분리(separating responsibilities)의 예

## StringBuilder 주요 메소드
append, insert, delete, deleteCharAt, reverse, replace, setCharAt, toString, capacity, length, setLength, charAt

## Command-Line Parameters
- `java TestMain arg0 arg1 ...` → main의 `args[0]`, `args[1]` …과 대응
- main도 일반 메소드 (다른 메소드가 호출 가능)

## Character
- `Character.isLetterOrDigit(c)`, `isLetter`, `isDigit`
- `compareTo`: 같으면 0, 크면 양수, 작으면 음수
