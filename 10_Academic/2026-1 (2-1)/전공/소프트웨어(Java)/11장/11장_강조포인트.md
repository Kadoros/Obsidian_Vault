# 11장. 강조포인트 ⭐

## 🔴 String은 불변, StringBuilder/Buffer는 가변 (제일 중요)
- String: 한번 생성하면 **고정(immutable)**
- StringBuilder/StringBuffer: **add/insert/append/delete 가능(가변)**
- StringBuffer = StringBuilder + **동기화(synchronized)**

## 🔴 regex 기본
- `Java.*` 의 `.*` = 임의 문자열 → `"Java is fun".matches("Java.*")` = true
- `[$+#]` = 그룹 중 **하나**
- `replaceAll`, `replaceFirst`, `split`이 regex와 함께 쓰임

## 🔴 indexOf 핵심
- 못 찾으면 **-1** (빨강)
- **대소문자 구분** → `indexOf("java")`는 "Java"를 못 찾아 -1
- 두 번째 인자 = 시작 위치, `lastIndexOf`는 뒤에서

## 🔴 valueOf
- String의 **static** 메소드, **overloading**
- `String.valueOf(5.44)` → "5.44"

## 🔴 palindrome 알고리즘
- low/high 양 끝에서 좁혀가며 `charAt` 비교
- 응용: `Character.isLetterOrDigit`로 영숫자만 필터 후 reverse 비교

## 🔴 Command-Line Parameters
- `java TestMain arg0 arg1` → `args[0]="arg0"`, `args[1]="arg1"`
- main도 그냥 일반 메소드

## 🟥 헷갈림 주의
- `matches`(패턴) vs `equals`(정확히 동일)
- Java 문자열 안에서 `\d`는 `"\\d"`로 써야 함
