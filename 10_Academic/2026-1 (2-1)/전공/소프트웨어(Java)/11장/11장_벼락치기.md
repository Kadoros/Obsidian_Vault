# 11장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> String은 **불변**, StringBuilder/Buffer는 **가변**. regex로 match/replace/split, indexOf는 없으면 **-1**.

## 무조건 외울 것
1. String **immutable** / StringBuilder **mutable** / StringBuffer = Builder + **동기화**
2. regex: `.*`=임의문자열, `[$+#]`=셋 중 하나, `\\d`=숫자
3. `replaceAll`/`replaceFirst`/`split` = regex와 함께
4. `indexOf` 못 찾으면 **-1**, **대소문자 구분**
5. `java Main arg0 arg1` → `args[0]`, `args[1]`

## StringBuilder 메소드
append / insert / delete / deleteCharAt / reverse / replace / setCharAt

## palindrome
```java
int low=0, high=s.length()-1;
while(low<high){ if(s.charAt(low)!=s.charAt(high)) return false; low++; high--; }
return true;
```

## valueOf
- String의 static, overloading. `String.valueOf(5.44)` → "5.44"

## 함정
- `matches`(패턴 검사) ≠ `equals`(정확히 같음)
- `indexOf("java")` 는 "Java"를 못 찾음(-1)
