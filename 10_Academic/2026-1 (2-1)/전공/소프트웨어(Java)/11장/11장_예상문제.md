## 💻 코드 분석

**10.** 다음 isPalindrome의 동작을 설명하시오.
```java
int low = 0, high = s.length() - 1;
while (low < high) {
  if (s.charAt(low) != s.charAt(high)) return false;
  low++; high--;
}
return true;
```
> [!success]- 정답
> 문자열의 양 끝(low, high)에서 한 글자씩 비교하며 안쪽으로 좁혀간다. 한 쌍이라도 다르면 false, 끝까지 같으면 회문이므로 true. 시간복잡도 O(n/2).
