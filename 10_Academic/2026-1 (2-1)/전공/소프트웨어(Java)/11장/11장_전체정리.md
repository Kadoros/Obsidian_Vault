# 11장. String (2) — 전체정리

> String의 "심화편"이다. ① 패턴으로 문자열을 다루는 **정규표현식(regex)**, ② 위치 찾기·형 변환 같은 **유용한 메소드들**, ③ String의 한계를 보완하는 **가변 버전(StringBuilder/StringBuffer)**, ④ 마지막으로 main의 **명령줄 인자**까지가 한 묶음이다.

## 1. Regular Expression (정규표현식)

특정 **패턴의 문자열**로 다른 문자열을 조작(match, replace, split)할 수 있게 해주는 강력한 도구다. 그 패턴을 적는 문자열을 **regular expression(regex)**이라 부른다. 초보자에겐 복잡하니, 강의에서는 자주 쓰는 패턴 몇 개만 본다.

```java
"Java".matches("Java");           // true — 패턴과 일치하나?
"Java".equals("Java");            // true — 정확히 같은 문자열인가?
"Java is fun".matches("Java.*");  // true — Java로 시작하면 OK
"Java is cool".matches("Java.*"); // true
```

여기서 `matches`와 `equals`의 차이를 분명히: **`equals`는 글자 그대로 같은지**, **`matches`는 패턴에 맞는지**를 본다.

### 자주 쓰는 기호
- `.*` = 아무 문자나 0개 이상 (그래서 `Java.*`는 "Java로 시작하는 모든 문자열")
- `[$+#]` = `$`, `+`, `#` 중 **하나** (대괄호 = "이 그룹 중 하나")
- `\\d` = 숫자, `\\w` = 단어 문자 (Java 문자열 안에서 `\`는 `\\`로 써야 함)

### replaceAll / replaceFirst / split
regex와 함께 쓰는 대표 메소드 3종.

```java
// 1) replaceAll: 패턴에 맞는 모든 부분 교체
String s = "a+b$#c".replaceAll("[$+#]", "NNN");
// $, +, # 각각이 NNN으로 → 결과: aNNNbNNNNNNc

// 2) split: 패턴을 기준으로 잘라서 배열로
String[] tokens = "Java,C?C#,C++".split("[.,:;?]");
// . , : ; ? 중 아무거나를 구분자로 → [Java, C, C#, C++]

// 3) 기타 예
"Java Java Java".replaceAll("v\\w", "wi");    // v + 단어문자 → wi (모두)
"Java Java Java".replaceFirst("v\\w", "wi");  // 첫 번째만
"Java1HTML2Perl".split("\\d");                // 숫자 기준 → [Java, HTML, Perl]
```

## 2. 문자/부분문자열 위치 찾기 (indexOf / lastIndexOf)

```java
"Welcome to Java".indexOf('W')        // 0   — 맨 앞이라 0
"Welcome to Java".indexOf('x')        // -1  — 없으면 -1 (★)
"Welcome to Java".indexOf('o', 5)     // 9   — 5번 위치부터 검색
"Welcome to Java".indexOf("come")     // 3   — 부분문자열도 가능
"Welcome to Java".indexOf("Java", 5)  // 11
"Welcome to Java".indexOf("java", 5)  // -1  — 대소문자 구분! (★)
"Welcome to Java".lastIndexOf('a')    // 14  — 뒤에서부터 찾기
```

핵심 규칙 세 가지:
1. 못 찾으면 **-1** 반환.
2. 두 번째 인자는 **검색 시작 위치**.
3. **대소문자를 구분**한다 ("java" ≠ "Java").

## 3. valueOf — 숫자/문자를 String으로

String class에는 **static** `valueOf` 메소드들이 있다. 이름은 다 `valueOf`로 같지만 인자 타입(`char`, `char[]`, `double`, `long`, `int`, `float`)이 다른 **method overloading**이다.

```java
String.valueOf(5.44);   // double 5.44 → "5.44"
```
- 결과는 `'5'`, `'.'`, `'4'`, `'4'`로 이루어진 **String형** 데이터. (숫자 5.44가 아니라 문자열 "5.44"가 된다는 점이 포인트.)

## 4. Palindrome (회문) 예제

앞에서 읽으나 뒤에서 읽으나 같은 문자열. **양 끝에서 가운데로 좁혀오며** 비교하는 게 정석 알고리즘.

```java
public static boolean isPalindrome(String s) {
  int low = 0;                  // 첫 글자 인덱스
  int high = s.length() - 1;    // 마지막 글자 인덱스
  while (low < high) {
    if (s.charAt(low) != s.charAt(high))
      return false;             // 한 쌍이라도 다르면 회문 아님
    low++; high--;              // 안쪽으로 한 칸씩
  }
  return true;
}
```
시간복잡도는 O(n/2). 중간에서 만나면 끝.

## 5. Character Class

`char`를 객체로 감싸는 wrapper 클래스. char에 대해 객체스러운 작업이 필요할 때 쓴다.

```java
Character charObject = new Character('b');
charObject.compareTo(new Character('a'));  // 1   (b > a)
charObject.compareTo(new Character('b'));  // 0   (같음)
charObject.compareTo(new Character('c'));  // -1  (b < c)
charObject.compareTo(new Character('d'));  // -2
charObject.equals(new Character('b'));     // true
charObject.equals(new Character('d'));     // false
```
- `compareTo`: 같으면 0, 크면 양수, 작으면 음수.
- 유용한 **static 메소드**: `Character.isLetterOrDigit(c)`, `isLetter(c)`, `isDigit(c)` 등 — 문자 종류 판별에 자주 쓴다.

## 6. StringBuilder / StringBuffer

String의 가장 큰 한계: **immutable(불변)**이다. 한번 만들면 내용을 못 바꾼다(바꾸면 새 객체가 생김). 이걸 보완하는 게 StringBuilder/StringBuffer.

- String이 쓰이는 거의 모든 곳에서 대체 가능.
- String과 달리 **가변(mutable)** — 같은 객체에 add/insert/append/delete를 할 수 있다.

```java
StringBuilder sb = new StringBuilder("Welcome to Java");
sb.append("Java");                  // 끝에 붙이기
sb.insert(11, "HTML and ");         // 11번 위치에 끼워넣기
sb.delete(8, 11);                   // 8~10번 삭제
sb.deleteCharAt(8);                 // 8번 한 글자 삭제
sb.reverse();                       // 통째로 뒤집기
sb.replace(11, 15, "HTML");         // 11~14를 HTML로
sb.setCharAt(0, 'w');               // 0번 글자 하나 교체
```
- 기타: `toString()`, `capacity()`, `length()`, `setLength()`, `charAt()`.

### Palindrome 응용 — 비-영숫자 무시
StringBuilder의 `reverse()`를 활용해 더 깔끔하게 회문 검사를 할 수 있다. 공백·기호는 빼고 영숫자만 비교.

```java
public static boolean isPalindrome(String s) {
  String s1 = filter(s);            // 영숫자만 남김
  String s2 = reverse(s1);          // 뒤집음
  return s2.equals(s1);             // 같으면 회문
}
public static String filter(String s) {
  StringBuilder sb = new StringBuilder();
  for (int i = 0; i < s.length(); i++)
    if (Character.isLetterOrDigit(s.charAt(i)))   // 영숫자만
      sb.append(s.charAt(i));
  return sb.toString();
}
public static String reverse(String s) {
  return new StringBuilder(s).reverse().toString();
}
```

### 책임 분리(Separating responsibilities) 관점
- **String**: 불변 문자열
- **StringBuilder**: 가변 문자열 (단일 스레드용, 빠름)
- **StringBuffer**: StringBuilder와 거의 같지만 **동기화(synchronized)** 기능 포함 (멀티스레드 안전)

→ 같은 "문자열"을 다루지만 역할을 셋으로 나눈 것. (12장 클래스 설계 지침과 연결되는 예시다.)

## 7. main도 그냥 보통 메소드 + Command-Line Parameters

- `main`이라고 특별한 게 아니라 **일반 메소드**다. 다른 메소드가 인자를 넘겨 호출할 수도 있다.
- 프로그램을 실행할 때 **명령줄에서 인자**를 받을 수 있다:
  ```
  java TestMain arg0 arg1 arg2 ... argn
  ```
- main 안에서 `args[0]`, `args[1]`, …, `args[n]`이 각각 명령줄의 `arg0`, `arg1`, …, `argn`과 **순서대로 대응**한다. (모두 String 타입으로 들어옴.)

```java
class TestMain {
  public static void main(String[] args) {
    // args[0] == "arg0", args[1] == "arg1" ...
  }
}
```

## 정리 — 이 장의 핵심 한 줄
> 패턴 작업은 **regex**(match/replace/split), 위치는 **indexOf(없으면 -1)**, 문자열을 자주 바꿔야 하면 **불변 String 대신 가변 StringBuilder/StringBuffer**.
