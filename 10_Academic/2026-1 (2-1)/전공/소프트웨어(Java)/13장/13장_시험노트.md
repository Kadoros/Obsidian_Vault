# 13장. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **inheritance** | superclass의 속성/method를 subclass가 물려받아 확장(extends). private 제외 |
| **super** | 상위 클래스 객체 지칭. 생성자 호출, 상위 method/변수 접근 |
| **overriding** | subclass가 superclass의 메소드를 재정의(같은 signature) |
| **polymorphism** | 하나의 참조가 실행 시 여러 type 객체로 동작 |
| **dynamic binding** | 호출할 메소드 구현을 runtime에 JVM이 결정 |
| **instanceof** | 객체가 특정 class의 instance인지 검사하는 연산자 |

## extends 의미 (★)
- A extends B = A는 B에 추가 → **A가 더 구체적, 더 좁은 의미**
- subclass ⊂ superclass (의미적), subclass가 superclass 코드 포함(코드적)

## super 규칙
1. 생성자 호출: `super(...)` — **반드시 첫 문장**
2. 상위 member 접근: `super.method()`
3. super 명시 안 하면 **no-arg super() 자동 호출**
4. 상위 객체 먼저 생성 → 하위 생성

## Constructor Chaining
- new 하면 상속 사슬의 **모든 상위 생성자 호출**
- 실행 완료 순서: **최상위(Object쪽)부터 → 아래로**
- superclass에 no-arg 없고 super 명시 안 하면 **컴파일 에러**

## Overriding 주의 (단골)
- **private** method → override 불가 (별개 메소드 = 추가)
- **static** method → override 불가 (상속은 됨, 같은 이름이면 hidden)
- instance method는 superclass의 static을 override 불가

## Overriding vs Overloading
| | signature | 관계 | 의미 |
|---|---|---|---|
| Overriding | 같음 | 상속 | 재정의 |
| Overloading | 다름(인자) | 같은/무관 | 추가 정의 |

## Object class
- 모든 class의 root. 상속 지정 안 하면 Object가 superclass
- `toString()` 기본 = `이름@16진수` → override 권장
- `equals()` 기본 = `this == obj` (참조 비교) → 내용 비교하려면 override

## == vs equals()
- `==`: primitive 값 또는 **같은 참조** 검사 (더 강함)
- `equals()`: **내용** 검사 (재정의 가능)

## Casting
- up-casting(자식→부모): **암시적, 안전**
- down-casting(부모→자식): **명시적 캐스팅 필요**, 실제 그 타입일 때만 OK
- `instanceof`로 확인 후 캐스팅

## Polymorphism / Dynamic Binding / Generic
- matching = compile time(인자), binding = runtime(구현 결정)
- JVM은 가장 **구체적인 class(C1)부터** 위로 구현 탐색, 처음 발견 호출
- generic: 형식 인자가 superclass면 subclass 객체 전달 가능

## ArrayList
- 크기 가변 객체 배열. `add/get/set/remove/size/contains`

## GenericStack<E>
- parameterized type → **type-safe** (`s.push(2)` on `<String>` = error)

## protected / final
- 접근 범위: **private < default < protected < public**
- protected: 같은 package + 다른 package의 subclass
- subclass는 접근성 **약화 불가**(좁히기 X)
- final: class(상속불가)/변수(상수)/method(override 불가)
