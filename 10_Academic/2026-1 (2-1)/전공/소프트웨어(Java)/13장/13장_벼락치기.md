# 13장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> subclass extends superclass(**private 제외 상속**). `super`로 상위 생성자/멤버 접근. 메소드 실행은 **runtime에 동적 결정**(dynamic binding).

## 무조건 외울 것
1. 상속 = private 빼고 다, **extends = 더 구체/좁음**
2. `super(...)` 상위 생성자 호출, **반드시 첫 줄**, 상위 객체 먼저
3. **constructor chaining**: 최상위 생성자부터 실행
4. override 불가: **private, static**
5. **up-casting 암시적 / down-casting 명시적** (`(Student)o`)

## == vs equals
- `==` 참조/값, `equals` 내용(override 가능). Object 기본 equals = `this==obj`

## Overriding vs Overloading
- Overriding: 같은 signature, 상속, 재정의
- Overloading: 다른 인자, 추가

## Object class
- 모든 class의 root, 기본 toString = `이름@16진수`

## Dynamic Binding 한 줄
- 호출 메소드를 runtime에 JVM이 C1(구체)→상위 순으로 찾아 결정

## ArrayList
- 가변 배열: `add / get / set / remove / size / contains`

## Generic
- `GenericStack<String>` 에 `push(2)` → error (type-safe)

## final
- class 상속불가 / 변수 상수 / method override 불가

## 함정
- superclass에 no-arg constructor 없으면 subclass에서 **에러** (super 명시 필요)
