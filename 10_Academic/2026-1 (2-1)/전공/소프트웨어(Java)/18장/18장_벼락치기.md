# 18장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> try-catch로 잡고 throws로 넘긴다. **Unchecked(Runtime/Error)는 강요 X, Checked는 강요 O**. finally는 **항상 실행**.

## 무조건 외울 것
1. **Unchecked = RuntimeException + Error** (강요 X) / **Checked = 나머지** (강요 O)
2. **throws**(선언) / **throw**(발생) / **try-catch**(처리)
3. **finally는 항상 실행** (rethrow해도 먼저 실행)
4. Catch-or-Declare: checked는 잡거나 throws
5. **Exception=robustness, Assertion=correctness**

## 예외 계층
- Throwable → Error / Exception → RuntimeException / 그 외

## 키워드 예
```java
void m() throws IOException { ... }       // 선언
throw new IllegalArgumentException("..."); // 발생
try{...}catch(E e){...}finally{...}        // 처리
```

## if vs Exception
- exception: **method 경계 넘어** + **예상 못 한 상황** 처리
- 단순/예상 상황은 **if** (남용 금지)

## Assertion
- `assert 조건 : msg;` → 실패 시 AssertionError
- 기본 disable, `java -ea`로 enable

## 함정
- NullPointer, IndexOutOfBounds = **unchecked**
- assertion은 exception 대체 ❌
