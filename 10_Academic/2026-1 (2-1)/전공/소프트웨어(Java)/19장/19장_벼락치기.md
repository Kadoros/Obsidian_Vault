# 19장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> Binary I/O는 byte↔byte(**변환 없음**). File stream을 **Data/Buffered/Object stream으로 감싸서** 쓴다. 객체 저장은 **Serializable**.

## 무조건 외울 것
1. text(문자 seq) vs binary(byte seq), 199 → '1''9''9' vs C7
2. Text I/O = encoding/decoding O, Binary I/O = **변환 없음**
3. stream wrapper: `new DataInputStream(new FileInputStream(...))`
4. Data(primitive/string) / Buffered(속도) / Object(객체)
5. 객체 저장 = **Serializable**(marker), 제외는 **transient**

## Stream 역할
- File~ : file 결합
- Data~ : primitive/string ↔ byte
- Buffered~ : 속도 향상(새 method 없음)
- Object~ : 객체 (writeObject/readObject)

## 주의
- 쓴 **순서·형식 그대로** 읽기 (writeUTF→readUTF)
- read() 끝 = **-1**, `available()==0` = EOF
- transient/static = 직렬화 안 됨, 아니면 NotSerializableException

## RandomAccessFile
- 임의 위치 read/write, 모드 `"rw"`/`"r"`
- file pointer: `seek()`, `getFilePointer()`

## UTF-8
- 1~3byte 가변, ASCII 1byte, html/xml 표준
