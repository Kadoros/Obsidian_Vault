## ⭕❌ OX 문제

**1.** Binary I/O는 입출력 과정에서 encoding/decoding 변환이 필요하다. (   )
> [!success]- 정답
> ❌ — Binary I/O는 byte↔byte로 변환이 없다. encoding/decoding은 Text I/O.

**2.** File 객체는 그 자체로 파일 입출력을 수행한다. (   )
> [!success]- 정답
> ❌ — File 객체는 file/path의 property만 갖는다. 입출력은 별도 I/O 객체가 한다.

**3.** Serializable은 구현할 메소드가 있는 interface이다. (   )
> [!success]- 정답
> ❌ — method 없는 marker interface. implements만 하면 된다.

**4.** transient로 표시된 field는 직렬화에서 제외된다. (   )
> [!success]- 정답
> ⭕ — static field도 직렬화되지 않는다.

**5.** RandomAccessFile은 임의 위치에서 읽고 쓸 수 있다. (   )
> [!success]- 정답
> ⭕ — sequential file과 달리 file pointer를 이동(seek)해 임의 접근한다.

## 🔤 빈칸 채우기

**6.** 10진수 199는 text file에서 ____ byte, binary file에서 ____ byte로 저장된다.
> [!success]- 정답
> 3 ('1','9','9') / 1 (C7)

**7.** primitive type과 string을 byte로 변환해 입출력하는 stream은 ________________ 이다.
> [!success]- 정답
> DataInputStream / DataOutputStream

**8.** read()가 stream의 끝에 도달하면 ____를 반환한다.
> [!success]- 정답
> -1

## 📝 단답·서술형

**9.** text file과 binary file의 차이를 예와 함께 설명하시오.
> [!success]- 정답
> text file은 문자의 sequence로 사람이 읽을 수 있고, binary file은 byte의 sequence로 program이 해석한다. 예로 10진수 199는 text에서 '1','9','9' 세 문자(3byte)로, binary에서 16진수 C7 한 byte로 저장된다. Java의 .class도 binary file이다.

**10.** Buffered stream을 쓰는 이유와 특징을 쓰시오.
> [!success]- 정답
> 버퍼를 사용해 I/O 속도를 높인다. 새로운 메소드를 추가하지 않고 InputStream/OutputStream의 메소드를 그대로 상속해 쓴다. 보통 FileStream을 감싸 사용한다.

**11.** 객체가 직렬화되려면 어떤 조건이 필요한가? non-serializable field가 있으면?
> [!success]- 정답
> 클래스가 java.io.Serializable을 구현해야 한다. non-serializable한 instance field가 있으면 직렬화 시 NotSerializableException이 발생하므로, 그 field에 transient를 붙여 직렬화에서 제외해야 한다(static field도 직렬화되지 않음).

## 💻 코드 분석

**12.** 다음 Copy 코드의 동작을 설명하시오.
```java
int r;
while ((r = input.read()) != -1) {
  output.write((byte)r);
}
```
> [!success]- 정답
> input에서 한 byte씩 읽어 r에 담고, 파일 끝(-1)이 아니면 그 byte를 output에 쓴다. 이를 반복해 source를 target으로 복사한다. -1을 만나면 EOF이므로 반복을 멈춘다.

**13.** 다음에서 직렬화되는 field는?
```java
public class Foo implements java.io.Serializable {
  private int v1;
  private static double v2;
  private transient A v3 = new A();
}
```
> [!success]- 정답
> v1만 직렬화된다. v2는 static이라 제외, v3는 transient라 제외. (A가 non-serializable인데 v3에 transient가 없었다면 NotSerializableException 발생)
