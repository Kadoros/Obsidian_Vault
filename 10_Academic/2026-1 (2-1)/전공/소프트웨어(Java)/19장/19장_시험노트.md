# 19장. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **text file** | 문자의 sequence, 사람이 읽음 |
| **binary file** | bit(byte)의 sequence, program이 해석 (.class 등) |
| **InputStream/OutputStream** | 모든 binary I/O class의 base class (byte 단위) |
| **Serializable** | 객체를 stream에 쓸 수 있게 하는 marker interface |
| **RandomAccessFile** | 임의 위치에서 읽고 쓸 수 있는 file |

## Text vs Binary
- text: 199를 '1','9','9' 3문자로 / binary: C7 한 byte로
- Text I/O는 **encoding/decoding** 필요, Binary I/O는 **conversion 없음**(byte↔byte)

## File 객체
- file/path의 **property만** 보유. 실제 I/O는 별도 I/O 객체 생성

## Stream 계층 (★)
- **InputStream/OutputStream**: base, byte 단위
- **FileInputStream/FileOutputStream**: file과 결합 (없는 file 읽기 → FileNotFoundException, append 옵션)
- **FilterInputStream/OutputStream**: 중간 처리 base
- **DataInputStream/DataOutputStream**: primitive/string ↔ byte (wrapper로 감쌈)
- **BufferedInputStream/OutputStream**: 버퍼로 **속도 향상**, 새 method 없음
- **ObjectInputStream/OutputStream**: 객체까지 I/O

## Data Stream 주의 (★)
- 읽기/쓰기 **순서·형식 일치**해야 함 (writeUTF→readUTF)
- EOF 확인: `available() == 0`이면 끝 (넘으면 EOFException)
- read()는 끝에서 **-1** 반환

## UTF-8
- Unicode 2byte는 ASCII에 낭비 → UTF-8은 **1~3 byte 가변**
- ASCII 1byte, 웹문서(html/xml) 표준. `writeUTF`/`readUTF`

## Object I/O
- DataStream = primitive/string, **ObjectStream = 객체까지**
- `writeObject` / `readObject`

## Serializable (marker interface)
- 객체가 stream에 쓰이려면 구현 필요. method 없음 → 추가 코드 불필요
- **transient**: 직렬화 제외 (non-serializable field 무시). static도 직렬화 안 됨
- 둘 다 아닌 non-serializable field → NotSerializableException

## RandomAccessFile
- sequential file과 달리 임의 위치 read/write
- 모드: `"rw"`(읽기+쓰기), `"r"`(읽기)
- **file pointer**: 현재 위치. `seek(pos)`, `getFilePointer()`. readInt()는 4byte 이동
