# 19장. 강조포인트 ⭐

## 🔴 Text vs Binary (제일 기본)
- text: 199 → '1','9','9' (3 byte) / binary: 199 → C7 (1 byte)
- Text I/O는 **encoding/decoding 필요**, Binary I/O는 **변환 없음**(byte↔byte)
- .class는 binary file (JVM이 해석)

## 🔴 Stream wrapper 구조 (★)
```java
DataInputStream in =
  new DataInputStream(new FileInputStream("in.dat"));
BufferedInputStream b =
  new BufferedInputStream(new FileInputStream(file));
```
- 안쪽(File) + 바깥쪽(Data/Buffered/Object)로 **감싼다**

## 🔴 각 Stream 역할
- File~Stream: file과 결합
- Data~Stream: **primitive/string ↔ byte**
- Buffered~Stream: **속도 향상**(새 method 없음)
- Object~Stream: **객체까지** I/O

## 🔴 Data Stream 주의
- **순서·형식 일치** (writeUTF → readUTF)
- read()는 끝에서 **-1**, `available()==0`이면 EOF

## 🔴 Serializable = marker interface
- method 없음 → 추가 코드 없이 implements만
- **transient** = 직렬화 제외, **static**도 직렬화 안 됨
- non-serializable field가 transient도 아니면 → **NotSerializableException**

## 🔴 RandomAccessFile
- 임의 위치 read/write (sequential과 대비)
- 모드 `"rw"` / `"r"`
- **file pointer**: `seek()`, `getFilePointer()`, readInt() 후 4byte 이동

## 🟥 UTF-8
- Unicode 2byte 낭비 → UTF-8 **1~3byte 가변**, ASCII는 1byte
- html/xml 표준
