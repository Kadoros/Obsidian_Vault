# 1장. 시험노트 📝 (개념 정밀 정리)

## 용어 정의 (서술형 대비)

| 용어 | 정의 |
| --- | --- |
| **class** | 자료구조(data)와 함수(method)를 하나로 묶은 단위. `class = [data] + [func]`. Java 프로그램의 1등 시민. |
| **method** | class에 부속된 함수. 반드시 class 안에 존재. `ClassName.methodName()`으로 호출. |
| **캡슐화 (encapsulation)** | 자료구조와 함수를 class로 묶어 구조화하는 것. 함수 이름 충돌을 방지. |
| **JVM (Java Virtual Machine)** | Java interpreter가 프로그램을 수행하는 환경/방식. interpreter 안의 가상 머신. |
| **Byte code** | Java 컴파일러가 만들어내는 중간 코드. JVM의 기계어. interpreter가 해석. 이식성 제공. |
| **Method Overloading** | 같은 이름의 메소드를 여러 형태로 정의하고, 호출 시 인자 수·형으로 적합한 형태를 결정하는 것. |

## 핵심 비교: Java vs C

**프로그램 구성**
- C: `{ functions [+ data types] }` — 함수 중심, action-oriented
- Java: `{ classes }` — 클래스 중심, object-oriented

**1등 시민 차이 (가장 중요)**
- C: 함수가 1등 시민, 프로그램 = 함수들
- Java: class가 1등 시민, 함수는 2등급(method)
- → Java는 `FirstJava.main()`으로만 호출 가능

**문법 외 차이점**
- pre-processor 없음 / header file 없음 / String 타입 별도(char* 없음 → pointer 개념 없음) / public 등 제어자

## 실행 방식 3가지 비교

| 방식 | 예 | 특징 |
| --- | --- | --- |
| 컴파일 | C (`cc -o test test.c`) | 빠름, 실행파일 생성 |
| 인터프리터 | Python (`python test.py`) | 즉시 수행, 이식성, 보안 |
| 컴파일+인터프리트 | **Java** | `.java`→`.class`(바이트코드)→JVM 실행. 두 방식 장점 결합 |

**Java를 이 방식으로 만든 이유 (Why?)**
- Interpreter 장점: 즉시 수행, portability, security
- Compiler 장점: execution speed, preprocessing을 통한 SW공학적 장점(1차 오류 점검, strongly typed)

## 실행 우열 정리

| 항목 | 결과 |
| --- | --- |
| 실행 시 성능 | C > Java > Python |
| 실행 편의성 | Python > C ? Java |
| 프로그램 호환성 | Python > Java > C |
| 보안성 | Python = Java > C |
| 대형 프로그램 | Java = C > Python |

## Anatomy of a Java Program
Comments(주석) · Reserved words(예약어) · Modifiers(제어자) · Statements(구문) · Blocks(블록) · Classes(클래스) · Methods(메소드) · main method

**주석 3종**
- Line comment `//`
- Paragraph comment `/* */`
- javadoc comment `/** */` (문서화, Javadoc 명령으로 HTML 생성)

**Modifiers**: public, static, private, final, abstract, protected

**Blocks**: `{ }` 한 쌍이 컴포넌트를 묶어 블록 형성 (class block / method block)

**main method**: program entry point, interpreter가 호출
```java
public static void main(String[] args) { // Statements }
```
