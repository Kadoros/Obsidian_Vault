# 1장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> Java는 **class가 1등 시민**인 객체지향 언어이고, **컴파일+인터프리트(JVM/바이트코드)** 방식으로 실행된다.

## 무조건 외울 5가지
1. **C = 함수 1등 시민 / Java = class 1등 시민** (함수는 method라 부름)
2. **class = [data] + [func]** = 캡슐화(encapsulation)
3. **Java = compile + interpret**, `javac`→`.class`(바이트코드)→`java`로 JVM에서 실행
4. **JVM** = interpreter 안의 가상 머신, **Byte code** = JVM의 기계어(중간코드)→이식성
5. **Java, 1995, Sun**

## 비교표 암기 (순서 주의!)
- 성능: **C > Java > Python**
- 호환성: **Python > Java > C**
- 보안: Python = Java > C
- 대형 프로그램: Java = C > Python

## 패러다임 짝 맞추기
- Java → object-oriented, entity, event-driven
- C → action-oriented, procedural, control

## 명령어 흐름
```
javac FirstJava.java   → FirstJava.class 생성 (cf. gcc → a.out)
java FirstJava         → 실행 (sum = 55)
```
