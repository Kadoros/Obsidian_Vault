# 1장. 예상문제 ✏️

> 답은 `> [!success]- 정답` 토글 안에 숨김. 먼저 풀고 펼쳐서 확인.

## ⭕❌ OX 문제

**1.** Java에서는 함수가 1등 시민이고 프로그램은 함수들로 구성된다. (   )
> [!success]- 정답
> ❌ — 그건 C. Java는 **class가 1등 시민**, 함수는 method.

**2.** Java에는 pointer 개념과 header file이 없다. (   )
> [!success]- 정답
> ⭕ — String 타입을 별도로 제공해 char*가 불필요, header file·pre-processor도 없다.

**3.** 바이트코드는 CPU가 직접 실행하는 바이너리 코드이다. (   )
> [!success]- 정답
> ❌ — 바이트코드는 **JVM의 기계어(중간코드)**. JVM(interpreter)이 해석해서 실행한다.

**4.** Java는 컴파일과 인터프리트를 모두 사용한다. (   )
> [!success]- 정답
> ⭕ — `javac`로 컴파일 후 `.class`를 JVM이 인터프리트.

## 🔤 빈칸 채우기

**5.** `class = [____] + [____]`
> [!success]- 정답
> data + func (자료구조 + 함수) → 캡슐화(encapsulation)

**6.** Java 소스 `FirstJava.java`를 컴파일하면 `__________` 파일이 생기고, `________` 명령으로 실행한다.
> [!success]- 정답
> `FirstJava.class` / `java FirstJava`

**7.** Java는 ____년 ____사에서 발표했다.
> [!success]- 정답
> 1995년 / Sun

## 📝 단답·서술형

**8.** C와 Java의 "1등 시민" 차이를 설명하시오.
> [!success]- 정답
> C는 함수가 1등 시민으로 프로그램이 함수들로 구성된다. Java는 class가 1등 시민이고 함수는 class에 부속된 2등급(method)이다. 그래서 Java에서는 `main()`을 단독 호출할 수 없고 `FirstJava.main()`처럼 class를 통해서만 호출한다.

**9.** JVM과 Byte code를 각각 정의하시오.
> [!success]- 정답
> JVM: Java interpreter가 프로그램을 수행하는 환경/가상 머신. Byte code: Java 컴파일러가 만드는 중간코드로 JVM의 기계어이며, interpreter가 해석한다. 바이트코드 덕분에 다른 시스템에서도 실행 가능(이식성).

**10.** Java 실행 방식(compile+interpret)을 택한 이유를 인터프리터/컴파일러 장점으로 설명하시오.
> [!success]- 정답
> 인터프리터 장점(즉시 수행, portability, security)과 컴파일러 장점(execution speed, preprocessing을 통한 1차 오류 점검·strongly typed 등 SW공학적 이점)을 모두 취하기 위해.

**11.** 다음 항목별 C/Java/Python 우열을 쓰시오: 성능, 호환성, 대형 프로그램.
> [!success]- 정답
> 성능: C > Java > Python / 호환성: Python > Java > C / 대형 프로그램: Java = C > Python

**12.** Method Overloading이란 무엇이며 장점은?
> [!success]- 정답
> 같은 이름의 메소드를 인자 수·형을 달리해 여러 개 정의하고, 호출 시 인자에 맞는 것을 자동 선택하는 것. 어색한 이름을 따로 지을 필요 없고, 프로그램 관리가 편해진다.

## 💻 코드 분석

**13.** 아래에서 잘못된 점을 찾으시오.
```java
public class Welcome {
  public static void main(String[] args)
    System.out.println("Welcome to Java!");
}
```
> [!success]- 정답
> main 메소드의 **block을 여는 중괄호 `{`가 빠짐**. `main(String[] args) {` 가 되어야 한다.

**14.** 주석 3종류를 기호와 함께 쓰시오.
> [!success]- 정답
> `//` Line comment, `/* */` Paragraph comment, `/** */` javadoc comment
