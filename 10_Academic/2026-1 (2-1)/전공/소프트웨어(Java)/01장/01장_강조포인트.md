# 1장. 강조포인트 ⭐

> 교수님이 빨간 글씨/강조로 짚은 부분 = 시험에 나오는 곳

## 🔴 1등 시민 (가장 강조)
- **C에서는 함수가 1등 시민** → 프로그램이 함수들로 구성
- **Java에서는 class가 1등 시민. 함수는 class에 부속되는 2등급 → 이름도 method**
- 따라서 Java에서는 `main()`으로 못 부르고, **`FirstJava.main()`으로만 호출** 가능

## 🔴 class = [data] + [func]
- **class = functions + data type**
- Java는 자료구조와 함수를 한 곳에 묶음 → **캡슐화(encapsulation)**
- C는 프로그래머가 file로 구조화(?) → **캡슐화 안 됨** (함수 이름 충돌), 불완전한 구조화

## 🔴 프로그래밍 패러다임 대비 (영어 용어 그대로 암기)
- Java: **object-oriented / entity description / event-driven**
- C: **action-oriented / procedural description / control**

## 🔴 실행 방법 핵심
- Java = **compile + interpret** 혼합 방식
- **JVM** = Java interpreter 안에 있는 가상 머신
- **Byte code** = Java 컴파일러가 만드는 중간 코드, JVM의 기계어
- 중간코드라서 **다른 시스템에서도 실행 가능 (portability)**

## 🔴 연도 / 출처
- **Java, May 20, 1995, Sun** (연도 1995 빨간 강조)

## 🔴 Characteristics 중 강조된 것
- 빨강: **Object-Oriented**
- 파랑: **Interpreted, Architecture-Neutral, Portable**
- 초록: **Robust, Secure**

## 🔴 기타 강조 표시
- IDE 중 **Eclipse (Open Source by IBM)** 빨간 강조
- 이 강의/교재는 **J2SE 기준**
- javadoc comment: **`/**` 로 시작하여 `*/`로 끝남** (빨강)
- Modifiers 예: **public, static / private, final, abstract, protected** (빨강)
- Method Overloading 결론: **"정리하려고 하지 말라!", "결국 필요하게 된다."** (빨강)

## 🟥 초기 학습 단계 주의 (빨강 경고)
- 당분간 **C-style 프로그래밍**으로 학습 (Object-oriented 없음)
- 이 경우 Class = Action = 프로그램 Title(추상적 object)
- ⚠️ **일반적 Java 프로그래밍 스타일 아님** ← 빨강으로 경고
