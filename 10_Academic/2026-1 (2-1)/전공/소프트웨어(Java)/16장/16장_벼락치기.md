# 16장. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> **program = { (event, handler) }**. ① 이벤트(Source+Class) ② 처리(Interface대로 listener) ③ 등록(addXxxListener). 핸들러는 JVM이 **upcall**.

## 무조건 외울 것
1. Event-Driven **3단계**: 이벤트 명시 → 핸들러 구현(implements) → 등록
2. **ActionEvent – ActionListener – actionPerformed**
3. JButton→ActionEvent, Mouse→MouseEvent, Key→KeyEvent
4. **anonymous inner class** = 선언+생성 한번에, extends/implements 안 씀
5. `e.getSource()`로 어떤 source인지 확인

## 등록 예
```java
jbtOK.addActionListener(new ActionListener(){
  public void actionPerformed(ActionEvent e){ ... }
});
```

## Listener 짝
| Event | Listener | Handler |
|---|---|---|
| Action | ActionListener | actionPerformed |
| Item | ItemListener | itemStateChanged |
| Mouse | MouseListener | mousePressed… |
| Key | KeyListener | keyPressed/Typed |

## Mouse
- MouseListener(클릭류) + MouseMotionListener(drag/move)

## Timer
- `javax.swing.Timer(1000, listener)` → 1초마다 ActionEvent, animation

## 왜 Interface?
- handler를 JVM이 upcall → 약속(Interface) 준수 필요
