# 16장. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **event** | 사건 발생 시 프로그램에 보내는 신호(signal) |
| **event source** | event를 발생시키는 GUI 요소(객체) |
| **listener** | event를 처리하는 handler를 담은 객체. interface를 implements |
| **upcall** | 시스템(JVM)이 프로그램 쪽 handler를 거꾸로 호출하는 것 |
| **inner class** | 다른 class의 member로 정의된 class |
| **anonymous inner class** | 이름 없이 선언+생성을 한번에 하는 inner class |

## Event-Driven 3단계 (★ 핵심)
1. **어떤 이벤트** = Event Source + Event Class (예: jbtOK + ActionEvent)
2. **어떤 처리** = handler를 구현해 class화, 약속된 **Interface**대로 implements (JVM이 upcall하므로)
3. **연결/등록** = `source.addXxxListener(listener)`

## User Action → Event
- JButton → ActionEvent
- JCheckBox/JRadioButton/JComboBox → ItemEvent, ActionEvent
- JTextField(Enter) → ActionEvent
- Window → WindowEvent / Mouse → MouseEvent / Key → KeyEvent

## Event–Listener–Handler (★)
| Event | Listener | Handler |
|---|---|---|
| ActionEvent | ActionListener | actionPerformed |
| ItemEvent | ItemListener | itemStateChanged |
| WindowEvent | WindowListener | windowClosing 등 |
| MouseEvent | MouseListener | mousePressed/Clicked 등 |
| KeyEvent | KeyListener | keyPressed/Released/Typed |

## getSource()
- event 발생시킨 객체 확인 → 통합 listener에서 `if (e.getSource()==jbtNew)`

## Inner / Anonymous
- inner class: outer의 member/data 참조 가능, hiding, `Outer$Inner.class`
- anonymous: 이름 없음, extends/implements 안 씀, abstract 다 구현, `Outer$1.class`
```java
jbtOK.addActionListener(new ActionListener(){
  public void actionPerformed(ActionEvent e){ ... }
});
```

## Listener 정의 방법 5가지
별도 class / inner class / anonymous / 통합(getSource로 구분) / frame이 직접 implements(`this`)

## Mouse / Key
- MouseListener(pressed/released/clicked/entered/exited) + MouseMotionListener(dragged/moved)
- KeyListener: keyPressed/keyReleased/keyTyped, getKeyChar()/getKeyCode()

## Timer
- `javax.swing.Timer(주기, listener)` → 주기마다 ActionEvent, animation용
- `timer.start()`
