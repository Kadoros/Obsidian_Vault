   ```asm
   .data
   Arrb byte 12h,34h,56,78h   Arrw word 1202h,7865h   Arrd dword 12345678h
   .code
   Mov ax, word ptr [arrb+2]   Mov al, byte ptr dword   Mov eax, dword arrw
   ```
   - data 영역에서 memory가 어떻게 잡히는지 그리기
   - 각 mov에 대해 레지스터 값이 어떻게 변하는지 쓰기
   - code segment가 필요한 이유를 서술
8. runtime stack을 이용해서 procedure를 부르고 push 하는 과정 그리기, 서술
9. stack을 응용하는 법 4가지

> ※ 문제 번호는 원본과 일치하지 않을 수 있습니다. 교수님이 문제에 별로 신경을 안쓰시는 듯 하지만 매번 새로운 문제가 나옵니다.. 조심하세요 ZEROPAGE

1. Scan Code에 대해 쓰시오 (2줄 이하)
2. 그림을 그려서 Disk의 SEEK을 설명하시오
3. Keyboard Stroke가 발생했을 때, CPU가 처리하는 과정을 설명하고, 그림도 그리시오.
4. CapsLock Key를 Control키와 같이 눌렀을 때만 실행되게 하는 법을 서술하시오.
5. 인터럽트가 발생했을 때, 원하지 않는 작업이 실행되는 것을 알려주는 방법을 제안하시오.
6. 다음 Code는 1부터 n까지의 합을 구하는 SumAll 프로시저이다. 물음에 답하시오.
   단, Main Procedure의 EBP는 00000240h라고 가정한다.

   ```asm
   EIP        명령
              INCLUDE Irvine32.inc   ; ZEROPAGE
              .code                  ; ZEROPAGE
              main PROC
   00173730   push 3
   00173732   call SumAll
   00173737   call DumpRegs
   0017373C   exit
              main ENDP

              SumAll PROC
   00173743   push ebp
   00173744   mov  ebp, esp
   00173746   mov  eax, [ebp+①8]
   00173749   cmp  eax, 1
   0017374C   ja   L1
   0017374E   mov  eax, 0
   00173753   jmp  L2
              L1:
   00173755   dec  eax
   00173756   push eax
   00173757   ④call SumAll
   0017375C   add  eax, [ebp+②8]
              L2:
   0017375F   pop  ebp
   00173760   ⑤ret ③4
              sumAll ENDP
              END main
   ```
   1) 다음의 빈 칸을 채우시오  ①_______  ②_______  ③_______
   2) ④번 명령어가 처음 실행된 후, ESP와 EIP를 각각 쓰시오.
      EIP: 00173743 ESP: 00000234h
   3) ⑤번 명령어가 처음 실행된 후, ESP와 EIP를 각각 쓰고, Stack Frame을 그리시오.
      EIP: 0017375Ch   ESP: 00000228h
   ```
   [Stack Frame 빈칸]
   0000023Ch [00000003h]
   00000238h [00173737h]
   00000234h [00000240h]
   00000230h [00000002h]
   0000022Ch [00017375C]
   00000228h [00000234h]
   00000224h []
   00000220h []
   0000021Ch []
   ```
