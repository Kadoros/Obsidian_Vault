## 📷 사진 1 — 기말고사 / 23년 1학기 수강자 (👍104 👎3)

**시험 전략**
> 오픈북이어서 피피티를 이해하는 데에 집중을 많이 했습니다. INT 21 부분을 좀 열심히 팠는데 그부분은 하나도 안 나왔고, stack이랑 keyboard 처럼 되게 이론 기초적인 것들 많이 물어보셨어요 피피티가 설명이 조금 약해서, 구글링 하시면서 FSM도형들이 각각 세부적으로 뭘 의미하는지 등등 찾아보시면서 공부하셔야 제대로 쓸 수 있었던 것 같아요. 특히 레지스터들이 각각 무슨 값을 가질 수 있고, 스택 관련 레지스터들이 어떻게 작동하는지 잘 파악하시는 게 중요한 것 같아요. 이렇게 하니까 A+ 받았습니다. 세부 성적은 공개를 안 하셔서 잘 모르겠어요
>
> 문제 수는 굉장히 적고, 시험 볼 수 있는 시간이 많아서 시간 부족할 일은 절대 없습니다. 그래도 웬만하면 시험 시간 다 쓰면서 검토하시는 걸 추천드려요

**문제 유형**: 논술형

**문제 예시**
- 주민등록번호 (000000-0000000)을 받는 FSM을 그리시오. (여기서 재귀를 쓰시면 안됩니다. 6개의 숫자를 받고 '-'를 받고 7개의 숫자를 받아야 하기 때문에 start부터 총 14개의 state를 만드셔야 해요)
- 해당 코드를 보고 EBP의 값이 변화대는 대로 빈칸에 채우시오 (코드가 길지는 않았고, 재귀함수 호출 문제였습니다. 재귀호출은 2번 일어났어요. 초기 EBP, ESP값을 알려주셔서 어렵진 않았어요. 스택 한 칸이 4byte인 거 아셔야 합니다)
- keyboard data table (shift 누르면 값 바뀌고, alt 누르면 바뀌...)

## 📷 사진 2 — 기말고사 / 24년 1학기 수강자 (👍84 👎1)

**시험 전략**
> 족보에서 거의 그대로 나오거나 유형은 같고 물어보는것만 약간 달라져서 나옵니다. 족보 열심히 보고가시는거 추천해요

**문제 유형**: 주관식, 약술형

**문제 예시**
- FSM을 만드는데 여기서 아무 핵사데시멀을 입력 받아서 저장 할수 있도록 설계하라.
- 뭉쳐있는 데이터에서 하나의 데이터를 담은 클러스터가 떨어져 있을때 이의 주소를 이어주는 것을 영어로 쓰시오 (FAT)
- 핵사데시멀 숫자를 왼쪽 루프 비트 연산자로 이동 시켰을때의 값.
- 아무 키가 입력으로 들어왔을때 Num Lock을 토글하는 FSM의 다이어그램을 그리고(1), 이를 단계별로 설명하라(2).
- 위 루프와 PROC가 포함된 코드가 돌기 이전 ESP와 EBP의 값은 다음과 같다. 해당 코드를 돌렸을때의 ESP값의 변화를 모두 적으시오.
- Suggest new Instruction (끝. 더 안적혀있음)

**문제 유형**: 논술형

**문제 예시**

- 해당 코드를 보고 EBP의 값이 변화대는 대로 빈칸에 채우시오 (코드가 길지는 않았고, 재귀함수 호출 문제였습니다. 재귀호출은 2번 일어났어요. 초기 EBP, ESP값을 알려주셔서 어렵진 않았어요. 스택 한 칸이 4byte인 거 아셔야 합니다)

## 📷 사진 4 — 기말고사 / 25년 1학기 수강자 (👍2 👎1)

**시험 전략**
> 약자 최대한 다 외우고 가시고 구하실 수 있는 모든 족보는 다 정리하고 답도 외워서 가시면 도움 마니 됩니다! 저는 그렇게 해서 거의 다 푼 것 같아요. 시험정보도 많이 참고했는데 자주 나온 new Instruction이런 문제는 제가 새롭게 아무 명령어나 만드는건데 족보에 여러 번 나왔길래 이것도 생각해갔어요. 시험시간은 문제8문항에 비해 너무 넉넉합니다

**문제 유형**: 객관식, 주관식, T/F형, 논술형

**문제 예시**
- IRQ의 약자
- 어셈블리어에 대해서 3문장으로 서술하시오
- value, reference 관련 t/f
- shl shr 쉬프트 문제
- suggest new intruction

## 📷 사진 5 — 기말고사 / 25년 1학기 수강자 (👎4)

**시험 전략**
> 그냥 내용 다 정리해서 외워가시는게 좋습니다. 어차피 기말범위 다 정리해도 a4 2페이지도 안나옵니다. 인터럽트는 개념만 나오고 세부적인 건 안나옵니다. ppt에 나오는 용어들은 다 풀네임을 외워가셔야 합니다. '새로운 ~~를 제안하시오' 라는 문제가 중간 기말 모두 출제되었으니, 시험 전에 생각해보시고 가는 걸 추천합니다. 시험 시간이 많아서 시험장 가서 보고 생각해도 괜찮습니다.

**문제 유형**: 주관식, T/F형

**문제 예시**
- 새로운 instruction 제안
- 코드를 주고 EBP 변화 계산 (칸은 많은데 EBP가 어떻게 변하는지만 쓰시면 됩니다.)
- rotation 계산문제
- IRQ 풀네임 (Interrupt Request levels까지 적었는데, Interrupt Request 중에 뭐가 답인지는 모르겠습니다.)
