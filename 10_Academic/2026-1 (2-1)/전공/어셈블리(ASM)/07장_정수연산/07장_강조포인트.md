# 07장 시프트/로테이트 — 강조포인트 ⭐

## 🔥 무조건
1. **논리 시프트 = 0 채움 / 산술 시프트 = 부호 비트 채움.**
2. **SHL = ×2ⁿ**, **SHR = ÷2ⁿ(부호 없음)**, **SAR = ÷2ⁿ(부호 있음, 부호 보존)**.
3. **SAL ≡ SHL** (완전히 같다).
4. 모든 시프트/로테이트 빠진 비트는 **CF**로 들어간다.

## 🔑 로테이트 4종 구분
| 명령 | 방향 | 회전 경로 |
|------|------|-----------|
| ROL | 좌 | MSB → CF **및** → LSB (8비트 회전) |
| ROR | 우 | LSB → CF **및** → MSB |
| RCL | 좌 | CF → LSB, MSB → CF (**CF 거침, 9비트**) |
| RCR | 우 | CF → MSB, LSB → CF |

## 💡 시험 트릭
- `rol/ror reg, 4` → 바이트의 **상·하위 니블 교환**.
- **SHLD**: dest 좌로, 빈자리는 source **MSB**로 채움.
- **SHRD**: dest 우로, 빈자리는 source **LSB**로 채움. (source는 안 변함)

## ⚠️ 자주 틀림
- 부호 있는 수 우측 시프트에 SHR 쓰면 ❌ → **SAR**.
- RCL/RCR은 CF를 한 칸 더 거치므로 같은 입력에서 ROL/ROR과 결과가 다르다.
