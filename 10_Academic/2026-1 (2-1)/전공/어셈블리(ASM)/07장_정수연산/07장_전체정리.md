## 1. 논리 시프트 vs 산술 시프트 (Logical vs Arithmetic)

| 구분 | 새로 생기는 비트 자리를 채우는 값 |
|------|----------------------------------|
| **논리 시프트 (Logical)** | **0** 으로 채움 |
| **산술 시프트 (Arithmetic)** | **부호 비트(sign bit)의 복사본**으로 채움 |

- 논리 시프트: 부호 없는 수에 사용.
- 산술 시프트: 부호 있는 수에 사용 — 시프트 후에도 **부호가 보존**됨.

## 2. 시프트 명령어

모든 시프트/로테이트의 **피연산자 형식**(동일):
```
SHL reg, imm8
SHL mem, imm8
SHL reg, CL          ; 시프트 횟수를 CL 레지스터에
SHL mem, CL
```

### SHL (Shift Left, 논리 좌측 시프트)
- 최하위 비트를 **0**으로 채움. 최상위 비트는 **CF**로 빠짐.
- **1비트 좌측 시프트 = ×2**, n비트 = **×2ⁿ**
```asm
mov dl, 5
shl dl, 1        ; DL = 10  (00000101 → 00001010)
shl dl, 2        ; ×4 → 5*4 = 20
```

### SHR (Shift Right, 논리 우측 시프트)
- 최상위 비트를 **0**으로 채움. 최하위 비트는 **CF**로 빠짐.
- **n비트 우측 시프트 = ÷2ⁿ** (부호 없는 나눗셈)
```asm
mov dl, 80
shr dl, 1        ; DL = 40
shr dl, 2        ; DL = 10
```

### SAL / SAR (산술 시프트)
- **SAL** (Shift Arithmetic Left) = **SHL과 완전히 동일**.
- **SAR** (Shift Arithmetic Right): 최상위 비트에 **부호 비트 복사** → 부호 보존. **부호 있는 ÷2ⁿ**.
```asm
mov dl, -80
sar dl, 1        ; DL = -40
sar dl, 2        ; DL = -10  (음수 유지)
```

> 🔑 우측 시프트 나눗셈: 부호 없으면 **SHR**, 부호 있으면 **SAR**. → [[07장_강조포인트]]

## 3. 로테이트 명령어 (비트가 사라지지 않음)

### ROL (Rotate Left)
- 각 비트를 좌로. **최상위 비트 → CF AND → 최하위 비트**로 동시에 복사. 비트 손실 없음.
```asm
mov al, 11110000b
rol al, 1        ; AL = 11100001b
mov dl, 3Fh
rol dl, 4        ; DL = F3h  (니블 교환 효과)
```

### ROR (Rotate Right)
- 각 비트를 우로. **최하위 비트 → CF AND → 최상위 비트**로 복사.
```asm
mov al, 11110000b
ror al, 1        ; AL = 01111000b
mov dl, 3Fh
ror dl, 4        ; DL = F3h
```
> 💡 `rol/ror dl, 4`는 바이트의 **상·하위 니블(4비트)을 교환**한다. 시험 단골.

### RCL (Rotate Carry Left) — 캐리를 포함한 9비트 회전
- **CF → 최하위 비트**, **최상위 비트 → CF**.
```asm
clc                ; CF = 0
mov bl, 88h        ; CF,BL = 0  10001000b
rcl bl, 1          ; CF,BL = 1  00010000b
rcl bl, 1          ; CF,BL = 0  00100001b
```

### RCR (Rotate Carry Right)
- **CF → 최상위 비트**, **최하위 비트 → CF**.
```asm
stc                ; CF = 1
mov ah, 10h        ; CF,AH = 1  00010000b
rcr ah, 1          ; CF,AH = 0  10001000b
```

> ⚠️ **ROL/ROR vs RCL/RCR 구분**: ROL/ROR는 빠진 비트가 곧바로 반대편으로(8비트 회전). RCL/RCR은 **CF를 거쳐** 회전(9비트 회전). → [[07장_시험노트]]

## 4. SHLD / SHRD (이중 정밀도 시프트)

두 피연산자를 결합해 시프트. **source는 변하지 않고**, dest만 바뀐다.
```
SHLD destination, source, count
SHRD destination, source, count
```
피연산자: `reg16/32` 또는 `mem16/32` (dest), `reg16/32` (source), `imm8/CL` (count).

### SHLD (좌측)
- dest를 좌로 count비트 시프트, 열린 하위 비트를 **source의 최상위(MSB) 비트들**로 채움.
```asm
mov al, 11100000b
mov bl, 10011101b
shld al, bl, 1   ; AL = 11000001b  (BL의 MSB '1'이 AL 최하위로)
```
**예제 2:**
```asm
.data
wval WORD 9BA6h
.code
mov ax, 0AC36h
shld wval, ax, 4   ; wval: 9BA6 → BA6A  (AX의 상위 4비트 'A'가 들어옴)
```

### SHRD (우측)
- dest를 우로 count비트 시프트, 열린 상위 비트를 **source의 최하위(LSB) 비트들**로 채움.
```asm
mov al, 11000001b
mov bl, 00011101b
shrd al, bl, 1   ; AL = 11100000b
```
**예제 2:**
```asm
mov ax, 234Bh
mov dx, 7654h
shrd ax, dx, 4   ; ax: 234B → 4234  (DX의 하위 4비트 '4'가 상위로)
```

> 🔑 SHLD는 source의 **윗부분**을, SHRD는 source의 **아랫부분**을 빌려 채운다. → [[07장_시험노트]]

## 5. 빠른 곱셈/나눗셈 정리

| 연산 | 명령 | 비고 |
|------|------|------|
| ×2ⁿ | `SHL`/`SAL` | 부호 무관 |
| ÷2ⁿ (부호 없음) | `SHR` | 0으로 채움 |
| ÷2ⁿ (부호 있음) | `SAR` | 부호 비트로 채움 |

> 시프트는 곱셈·나눗셈 명령보다 훨씬 빠르므로, 2의 거듭제곱 연산은 시프트로 최적화한다.

## 6. 자주 나오는 16진 계산 (Your turn 정답)
- `al=6Bh; shr al,1` → **35h**, 이어 `shl al,3` → **A8h**
- `al=8Ch; sar al,1` → **C6h**, 이어 `sar al,3` → **F8h** (부호 보존)
- `al=6Bh; ror al,1` → **B5h**, 이어 `rol al,3` → **ADh**
- `stc; al=6Bh; rcr al,1` → **B5h**, 이어 `rcl al,3` → **AEh**
- `ax=7C36h, dx=9FA6h; shld dx,ax,4` → DX=**FA67h**; `shrd dx,ax,8` → DX=**36FAh**
