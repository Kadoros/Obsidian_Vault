# 07장 시프트/로테이트 — 예상문제 ✍️

## Q1. 각 시프트 후 AL의 16진 값?
```asm
mov al, 6Bh
shr al, 1     ; a.
shl al, 3     ; b.
mov al, 8Ch
sar al, 1     ; c.
sar al, 3     ; d.
```
> **정답**: a. **35h**  b. **A8h**  c. **C6h**  d. **F8h**
> (8Ch는 음수이므로 sar이 부호 비트 1을 복제해 채움)

## Q2. 각 회전 후 AL의 16진 값?
```asm
mov al, 6Bh
ror al, 1     ; a.
rol al, 3     ; b.
```
> **정답**: a. **B5h**  b. **ADh**

## Q3. 캐리 회전. 각 단계 후 AL?
```asm
stc
mov al, 6Bh
rcr al, 1     ; a.
rcl al, 3     ; b.
```
> **정답**: a. **B5h**  b. **AEh**
> (CF=1로 시작; rcr이 CF를 MSB로 넣어 회전)

## Q4. SHLD/SHRD. DX 값은?
```asm
mov ax, 7C36h
mov dx, 9FA6h
shld dx, ax, 4   ; DX = ?
shrd dx, ax, 8   ; DX = ?
```
> **정답**: `shld dx,ax,4` → DX = **FA67h** (AX 상위 4비트 '7'이 DX 하위로)
> `shrd dx,ax,8` → DX = **36FAh** (AX 하위 8비트 '36'이 DX 상위로)

## Q5. (응용) 5에 7을 곱하지 않고 시프트+덧셈으로 5×10 만들기
> **정답**: 10 = 8 + 2 이므로 `x*10 = (x<<3) + (x<<1)`.
> ```asm
> mov eax, 5
> mov ebx, eax
> shl eax, 3       ; x*8
> shl ebx, 1       ; x*2
> add eax, ebx     ; x*10 = 50
> ```

## Q6. (개념) `dl=3Fh`에 `rol dl,4`를 하면? 왜 그렇게 되는가?
> **정답**: **F3h**. 3Fh = `0011 1111`을 4비트 좌측 회전하면 상·하위 니블이 교환되어 `1111 0011` = F3h.

## Q7. (서술) SAR로 −80을 8로 나누려면? 명령과 결과는?
> **정답**: ÷8 = ÷2³ → `sar dl, 3`. dl=−80 → `sar dl,3` = −10. (부호 보존됨)
