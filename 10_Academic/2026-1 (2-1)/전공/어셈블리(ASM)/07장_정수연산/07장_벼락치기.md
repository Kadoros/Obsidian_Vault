# 07장 시프트/로테이트 — 벼락치기 ⚡

## 한 표 요약
| 명령         | 동작         | 빈자리            | 효과          |
| ---------- | ---------- | -------------- | ----------- |
| SHL/SAL    | 좌 시프트      | LSB ← 0        | ×2ⁿ         |
| SHR        | 우 시프트      | MSB ← 0        | ÷2ⁿ (부호 없음) |
| SAR        | 우 시프트      | MSB ← 부호비트     | ÷2ⁿ (부호 있음) |
| ROL        | 좌 회전       | MSB→CF·LSB     | 비트 보존       |
| ROR        | 우 회전       | LSB→CF·MSB     | 비트 보존       |
| RCL        | 좌 회전(CF통과) | CF→LSB, MSB→CF | 9비트 회전      |
| RCR        | 우 회전(CF통과) | CF→MSB, LSB→CF | 9비트 회전      |
| SHLD d,s,n | d 좌시프트     | s의 **MSB**로 채움 | s 불변        |
| SHRD d,s,n | d 우시프트     | s의 **LSB**로 채움 | s 불변        |

## 피연산자 형식 (전부 공통)
`reg,imm8` / `mem,imm8` / `reg,CL` / `mem,CL`

## 빠른 암산
- 좌 시프트 = 2배씩, 우 시프트 = 절반씩
- `rol/ror x,4` = 니블 교환
- 음수는 `sar`로 나눠야 부호 유지

## 핵심 수치 예
- `6Bh shr 1` = 35h / `35h shl 3` = A8h
- `8Ch sar 1` = C6h / `C6h sar 3` = F8h
- `6Bh ror 1` = B5h / `rol 3` = ADh
