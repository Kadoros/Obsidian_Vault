# 07장 시프트/로테이트 — 시험노트 📝

> 비트 추적 문제(16진 변환)가 시험에 가장 많이 나온다. 손으로 직접 비트를 그려서 풀 것.

## ❗ 함정
1. **SHR vs SAR**: 부호 있는 수의 우측 시프트는 SAR(부호 비트 복제). SHR 쓰면 음수가 양수로 변함.
2. **ROL/ROR vs RCL/RCR**: 캐리 통과 여부. RCL/RCR은 CF가 회전 고리에 끼어 **총 (비트수+1)칸** 회전.
3. **SHLD/SHRD의 source는 변하지 않는다.** dest만 바뀐다. 채우는 비트 출처 헷갈림 주의:
   - SHLD → source **상위(MSB)** 비트
   - SHRD → source **하위(LSB)** 비트
4. **SAL = SHL**. 별개 동작 아님.

## 🧮 비트 추적 손풀이 절차 (8비트)
1. 16진 → 2진 8자리로 변환 (예: 6Bh = 0110 1011)
2. 명령에 따라 한 칸씩 이동, 빈자리 규칙대로 채움
3. 다시 16진으로

**검증 예시: `mov al,6Bh; shr al,1`**
- 6Bh = `0110 1011` → 우 1칸, MSB←0 → `0011 0101` = **35h** ✔ (CF=1)

**`shl al,3` (35h부터)**
- `0011 0101` 좌 3칸 → `1010 1000` = **A8h** ✔

**`mov al,8Ch; sar al,1`**
- 8Ch = `1000 1100`(음수), 우 1칸 MSB←1(부호) → `1100 0110` = **C6h** ✔

## 📐 회전 예제 검증
- `6Bh ror 1`: `0110 1011` → LSB '1' 이 MSB로 → `1011 0101` = **B5h**
- `B5h rol 3`: `1011 0101` 좌 3칸 회전 → `1010 1101` = **ADh**
- `rcl`/`rcr`은 시작 전 **CF 값**(clc/stc)을 반드시 확인하고 회전 고리에 포함.

## 💬 서술형
- **논리 vs 산술 시프트 차이**: 빈 비트를 0으로 채우면 논리, 부호 비트로 채우면 산술(부호 보존).
- **시프트로 곱·나눗셈하는 이유**: 전용 곱셈/나눗셈 명령보다 빠르다. 단 2의 거듭제곱에만 적용.
- **SHLD 활용**: 비트 단위 패킹/필드 조립, 다중워드 시프트 구현.
