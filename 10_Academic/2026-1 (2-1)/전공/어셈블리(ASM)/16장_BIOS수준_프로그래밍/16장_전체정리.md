## 1. PC-BIOS

- **BIOS** (Basic Input-Output System) = OS를 위한 **저수준 하드웨어 드라이버**.
  - **16비트 앱**에서 접근 가능, 당연히 **어셈블리로 작성**, 소스는 1980년대 초 IBM 공개.
- **MS-DOS 대비 장점**:
  - 그래픽·컬러 프로그래밍 가능
  - **더 빠른 I/O** 속도
  - 마우스·시리얼·패럴렐 포트 읽기
  - 저수준 디스크 접근

### BIOS 데이터 영역 (BIOS Data Area)
- 주소 **00400h(세그먼트 0040h)** 의 **고정 위치** 데이터 영역. MS-DOS도 사용.
- Windows 98/Me에서는 접근 가능, **Windows NT/2000/XP에서는 불가**.
- 내용: 시리얼·패럴렐 포트 주소, 하드웨어 목록·메모리 크기, **키보드 상태 플래그·버퍼 포인터·버퍼 데이터**, 비디오 하드웨어 설정, 타이머 데이터.
- 주요 오프셋(세그먼트 0040h 기준): `0000-0007` COM1-4, `0008-000F` LPT1-4, `0017-0018` 키보드 상태 플래그, `001E-003D` 키보드 typeahead 버퍼, `0049` 현재 비디오 모드.

## 2. INT 16h — 키보드 입력

### 키보드 동작 원리
1. 키 입력 → **스캔 코드(scan code)** 가 키보드 직렬 입력 포트로 전송.
2. 인터럽트 발생 → **INT 9h 서비스 루틴** 실행.
3. **스캔 코드 + ASCII 코드**가 키보드 **typeahead 버퍼**에 삽입.
4. 버퍼에서 INT 16h 핸들러(스캔+ASCII) 또는 INT 21h 핸들러(ASCII만)가 읽음.

> 💡 **스캔 코드 ≠ ASCII 코드**. 같은 키도 Normal/Shift/Ctrl/Alt에 따라 다른 스캔 코드. 화살표·F1~F12 등 비ASCII 키는 스캔 코드로만 식별. INT 21h로 읽으면 첫 읽기는 0 반환, 두 번째에 스캔 코드.

### 키보드 상태 플래그 (16비트, 0040:0017h~0018h)
| bit | 의미 | bit | 의미 |
|-----|------|-----|------|
| 0 | Right Shift down | 8 | Left Ctrl down |
| 1 | Left Shift down | 9 | Left Alt down |
| 2 | Either Ctrl down | 10 | Right Ctrl down |
| 3 | Either Alt down | 11 | Right Alt down |
| 4 | Scroll Lock on | 13 | Num Lock down |
| 5 | Num Lock on | 14 | Caps Lock down |
| 6 | Caps Lock on | 15 | SysReq down |
| 7 | Insert on | | |

### INT 16h 함수 (기능번호는 항상 AH)
MS-DOS보다 저수준 키보드 접근. 주요 기능: 타이프매틱 속도 설정, 키 푸시, **키 대기**, **버퍼 확인**, **키보드 플래그 얻기**.

**기능 10h — 키 대기 (Wait for Key)**: 버퍼에 키 있으면 즉시 반환, 없으면 **블록(대기)**. AH=스캔코드, AL=ASCII.
```asm
.data
scanCode  BYTE ?
ASCIICode BYTE ?
.code
mov ah, 10h
int 16h
mov scanCode, ah
mov ASCIICode, al
```

**기능 12h — 키보드 플래그 얻기**: BIOS 데이터 영역의 상태 플래그 복사본 반환(AX).
```asm
.data
keyFlags WORD ?
.code
mov ah, 12h
int 16h
mov keyFlags, ax
```

**기능 11h — 버퍼 확인 (typeahead)**: 키가 대기 중이면 **ZF=0**, 없으면 ZF=1. (키를 버퍼에서 제거하지 않음)
```asm
L1: mov ah, 11h
    int 16h
    jz  noKey          ; 키 없음
    mov ah, 10h        ; 있으면 버퍼에서 제거
    int 16h
    cmp ah, scanCode   ; 종료 키였나?
    je  quit
    jmp L1
noKey:
    or  al, 1           ; ZF 클리어
quit:
```

## 3. INT 10h — 비디오 프로그래밍

### 세 가지 비디오 접근 수준
| 수준 | 속도 | 호환 |
|------|------|------|
| MS-DOS 함수 호출 | 느림 | 모든 MS-DOS 머신 |
| **BIOS 함수 호출(INT 10h)** | 중간 | 거의 모든 MS-DOS 기반 |
| **직접 메모리 매핑 비디오** | 빠름 | 100% IBM 호환만 |

### 색상 제어 (Controlling the Color)
- 3원색 **R·G·B** 혼합 + **intensity(밝기) 비트**(4번째 채널).
- 예: R+G+B=light gray(0111), intensity+R+G+B=white(1111), G+B=cyan(0011), R+B=magenta(0101).
- **속성 바이트(attribute byte)**: **상위 4비트(MSB)=배경색, 하위 4비트(LSB)=전경색(글자색)**.

**속성 바이트 구성** — `(배경색 SHL 4) OR 전경색`:
```
파랑 배경 + 밝은 회색 글자 = (blue SHL 4) OR lightGray
빨강 배경 + 흰색 글자      = (red SHL 4) OR white
```
> 🔑 배경은 왼쪽 4비트로 시프트, 전경은 OR로 합친다. → [[16장_강조포인트]]

### INT 10h 비디오 함수 (AH = 기능번호)
| AH | 기능 |
|----|------|
| 00h | Set video mode (텍스트/그래픽 모드) |
| 01h | Set cursor lines (커서 모양) |
| **02h** | Set cursor position (커서 위치) |
| 03h | Get cursor position and size |
| **06h** | Scroll window up (위로 스크롤) |
| 07h | Scroll window down |
| 08h | Read character and attribute |
| **09h** | Write character and attribute |
| 0Ah | Write character (속성 없이) |
| 10h (AL=03h) | Toggle blinking/intensity bit |
| 0Fh | Get video mode |

### 컬러 문자 출력 (기능 09h)
```asm
mov si, OFFSET string
mov ah, 9            ; 문자+속성 출력
mov al, [si]         ; 출력할 문자
mov bh, 0            ; 비디오 페이지 0
mov bl, color        ; 속성(색상)
or  bl, 10000000b    ; blink/intensity 비트
mov cx, 1            ; 1번 출력
int 10h
```

### 화면 지우기 (Clrscr 프로시저)
**기능 06h(스크롤 업)로 전체 화면을 비우고, 02h로 커서를 (0,0)** 으로.
```asm
Clrscr PROC
    pusha
    mov ax, 0600h     ; AH=06 스크롤 업, AL=0 전체
    mov cx, 0         ; 좌상단 (0,0)
    mov dx, 184Fh     ; 우하단 (24,79)
    mov bh, 7         ; 일반 속성
    int 10h
    mov ah, 2         ; 커서 위치 설정
    mov bh, 0         ; 페이지 0
    mov dx, 0         ; 행 0, 열 0
    int 10h
    popa
    ret
Clrscr ENDP
```
> 💡 `dx=184Fh`: DH=18h(24)=하단 행, DL=4Fh(79)=우측 열. 표준 80×25 텍스트 화면.

## 5. 한 줄 요약
- **BIOS** = OS용 저수준 드라이버. MS-DOS보다 빠르고 그래픽/색상 가능.
- **INT 16h**: 키보드(스캔코드+ASCII). 10h 키대기, 11h 버퍼확인(ZF), 12h 플래그.
- **INT 10h**: 비디오. 속성 바이트 = (배경<<4)|전경. 02h 커서, 06h 스크롤, 09h 문자+속성.
- 키 입력 흐름: 키 → 스캔코드 → INT 9h → typeahead 버퍼 → INT 16h/21h.
