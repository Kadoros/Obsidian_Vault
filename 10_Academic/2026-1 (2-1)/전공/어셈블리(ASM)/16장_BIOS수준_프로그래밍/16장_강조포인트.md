# 16장 BIOS 수준 프로그래밍 — 강조포인트 ⭐

## 🔥 무조건
1. **BIOS = 저수준 하드웨어 드라이버**. MS-DOS보다 빠르고 그래픽·색상·마우스 가능.
2. **기능번호는 항상 AH**. INT 16h(키보드), INT 10h(비디오).
3. **속성 바이트 = (배경색 SHL 4) OR 전경색.** 상위 4비트=배경, 하위 4비트=전경.

## 🔑 INT 16h 키보드 (AH값)
| AH | 기능 |
|----|------|
| 10h | 키 대기 (AH=스캔코드, AL=ASCII), 없으면 블록 |
| 11h | 버퍼 확인 — 키 있으면 **ZF=0** (제거 안 함) |
| 12h | 키보드 플래그 얻기 (AX) |

- 키 입력 흐름: **키 → 스캔코드 → INT 9h → typeahead 버퍼 → INT 16h/21h**.
- **스캔코드 ≠ ASCII**. 화살표·F키는 스캔코드로만 식별.

## 🔑 INT 10h 비디오 (AH값)
| AH | 기능 |
|----|------|
| 00h | 비디오 모드 설정 |
| 02h | 커서 위치 설정 |
| 06h | 윈도우 위로 스크롤 (화면 지우기에 사용) |
| 09h | 문자+속성 출력 |
| 0Ah | 문자만 출력 |

## 💡 색상 (4비트)
- R+G+B=light gray(0111), +intensity=white(1111), G+B=cyan(0011), R+B=magenta(0101).
- 화면 지우기 **Clrscr**: 06h 스크롤(CX=0,0 / DX=184Fh=24행79열) + 02h 커서 (0,0).

## ⚠️ 함정
- 배경색은 **SHL 4** 후 OR. 그냥 더하지 않음.
- 11h는 버퍼에서 키를 **제거하지 않는다**(확인만). 제거는 10h.
