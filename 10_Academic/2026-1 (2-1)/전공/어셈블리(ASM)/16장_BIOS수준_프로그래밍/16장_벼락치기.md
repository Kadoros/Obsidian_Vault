# 16장 BIOS 수준 프로그래밍 — 벼락치기 ⚡

## BIOS 기본
저수준 하드웨어 드라이버. MS-DOS보다 빠름·그래픽·색상·마우스. 기능번호 항상 **AH**.

## 비디오 접근 3수준
MS-DOS(느림·범용) < BIOS INT 10h(중간) < 직접 메모리매핑(빠름·IBM호환만).

## INT 16h 키보드 (AH)
| AH | 동작 |
|----|------|
| 10h | 키 대기 → AH스캔/AL ASCII |
| 11h | 버퍼 확인 (키 있으면 ZF=0) |
| 12h | 플래그 → AX |

키 흐름: 키→스캔코드→INT 9h→typeahead버퍼→INT 16h(스캔+ASCII)/21h(ASCII).

## INT 10h 비디오 (AH)
| AH | 동작 |
|----|------|
| 00h | 비디오 모드 |
| 02h | 커서 위치 |
| 06h | 스크롤 업 |
| 09h | 문자+속성 |
| 0Ah | 문자만 |

## 색상 속성 바이트
**속성 = (배경 SHL 4) OR 전경.** 상위4=배경, 하위4=전경.
- 0111 회색, 1111 흰색(+intensity), 0011 cyan, 0101 magenta.

## Clrscr 공식
06h 스크롤(AX=0600h, CX=0, DX=184Fh, BH=7) + 02h 커서(0,0).
- 184Fh = 24행(DH=18h), 79열(DL=4Fh).
