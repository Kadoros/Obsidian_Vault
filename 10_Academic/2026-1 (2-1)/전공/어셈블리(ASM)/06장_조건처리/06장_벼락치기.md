# 06장 조건 처리 — 벼락치기 ⚡ (5분 컷)

> 시험 직전 이것만. 표 위주.

## 비트 명령어
`AND`(끄기/마스크) · `OR`(켜기) · `XOR`(토글, 0초기화) · `NOT`(반전) · `TEST`(검사만, 결과 버림)

## CMP → 점프 (제일 중요)
| 부호없음 | 부호있음 | 동등 |
|---|---|---|
| JA (>) | JG (>) | JE/JZ (=) |
| JAE (≥) | JGE (≥) | JNE/JNZ (≠) |
| JB (<) | JL (<) | |
| JBE (≤) | JLE (≤) | |

**A/B = unsigned, G/L = signed.** 끝.

## 조건부 루프 (ECX−1 후)
- `LOOPE/LOOPZ`: ECX>0 **and ZF=1** → 점프
- `LOOPNE/LOOPNZ`: ECX>0 **and ZF=0** → 점프

## IF/WHILE/AND/OR 번역
- **IF**: 조건 거짓 → 건너뛸 곳 점프, then 끝에 `jmp`로 else 스킵
- **WHILE**: `top: cmp / jcond next / 본문 / jmp top / next:`
- **AND**: 거짓이면 탈출 — 연산자 뒤집어 `jbe next` 연속
- **OR**: 참이면 `ja L1`로 실행 점프, 둘 다 거짓이면 `jbe next`

## 테이블 기반 선택
값+주소 테이블 → 루프로 `cmp al,[ebx]` → 일치 시 `call NEAR PTR [ebx+1]`

## FSM
상태=노드, 입력=엣지. 시작/수락/중간. 부호정수: **부호 뒤 숫자 필수**, 각 상태는 `cmp`+`je`로 전이.
