# 06장 조건 처리 — 예상문제 ✍️

> 정답은 각 문제 아래 `> 정답:` 토글식으로. 직접 풀고 확인.

## Q1. 다음 의사코드를 어셈블리로 (부호 없는 정수)
```
if( ebx <= ecx )
{
    eax = 5;
    edx = 6;
}
```
> **정답**
> ```asm
>     cmp ebx, ecx
>     ja  next        ; ebx > ecx 면 건너뜀
>     mov eax, 5
>     mov edx, 6
> next:
> ```

## Q2. 32비트 부호 있는 정수 버전
```
if( var1 <= var2 )
    var3 = 10;
else { var3 = 6; var4 = 7; }
```
> **정답**
> ```asm
>     mov eax, var1
>     cmp eax, var2
>     jle L1          ; signed!
>     mov var3, 6
>     mov var4, 7
>     jmp L2
> L1: mov var3, 10
> L2:
> ```
> 함정: `<=` 부호 있음이므로 `jle` (jbe 아님).

## Q3. 복합 AND (부호 없음)
```
if( ebx <= ecx && ecx > edx )
{ eax = 5; edx = 6; }
```
> **정답**
> ```asm
>     cmp ebx, ecx
>     ja  next        ; 첫 조건 거짓 → 탈출
>     cmp ecx, edx
>     jbe next        ; 둘째 조건 거짓 → 탈출
>     mov eax, 5
>     mov edx, 6
> next:
> ```

## Q4. WHILE 루프 (부호 없는 32비트)
```
while( ebx <= val1 ) { ebx = ebx + 5; val1 = val1 - 1; }
```
> **정답**
> ```asm
> top: cmp ebx, val1
>      ja  next       ; 거짓이면 탈출
>      add ebx, 5
>      dec val1
>      jmp top
> next:
> ```

## Q5. LOOPE를 써서 배열의 첫 **0이 아닌** 값 찾기 (없으면 ESI가 sentinel 가리킴)
```asm
.data
array SWORD 50 DUP(?)
sentinel SWORD 0FFFFh
.code
    mov esi, OFFSET array
    mov ecx, LENGTHOF array
L1: cmp WORD PTR [esi], 0
    ; (여기 채우기)
quit:
```
> **정답**
> ```asm
> L1: cmp WORD PTR [esi], 0
>     pushfd                 ; 플래그 보존
>     add esi, TYPE array
>     popfd
>     loope L1               ; 0인 동안(ZF=1) 계속
>     jz  quit               ; 끝까지 0이면 못 찾음
>     sub esi, TYPE array    ; ESI를 찾은 값으로 되돌림
> quit:
> ```

## Q6. (서술) 다음 FSM이 부호 정수 인식에 부적합한 이유?
> A → (+,−) → B, A →(digit)→ B, B →(digit)→ B 구조 (수락 상태 B 하나).
>
> **정답**: B가 부호만 받은 직후에도 수락 상태가 되어, **부호만 있고 숫자가 없는 입력**(`+`, `-`)을 정수로 잘못 수락한다. 올바른 FSM은 부호 뒤 별도 상태에서 **숫자를 반드시 한 번 이상** 받아야 수락하도록 한다.

## Q7. (개념) `TEST al, 1` 이 검사하는 것은?
> **정답**: AL의 **최하위 비트(bit 0)** 가 1인지. 즉 **홀수/짝수** 판별. 결과는 저장하지 않고 ZF만 세팅(ZF=1이면 짝수).
