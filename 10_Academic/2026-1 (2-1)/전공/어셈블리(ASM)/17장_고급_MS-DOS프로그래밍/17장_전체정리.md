## 1. 개요 — 인터럽트 핸들러 (ISR)

- **인터럽트 핸들러(interrupt handler = ISR, Interrupt Service Routine)**: 공통 I/O 작업을 수행.
  - **함수처럼 호출** 가능 (`INT n`)
  - **하드웨어 이벤트로 활성화** 가능
- 예: 비디오 출력 핸들러, 크리티컬 에러 핸들러, 키보드 핸들러, **0으로 나눔(divide by zero) 핸들러**, Ctrl-Break 핸들러, 시리얼 포트 I/O.

### 인터럽트 벡터 테이블 (IVT)
- 각 엔트리 = ISR을 가리키는 **32비트 세그먼트:오프셋 주소**.
- **오프셋 = 인터럽트번호 × 4** (각 엔트리 4바이트).
> 🔑 INT 9의 벡터는 IVT 오프셋 `9×4 = 36 = 24h`에 위치. → [[17장_강조포인트]]

---

## 2. 하드웨어 인터럽트 (Hardware Interrupts)

- **Intel 8259 PIC (Programmable Interrupt Controller)** 가 하드웨어 신호에 응답해 생성.
- **IRQ (Interrupt Request Levels)**:
  - 우선순위 기반 인터럽트 스케줄러
  - 동시 인터럽트 요청을 중재(broker)
  - **낮은 우선순위가 높은 우선순위를 인터럽트하지 못하게** 함.

### 자주 쓰는 IRQ 할당
| IRQ | 장치 | IRQ | 장치 |
|-----|------|-----|------|
| 0 | System timer | 8 | CMOS real-time clock |
| 1 | Keyboard | 9 | modem/video/network/sound/USB |
| 2 | PIC | 12 | mouse |
| 3 | COM2 (serial) | 13 | Math coprocessor |
| 4 | COM1 (serial) | 14 | Hard disk controller |
| 5 | LPT2 (printer) | 10,11,15 | (available) |
| 6 | Floppy disk controller | | |
| 7 | LPT1 (printer) | | |

## 3. 인터럽트 제어 명령어 (STI / CLI)

| 명령 | 의미 | 용도 |
|------|------|------|
| **STI** | Set Interrupt flag (IF=1) | **외부 인터럽트 활성화**. 인터럽트 핸들러 **시작 부분에 항상** 실행 |
| **CLI** | Clear Interrupt flag (IF=0) | **외부 인터럽트 비활성화**. 인터럽트되면 안 되는 **크리티컬 코드 직전**에 사용, **시스템 타이머도 정지** |

> ⚠️ CLI를 오래 켜두면 타이머·키보드 등이 멈추므로 짧은 구간에만 사용. → [[17장_시험노트]]

## 4. 커스텀 인터럽트 핸들러 작성

### 동기 (Motivations)
- 기존 핸들러 **동작 변경**, **버그 수정**, **특정 키보드 명령 차단으로 보안 강화**.

### 무엇이 필요한가 (What's Involved)
1. 새 핸들러 작성
2. 메모리에 로드
3. **IVT 엔트리 교체**(우리 핸들러를 가리키도록)
4. 보통 **기존 인터럽트 핸들러로 체이닝(chain)**.

### 인터럽트 벡터 얻기 — INT 21h 기능 35h
기존 핸들러의 세그먼트:오프셋 주소를 **ES:BX**로 반환.
```asm
.data
int9Save LABEL WORD
DWORD ?                  ; 기존 INT 9 주소 저장
.code
mov ah, 35h              ; 인터럽트 벡터 얻기
mov al, 9                ; INT 9
int 21h
mov int9Save, BX         ; 오프셋 저장
mov [int9Save+2], ES     ; 세그먼트 저장
```

### 인터럽트 벡터 설정 — INT 21h 기능 25h
**DS:DX**가 가리키는 새 핸들러를 설치.
```asm
mov ax, SEG kybd_rtn     ; 새 핸들러 세그먼트
mov ds, ax
mov dx, OFFSET kybd_rtn  ; 오프셋
mov ah, 25h              ; 인터럽트 벡터 설정
mov al, 9h               ; INT 9h
int 21h
;...
kybd_rtn PROC            ; 새 핸들러 시작
```

### 키보드 처리 단계 (인터셉트 흐름)
1. 키 누름 → 바이트가 키보드 포트로 전송.
2. **8259 컨트롤러가 CPU를 인터럽트**, 인터럽트 번호 전달.
3. CPU가 IVT 9h 엔트리를 조회, 그 주소로 분기.
4. **우리 핸들러가 실행**, 키보드 바이트를 가로챔(intercept).
5. 우리 핸들러가 **기존 INT 9 핸들러로 점프**.
6. INT 9h 핸들러가 끝나고 복귀.
7. 시스템 정상 처리 계속.

## 5. Ctrl-Break 핸들러 예제 (INT 23h)

- Ctrl-Break를 누르면 기본 **INT 23h** 핸들러가 현재 프로그램을 **종료** → 파일이 열린 채, 메모리 미해제 등 불안정 상태 가능.
- 자신의 코드를 INT 23h에 설치하면 **종료를 막을 수 있다**.
```asm
install_handler:
    push ds                    ; DS 보존
    mov  ax, @code
    mov  ds, ax                ; DS를 코드 세그먼트로
    mov  ah, 25h               ; 인터럽트 벡터 설정
    mov  al, 23h               ; INT 23h
    mov  dx, OFFSET break_handler
    int  21h
    pop  ds
L1: mov  ah, 1                 ; 키 대기·에코
    int  21h
    cmp  al, 1Bh               ; ESC?
    jnz  L1
    exit

break_handler PROC             ; Ctrl-Break 시 실행, 모든 레지스터 보존
    push ax
    push dx
    mov  dx, OFFSET breakMsg
    call WriteString
    pop  dx
    pop  ax
    iret                       ; ← 인터럽트 복귀는 IRET
break_handler ENDP
```
> 🔑 인터럽트 핸들러는 **레지스터를 모두 보존**하고 **IRET**로 복귀한다(RET 아님).

## 6. TSR (Terminate and Stay Resident) 프로그램

- **TSR**: 메모리에 설치되어 **제거 프로그램이나 재부팅 전까지 상주**.
- 키보드 예:
  - **INT 9 벡터를 교체**해 우리 핸들러를 가리킴.
  - 우리 핸들러로 특정 **키 조합을 검사/필터**.
  - **기존 INT 9 핸들러로 전방 체이닝(forward-chain)** 해 정상 키보드 처리.

## 7. No_Reset 프로그램 (Ctrl-Alt-Del 막기)

- 들어오는 키마다 검사. **Del 키**가 오면 **Ctrl·Alt 키**를 확인하고, **Right Shift도 눌려야만** 시스템 리셋 허용.
- 키보드 상태 바이트(0040:0017h) 비트: 0=Right Shift, 1=Left Shift, 2=Ctrl, 3=Alt, 4=Scroll, 5=Num, 6=Caps, 7=Insert.

```asm
.code
rt_shift  EQU 01h    ; Right shift: bit 0
ctrl_key  EQU 04h    ; Ctrl: bit 2
alt_key   EQU 08h    ; Alt: bit 3
del_key   EQU 53h    ; DEL 스캔 코드
kybd_port EQU 60h    ; 키보드 입력 포트

int9_handler PROC FAR
    sti                      ; 하드웨어 인터럽트 활성화
    pushf                    ; 레지스터·플래그 보존
    push es
    push ax
    push di

L1: mov  ax, 40h             ; BIOS 데이터 세그먼트 40h
    mov  es, ax
    mov  di, 17h             ; 키보드 플래그 위치
    mov  ah, es:[di]         ; 키보드 플래그를 AH로 복사

L2: test ah, ctrl_key        ; Ctrl 눌림?
    jz   L5                  ; 아니면 종료
    test ah, alt_key         ; Alt 눌림?
    jz   L5

L3: in   al, kybd_port       ; 키보드 포트 읽기
    cmp  al, del_key         ; Del?
    jne  L5
    test ah, rt_shift        ; Right shift?
    jnz  L5                  ; 눌렸으면 리셋 허용

L4: and  ah, NOT ctrl_key    ; Ctrl 비트 끄기 → 리셋 차단
    mov  es:[di], ah         ; 키보드 플래그 다시 저장

L5: pop  di                  ; 레지스터·플래그 복원
    pop  ax
    pop  es
    popf
    jmp  cs:[old_interrupt9] ; 기존 BIOS INT 9로 far 점프 (체이닝)
int9_handler ENDP
```
> 💡 핵심 트릭: Ctrl+Alt+Del인데 Right Shift가 없으면 **Ctrl 비트를 꺼서** BIOS가 리셋을 인식하지 못하게 한 뒤, 기존 핸들러로 체이닝. → [[17장_예상문제]]

## 8. 한 줄 요약
- **ISR/IVT**: 핸들러 = ISR, IVT 엔트리 = 세그먼트:오프셋, 오프셋 = INT번호×4.
- **8259 PIC + IRQ**: 우선순위 기반 하드웨어 인터럽트 중재.
- **STI/CLI**: 인터럽트 활성/비활성. 핸들러는 STI로 시작.
- **35h/25h**: 벡터 얻기(ES:BX)/설정(DS:DX). 핸들러는 레지스터 보존 + IRET.
- **TSR**: 상주하며 인터럽트 가로채고 기존 핸들러로 체이닝.
