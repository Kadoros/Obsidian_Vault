# 08장 고급 프로시저 — 벼락치기 ⚡

## 프레임 한 장
```
+param2  [ebp+12]
+param1  [ebp+8]
+ret     [ebp+4]
 EBP     [ebp]   ←EBP
-local1  [ebp-4]
-local2  [ebp-8] ←ESP
```
서두 `push ebp; mov ebp,esp; sub esp,n` / 마무리 `mov esp,ebp; pop ebp; ret`

## 파라미터 전달
- 값: `push 값` → 프로시저는 `[ebp+8]`로 읽음
- 참조: `push OFFSET 변수` → 주소가 들어감

## 정리 주체
- **C 규약**: 호출자가 `add esp,n`
- **stdcall**: 피호출자가 `ret n`

## 명령/지시어 등가
| 쓰면 | 같은 동작 |
|------|-----------|
| `enter 8,0` | push ebp / mov ebp,esp / sub esp,8 |
| `leave` | mov esp,ebp / pop ebp |
| `USES ecx edx` | push ecx,edx ... pop edx,ecx |
| `LOCAL x:DWORD` | sub esp 공간 + [ebp-n] 매핑 |

## LEA vs OFFSET
- 상수 주소 → `OFFSET`
- 스택/지역변수 주소 → **`lea`** (OFFSET 불가)

## 재귀
- 자기 호출 = 사이클. base case 필수. 호출마다 새 프레임.
- factorial: `ret 4`로 파라미터 정리, 되돌아오며 `mul`.

## INVOKE/PROC/PROTO
- INVOKE proc, arg1, arg2 / ADDR로 주소
- PROC paramName:type
- PROTO = 시그니처 선언
