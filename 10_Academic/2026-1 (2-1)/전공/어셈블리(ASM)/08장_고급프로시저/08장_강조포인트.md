# 08장 고급 프로시저 — 강조포인트 ⭐

## 🔥 스택 프레임 구조 (제일 중요, 반드시 그릴 줄 알기)
```
[ebp+12]  두 번째 인수
[ebp+8]   첫 번째 인수
[ebp+4]   복귀 주소
[ebp]     저장된 EBP    ← EBP
[ebp-4]   지역변수 1
[ebp-8]   지역변수 2    ← ESP
```
- **파라미터 = [ebp+양수], 지역변수 = [ebp-양수]**
- 표준 서두: `push ebp` → `mov ebp,esp` → (`sub esp,n` 지역변수)
- **EBP = base/frame pointer**, 함수 중 불변, 복귀 시 복원.

## 🔑 호출 규약 (단골 비교)
| | 정리 주체 | 코드 |
|---|---|---|
| **C** | 호출자 | `add esp, n` |
| **STDCALL** | 피호출자 | `ret n` |

## 💡 꼭 외우는 것
1. **값 전달** = `push 값`, **참조 전달** = `push OFFSET 변수`.
2. **LEA vs OFFSET**: 스택 파라미터/지역변수 주소는 **LEA만** 가능 (OFFSET은 상수만).
3. **ENTER n,0** = `push ebp / mov ebp,esp / sub esp,n`.
   **LEAVE** = `mov esp,ebp / pop ebp`.
4. **USES** 연산자 = 레지스터 push/pop 자동 생성.
5. **LOCAL** 지시어는 PROC 바로 다음 줄.

## ⚠️ 재귀
- 자기 자신 호출 → 호출 그래프에 **사이클**. 각 호출이 **새 프레임** 사용(스택 소비).
- 반드시 **base case**(종료 조건)가 있어야 무한재귀 방지.
- 두 단계: 내려가며 호출 → 베이스에서 되돌아오며 계산.

## INVOKE/PROC/PROTO
- **INVOKE**: 여러 인수를 한 번에 전달(CALL 대체). `ADDR`로 주소 전달.
- **PROC paramList**: 이름 있는 파라미터. 여러 줄이면 `PROC,` 콤마 필수.
- **PROTO**: 프로시저 시그니처 선언(타입 검사).
