# 📊 족보 출제빈도 분석 — 기말고사 중심

> 2013·2015·2017·2023 기출 + ZP 10년 모음 + 에타 후기(23/24/25)를 전부 대조해 **반복 주제**를 집계.
> ★ 개수 = 출제 빈도. **★★★ = 거의 매 시험, ★★ = 자주, ★ = 가끔/개념만.**

---

## 🥇 ★★★ 거의 매번 나옴 — 무조건 잡아야 함

### 1. FSM 그리기
| 출제처 | 문제 |
|--------|------|
| 2015 기말 | 부호 없는 정수 받는 FSM |
| 2023 기말 | 숫자6+`-`+숫자7 (주민번호) FSM |
| ZP 모음 | 16진수 FSM / 부호 있는 실수 FSM / 8자리 암호 FSM |
| 후기 24·25 | hex 입력 저장 FSM / Num Lock 토글 FSM |
> 👉 **주민번호·16진수·Num Lock** 세 패턴 직접 그려보기. [[06장_예상문제]]

### 2. 키보드 / Caps Lock·Shift 핸들러
| 출제처 | 문제 |
|--------|------|
| 2013 기말 | 키보드 입력 과정 도식 / LEFT SHIFT 고장 해결 |
| 2015 기말 | 조합키+알파벳 → 대문자 효과 |
| 2017 기말 | CapsLock + Ctrl 같이 눌렀을 때만 실행 |
| 2023 기말 | 키보드 입력 시 Caps Lock OFF 시키는 법 + 다이어그램 |
| ZP 모음 | 왼쪽 Shift 눌렀을 때만 Caps Lock ON / Home키 커서 이동 |
| 후기 | keyboard data table (shift·alt 의미) |
> 👉 키보드 플래그 비트 + interrupt handler 수정 패턴. [[16장_강조포인트]] · [[17장_전체정리]]

### 3. EBP / ESP 스택 변화 (코드 빈칸·추적)
| 출제처 | 문제 |
|--------|------|
| 2017 기말 | SumAll 프로시저 빈칸 `[ebp+①]`·`ret ③` + ESP/EIP + Stack Frame 그리기 |
| 2023 기말 | 기존 족보 + ebp 변화 |
| ZP 모음 | 계승 프로시저 스택프레임 도식 / 빈칸 채우기 |
| 무년도2 | 1~n 더하는 스택프레임 빈칸 / 스택 쌓이는 그림 |
| 후기 23·25 | EBP 변화 계산 (재귀 2번, 4byte 칸) |
> 👉 **2017 SumAll 문제를 직접 풀어볼 것** (이번 시험 거의 동일 유형). [[08장_시험노트]]

## 🥈 ★★ 자주 나옴

### 4. Scan Code 설명
2013·2017·2023 기말 + 후기 → **"Scan Code가 뭔지 1~2줄"** 거의 고정. [[16장_전체정리]]

### 5. 새 명령어 제안 (Suggest new instruction)
2023 기말 + 후기(여러 번, *중간·기말 모두*). 미리 준비 안 하면 손해. **2~3개 외워가기.** [[00_시험전략_족보분석]] §4

### 6. 디스크 / 클러스터 / FAT
2013(클러스터)·2015(실린더)·ZP(단편화·Average Seek·DTA)·후기(FAT 영어로). [[15장_전체정리]]

### 7. 비트 연산 (ROL / SHL·SHR / AND)
ZP(비트이동 ×4)·2023중간(AND로 a→A)·후기(shl shr, rotation 계산). **16진 값 계산 연습.** [[07장_예상문제]]

## 🥉 ★ 가끔 / 개념만 (가볍게)

| 주제 | 출제처 | 메모 |
|------|--------|------|
| 인터럽트 HW/SW 비교, IVT, PIC | 2013·2015·ZP | **개념만** (후기: 세부 안 나옴) |
| INT 16h / INT 명령어 | ZP·후기 | 후기: "INT 21 팠는데 안 나옴" → 가볍게 |
| 스택 응용 4가지 | 무년도·ZP·무년도2 | 열거형 |
| 어셈블리어/어셈블러란 | 무년도·2023중간·후기 | 3문장 서술 |
| BIOS 데이터 영역 / BIOS vs Device Driver | 2013·무년도·ZP | 서술 |
| Macro vs Procedure | ZP | PPT 외 주제 |
| value/reference T/F | 후기 | T/F |
| 약어 풀네임 (IRQ 등) | 후기·2023 | 암기 [[00_시험전략_족보분석]] §5 |
