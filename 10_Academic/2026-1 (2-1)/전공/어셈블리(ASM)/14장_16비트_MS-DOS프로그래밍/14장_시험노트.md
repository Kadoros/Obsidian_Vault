# 14장 16비트 MS-DOS — 시험노트 📝

> 선형 주소 변환 계산 + INT 21h 기능번호 매칭이 핵심 출제.

## ❗ 함정
1. **선형 주소 계산에서 ×16 누락**: 세그먼트는 반드시 16배(왼쪽 시프트) 후 오프셋 더함. `08F1+0100` ❌ → `08F10+0100` ✔.
2. **09h 문자열은 `$` 종료**, null 종료 아님. `$` 없으면 메모리 끝까지 출력.
3. **01h vs 06h**: 01h는 에코O·대기O, 06h는 에코X·대기X(ZF로 검사). 폴링 루프엔 06h.
4. **716Ch 실패 판정은 CF**(`jc`), AX 값 아님.
5. **문자=DL(8비트), 문자열 주소=DX(16비트)**. 02h는 DL, 09h/40h는 DX.
6. 날짜/시간 반환 레지스터 혼동: 날짜 년은 **CX(16비트)**, 시간은 CH/CL/DH 각 8비트.

## 🧮 선형 주소 변환 절차
1. 세그먼트 16진수 끝에 `0` 추가 (×16).
2. 오프셋을 더한다.
3. 예: `1234:5678` → 12340 + 5678 = **179B8**.

## 📐 비교: 입력 함수
| AH | 에코 | 대기 | 검사 | 용도 |
|----|------|------|------|------|
| 01h | O | O | Ctrl-Break | 일반 문자 입력 |
| 06h | X | X | ZF | 폴링/게임 입력 |
| 0Ah | O | O | — | 버퍼(구조체) 입력 |
| 3Fh | — | — | Ctrl-Break | 파일/장치 블록 읽기 |

## 📊 비교: 출력 함수
| AH | 대상 | 종료 |
|----|------|------|
| 02h/06h | 표준 출력(문자) | — |
| 05h | 프린터(문자) | — |
| 09h | 표준 출력(문자열) | `$` |
| 40h | 파일/장치(문자열) | CX 길이 |

## 💬 서술형 대비
- **실주소 모드 특징 4가지**: 1MB 한계, 단일 태스킹, 메모리 보호 없음, 16비트 오프셋.
- **인터럽트 벡터링 과정**: INT n → IVT에서 핸들러 주소 조회 → 핸들러(ISR) 실행 → IRET로 복귀.
- **세그먼트:오프셋이 필요한 이유**: 16비트 레지스터로 1MB(20비트 주소)를 가리키려면 세그먼트(×16)+오프셋 조합 필요.
- **XOR 암호화 원리**: 같은 키로 두 번 XOR하면 원문 복원(대칭키).

## INT 21h 기능번호 암기표 (빈출)
종료 4Ch · 문자출력 02h · 문자열출력 09h · 파일쓰기 40h · 문자입력 01h/06h · 버퍼입력 0Ah · 파일읽기 3Fh · 날짜 2Ah · 시간 2Ch · 파일생성/열기 716Ch · 닫기 3Eh.
