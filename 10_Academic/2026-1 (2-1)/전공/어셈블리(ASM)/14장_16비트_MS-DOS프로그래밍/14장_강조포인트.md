# 14장 16비트 MS-DOS — 강조포인트 ⭐

## 🔥 무조건
1. **선형 주소 = 세그먼트 × 16 + 오프셋** (= 세그먼트 뒤에 16진 0 붙이고 오프셋 더함).
   - 예: `08F1:0100` → 08F10 + 0100 = **09010**.
2. **실주소 모드**: 최대 1MB, 단일 태스킹, 메모리 보호 없음, 오프셋 16비트.
3. **INT 21h 호출 패턴**: 기능번호 → **AH**, 부가인자 → AL/DL/DX, 그리고 `int 21h`.
4. **IVT**(주소 0번지)는 인터럽트 핸들러의 세그먼트:오프셋 주소 테이블. 핸들러=ISR, 복귀는 **IRET**.

## 🔑 INT 21h 기능번호 (AH값) 핵심
| AH | 기능 |
|----|------|
| 4Ch | 프로세스 종료 |
| 02h | 문자 출력 (DL=문자) |
| 09h | 문자열 출력 (**$** 종료, DS:DX=주소) |
| 40h | 문자열을 파일/장치에 (BX=핸들,CX=길이,DX=주소) |
| 01h | 문자 입력 (에코O, 대기O) |
| 06h | 문자 입력 (에코X, 대기X, **ZF로 검사**) |
| 0Ah | 버퍼 입력 (KEYBOARD 구조체) |
| 3Fh | 파일/장치에서 읽기 |
| 2Ah/2Ch | 날짜/시간 얻기 |

## 💡 자주 나오는 것
- **09h 출력 문자열은 반드시 `$`로 끝나야** 한다.
- **콘솔 핸들 = 1(또는 키보드 0)**, 40h/3Fh에서 BX에.
- 날짜: 2Ah → CX=년, DH=월, DL=일, AL=요일. 시간: 2Ch → CH=시, CL=분, DH=초.
- 파일 생성/열기 **716Ch**: BX=모드, CX=속성, DX=동작(10h=create,1=open,2=truncate), DS:SI=파일명. **실패 CF=1**.

## ⚠️ 함정
- 09h(문자열)는 DX, 02h(문자)는 DL. 레지스터 크기 혼동 주의.
- 06h는 ZF=1이면 입력 없음 / EOF. 01h는 무조건 대기.
