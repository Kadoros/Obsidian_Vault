# 14장 16비트 MS-DOS — 예상문제 ✍️

## Q1. `08F1:0100`의 선형(절대) 주소는?
> **정답**: 08F10 + 0100 = **09010h**.

## Q2. `1000:5678`의 선형 주소는?
> **정답**: 10000 + 5678 = **15678h**.

## Q3. 표준 출력에 문자 'A'를 출력하는 코드?
> **정답**
> ```asm
> mov ah, 02h
> mov dl, 'A'
> int 21h
> ```

## Q4. `$`로 끝나는 문자열을 표준 출력에 출력하는 코드?
> **정답**
> ```asm
> .data
> msg BYTE "Hello$"
> .code
> mov ah, 9
> mov dx, OFFSET msg
> int 21h
> ```

## Q5. 키가 눌릴 때까지 대기하지 않고 폴링하는 루프 (06h)?
> **정답**
> ```asm
> L1: mov ah, 06h
>     mov dl, 0FFh
>     int 21h
>     jz  L1          ; 입력 없으면 반복
>     mov char, al
> ```

## Q6. 새 파일을 읽기/쓰기로 생성(create+truncate)하는 코드와 실패 처리?
> **정답**
> ```asm
> mov ax, 716Ch
> mov bx, 2            ; read-write
> mov cx, 0            ; normal
> mov dx, 10h + 02h    ; create + truncate
> mov si, OFFSET Filename
> int 21h
> jc  failed          ; CF=1 → 실패
> mov handle, ax
> ```

## Q7. 시스템 날짜를 얻어 변수에 저장하는 코드 (2Ah)?
> **정답**
> ```asm
> mov ah, 2Ah
> int 21h
> mov year, cx        ; 년
> mov month, dh       ; 월
> mov day, dl         ; 일
> mov dayOfWeek, al   ; 요일
> ```

## Q8. (서술) INT 명령이 실행될 때 인터럽트 벡터링 과정을 설명하라.
> **정답**: ① `int n`이 IVT(주소 0번지의 벡터 테이블)에서 n번 엔트리를 참조. ② 그 엔트리에 저장된 세그먼트:오프셋 주소의 인터럽트 핸들러(ISR)로 점프. ③ 핸들러가 작업 수행. ④ `IRET`로 호출 프로그램의 다음 명령으로 복귀.

## Q9. (서술) 실주소 모드에서 세그먼트:오프셋 주소 방식을 쓰는 이유?
> **정답**: 16비트 레지스터 하나로는 64KB(2¹⁶)만 가리킬 수 있지만 1MB(2²⁰)를 주소 지정해야 하므로, 16비트 세그먼트(×16)와 16비트 오프셋을 조합해 20비트 선형 주소를 만든다.

## Q10. XOR 암호화 코드에서 복호화는 어떻게 하나?
> **정답**: 동일한 `XORVAL`로 다시 한 번 XOR한다. XOR은 대칭이므로 `(x XOR k) XOR k = x`로 원문 복원.
