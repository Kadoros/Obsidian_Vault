# 14장 16비트 MS-DOS — 벼락치기 ⚡

## 선형 주소 (1줄)
**선형 = 세그먼트×16 + 오프셋.** `08F1:0100` = 08F10+0100 = **09010**.

## 실주소 모드
1MB / 단일태스킹 / 보호없음 / 오프셋 16비트.

## INT 21h 치트시트 (AH값)
| AH | 동작 | 주요 레지스터 |
|----|------|---------------|
| 4Ch | 종료 | AL=반환코드 |
| 02h | 문자출력 | DL=문자 |
| 09h | 문자열출력 | DX=주소(**$**종료) |
| 40h | 파일에 쓰기 | BX핸들,CX길이,DX주소 |
| 01h | 문자입력(대기) | →AL |
| 06h | 문자입력(무대기) | DL=0FFh, ZF검사 |
| 0Ah | 버퍼입력 | DX=KEYBOARD구조체 |
| 3Fh | 파일읽기 | BX핸들,CX길이,DX주소 |
| 2Ah | 날짜 | CX년,DH월,DL일,AL요일 |
| 2Ch | 시간 | CH시,CL분,DH초 |

## 인터럽트
- IVT(0번지) = 핸들러 주소표. INT n → 핸들러(ISR) → IRET 복귀.
- Common: 10h비디오, 16h키보드, 17h프린터, 1Ah시간, 21h DOS.

## 파일 716Ch
BX=모드(0R/1W/2RW), CX=속성(0normal), DX=동작(1open/2trunc/10h create), DS:SI=파일명. 실패 **CF=1** → `jc failed`. 성공 AX=핸들.
