> 에브리타임 시험정보 후기 **5건**(23/24/25년 1학기, 추천 104·84···)을 종합한 출제경향. **이 노트를 먼저 보고 각 장 노트로 들어갈 것.**

## 1. 시험 형식 (후기 공통)

- **오픈북** (한 후기 기준). 단, 이해 없이 찾기만 하면 시간 부족.
- **문제 수 적고 시간 매우 넉넉** (약 8문항). "시험장 가서 보고 생각해도 됨."
- **문제 유형 혼합**: 객관식 · 주관식 · **T/F형** · **논술/약술형**.
- **기말 범위 정리하면 A4 2페이지도 안 됨** → 양 적음, 깊이로 승부.
- **족보에서 거의 그대로 / 유형 같고 살짝 변형** → 족보 암기가 최강 전략.

## 4. 🔥 "새 명령어 제안" 공략 (필수 준비)

> 후기: *"여기가 굉장히 핵심… mov/sub/add 같은 걸 의미. 재귀함수 호출 최대 수를 지정하는 함수 호출 instruction을 만들고, 작동 방식과 사용 가능한 내용까지 썼습니다. (5C3 계산 시 팩토리얼 함수를 3번만 호출하는 예시)"*

### 답안 작성 틀 (이 5요소를 채워라)
1. **명령어 이름 & 문법(syntax)**: `CALLMAX dest, count` 처럼.
2. **무슨 문제를 해결하나** (동기): 기존 mov/add/call로는 불편한 점.
3. **동작(logic)**: 의사코드로 단계 서술.
4. **영향받는 플래그/레지스터/스택**.
5. **사용 예제** (실제 코드 1개).

### 모범답안 예시 A — 재귀 깊이 제한 명령어 (후기 그대로)
```
명령어:  CALLN  procedure, n      ; 최대 n번까지만 재귀 호출
동기:    재귀함수가 무한 호출로 스택 오버플로 나는 것을 막기 위해
동작:    내부 카운터가 현재 호출 깊이를 추적.
         호출 깊이 < n 이면 procedure를 call,
         깊이 == n 이면 호출하지 않고 즉시 return.
영향:    스택에 깊이 카운터 1개 추가, ZF로 "한계 도달" 표시.
예제:    5C3(=10) 계산 시 factorial을 3번만 호출하도록 CALLN factorial, 3
```

### 모범답안 예시 B — 안전한 나눗셈 (divide-by-zero 방지)
```
명령어:  SDIV  dest, src          ; src=0이면 0으로 나누지 않고 CF=1만 세팅
동기:    DIV는 0으로 나누면 인터럽트(예외) 발생 → 프로그램 비정상 종료
동작:    if src == 0 → CF=1, dest 불변, 예외 발생 안 함
         else → 일반 나눗셈 수행, CF=0
예제:    SDIV eax, ebx  /  jc divByZeroHandler
```

### 모범답안 예시 C — 배열 합 한 줄 명령어
```
명령어:  SUMARR  dest, srcAddr, count   ; 배열 원소 count개를 합산해 dest에
동작:    ESI←srcAddr, ECX←count, 루프 돌며 dest += [ESI], ESI+=TYPE
예제:    SUMARR eax, OFFSET arr, LENGTHOF arr
```

> 💡 **시험 전 최소 2~3개 미리 만들어 외워가기.** 작동방식+사용예제까지 써야 만점.

## 5. 📖 약어 풀네임 모음 (전부 암기)

> 후기: *"ppt에 나오는 용어들은 다 풀네임을 외워가셔야 합니다."* / *"IRQ 풀네임(Interrupt Request levels)"*

| 약어 | 풀네임 | 한 줄 의미 |
|------|--------|-----------|
| **IRQ** | **Interrupt Request (levels)** | 우선순위 기반 하드웨어 인터럽트 요청 |
| **ISR** | Interrupt Service Routine | = 인터럽트 핸들러 |
| **IVT** | Interrupt Vector Table | 핸들러 주소(세그:오프셋) 테이블 |
| **PIC** | Programmable Interrupt Controller | Intel 8259, 인터럽트 생성·중재 |
| **FSM** | Finite-State Machine | 상태 전이 그래프 |
| **FAT** | File Allocation Table | 클러스터 체인(흩어진 클러스터 주소 잇기) |
| **TSR** | Terminate and Stay Resident | 메모리 상주 프로그램 |
| **BIOS** | Basic Input-Output System | 저수준 하드웨어 드라이버 |
| **CMP** | Compare | 암묵적 뺄셈으로 플래그 세팅 |
| **TEST** | (test bits) | AND 결과 버리고 플래그만 |
| **PROC / ENDP** | Procedure / End Procedure | 프로시저 정의 |
| **PROTO** | Prototype | 프로시저 시그니처 선언 |
| **LEA** | Load Effective Address | 런타임 주소 로드 |
| **STI / CLI** | Set / Clear Interrupt flag | 인터럽트 활성/비활성 |
| **STD CALL** | Standard Call | 피호출자가 스택 정리(ret n) |
| **VRAM** | Video RAM | 비디오 메모리 |
| **EBP / ESP** | Base / Stack Pointer | 프레임 기준점 / 스택 top |
| **ZF·CF·SF·OF·PF** | Zero·Carry·Sign·Overflow·Parity Flag | 상태 플래그 |

## 6. 🗺️ 주민등록번호 FSM (기출 재현)

6자리 숫자 + `-` + 7자리 숫자. 각 입력마다 다음 state로, 마지막이 **수락(accept) state**.

```mermaid
stateDiagram-v2
    [*] --> S0
    S0 --> S1: digit
    S1 --> S2: digit
    S2 --> S3: digit
    S3 --> S4: digit
    S4 --> S5: digit
    S5 --> S6: digit
    S6 --> S7: '-'
    S7 --> S8: digit
    S8 --> S9: digit
    S9 --> S10: digit
    S10 --> S11: digit
    S11 --> S12: digit
    S12 --> S13: digit
    S13 --> S14: digit
    S14 --> [*]
```
- 6자리(S1~S6) → `-`(S7) → 7자리(S8~S14). **S14가 유일한 수락 상태.**
- 핵심: 각 자리에서 **정해진 입력(숫자/대시)만** 다음으로 보내고, 그 외 입력은 거부.
