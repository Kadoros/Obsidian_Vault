# 1주차. 전체정리 📚 — 오리엔테이션

> [!summary] 한눈에 보기 (TL;DR)
> 데이터는 4차 산업혁명의 핵심자원이지만 **그 자체가 답은 아니다.** 맥락과 목적 위에서 데이터를 **읽고(read)·표현하고(speak)·소통**하는 능력이 **데이터 리터러시**다. 이 수업은 다빈치러닝(동영상)으로 진행되며, 데이터 리터러시 기초→재무제표 분석 응용으로 이어진다.

## 1. 배경: Can you read data?
데이터를 단순히 *보는 것*과 **읽고 해석하는 것**은 다르다. 강의는 여러 기사·통계 사례로 데이터 해석의 함정을 보여준다.

| 사례 | 함정 | 교훈 |
|---|---|---|
| NEJM "초콜릿 소비↑ → 노벨상 수상자↑" | **상관 ≠ 인과** | 함께 움직인다고 원인은 아니다 |
| "해외이주자 330% 증가" | 맥락 없는 수치 | 기준연도·표본·절대규모를 따져야 |
| 서울시 상권분석(golmok) | 어떤 데이터가 필요한가 | 분석 전 **필요 데이터 정의**가 먼저 |

- 핵심 질문: **"어떤 데이터가 있어야 이 분석이 가능한가?"**

## 2. Can you speak data?
- 같은 데이터라도 **시각화 방식**(차트 종류, 축 범위)에 따라 전달 메시지가 달라진다.
- 적합한 데이터를 **수집·정제**하고 **효과적으로 표현**해야 한다. (예: 대한민국 우울증 보고서 인터랙티브 시각화)
- → 데이터를 "읽는 것"뿐 아니라 "말하는(표현·소통)" 능력이 필요하다.

## 3. 데이터 시대 — 데이터는 답이 아니다
- **4차 산업혁명의 핵심자원 = 데이터.**
- 그러나 데이터 자체로는 목적도 답도 될 수 없다. 데이터에 **숨은 의미와 통찰**을 발견하는 것이 중요.
- 강양석(2021)의 의사결정 흐름:

> **맥락(context)** → **목적(어떤 질문에 답하려는가)** → **문제 규정** → **가설** → **어프로치(검증 설계)** → **데이터**

- 문제가 정확해야 적중도 높은 가설이 나오고, 가설이 명확해야 효율적 검증이 가능하다.
- 비유: *영어를 배운다고 논리적 사고력이 저절로 높아지지 않듯*, 데이터를 모은다고 통찰이 생기지 않는다.

## 4. 데이터 리터러시 (Data Literacy)
- **Data + Literacy** = 데이터를 읽고 이해·분석하며 **비판적으로 수용·활용**하고, 상황에 맞게 읽고 쓰며 **소통**하는 능력.
- 데이터 리터러시를 갖춘 인재:
  - 데이터 지식을 **생산·소비·비판적으로 수용**
  - 개인·사회의 **문제해결**을 위해 데이터를 **분석·활용**

### 주요 인용 (출제 가능)
| 인물 | 소속/연도 | 핵심 메시지 |
|---|---|---|
| 핼 베리안 | Google 수석 이코노미스트, 2013 | 앞으로 10년 가장 중요한 비즈니스 역량 = 데이터 분석·활용 |
| 브랜트 다이크스 | 2017 | 데이터는 소수의 손에선 **권력**, 다수의 손끝에선 **혁신** |
| 앨런 던컨 | 가트너 부사장, 2019 | 2020년경 회사의 **80%**가 데이터 리터러시 역량 개발 시작 |
| HBR | 2020 | 부족한 것은 기술이 아니라 **데이터로 문제를 푸는 역량** |

## 5. 학습목표 / 학습성과
- **목표**: ① 데이터로 사회현상·기업환경 이해 ② 비판적 사고·분석 ③ SW·DB로 효과적 의사결정.

| 구분 | 학습성과 |
|---|---|
| 기초 | 데이터 개념·이슈 이해 / 경영데이터 분석·활용 |
| 응용 | 스마트한 사회생활 문해력 / 재테크 데이터 문해력 |
