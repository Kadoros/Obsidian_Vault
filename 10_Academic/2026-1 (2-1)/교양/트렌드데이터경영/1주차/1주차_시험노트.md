# 1주차. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **데이터 리터러시** | 데이터를 읽고 이해·분석하며 비판적으로 수용·활용하고, 상황에 맞게 읽고 쓰며 소통하는 능력 (Data + Literacy) |
| **맥락(context)** | 데이터에 숨은 의미·통찰을 발견하기 위해 알아야 하는 배경. 문제를 정확히 규정하는 출발점 |
| **다빈치러닝** | 중앙대 특화 수업방식. 모든 진도를 e-Class 동영상 강의로 진행 |

## 배경: 데이터를 잘못 읽는 사례
- **상관 ≠ 인과**: "초콜릿 소비 ↑ → 노벨상 수상자 ↑" (NEJM) — 상관일 뿐 인과 아님
- 같은 데이터도 **차트 표현 방식**에 따라 해석이 달라짐 → "Can you speak data?"

## 데이터 시대
- **4차 산업혁명 핵심자원 = 데이터**
- 데이터만으로는 불충분 → 숨은 의미·통찰 발견이 핵심
- 의사결정 흐름: 맥락 → 목적(질문) → 문제 규정 → 가설 → 어프로치 → 데이터

## 데이터 리터러시를 갖춘 인재
- 데이터에 대한 지식을 **생산·소비·비판적으로 수용**
- 개인·사회의 **문제해결**을 위해 데이터를 **분석·활용**

## 학습목표 / 성과
- 목표: 데이터로 사회현상·기업환경 이해, 비판적 분석, SW·DB로 효과적 의사결정
- 성과(기초): 개념·이슈 이해, 경영데이터 분석·활용
- 성과(응용): 사회생활·재테크 데이터 문해력 향상
