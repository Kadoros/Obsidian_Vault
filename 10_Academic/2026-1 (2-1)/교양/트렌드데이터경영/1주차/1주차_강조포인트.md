# 1주차. 강조포인트 ⭐

## 🔴 강의 핵심 질문 2가지
- **Can you read data?** — 데이터를 읽고 해석하는 능력
- **Can you speak data?** — 데이터를 효과적으로 표현(시각화)하고 소통하는 능력

## 🔴 데이터 ≠ 답
- 데이터 자체로는 목적도 답도 될 수 없다 → **맥락(context)**과 **목적**이 중요
- 흐름: **맥락 → 목적 → 문제 규정 → 가설 → 어프로치(검증 설계) → 데이터**
- "어떤 질문에 답하기 위해 데이터를 쓰는가?"가 출발점

## 🔴 데이터 리터러시 (Data Literacy) ★
- **Data + Literacy** = 데이터를 **읽고·이해하고·분석하며 비판적으로 수용·활용**하는 능력
- 상황에 맞추어 데이터를 **읽고 쓰며 소통**하는 능력
- 핼 베리안(Google): "앞으로 10년 가장 중요한 비즈니스 역량 = 데이터 분석·활용"
