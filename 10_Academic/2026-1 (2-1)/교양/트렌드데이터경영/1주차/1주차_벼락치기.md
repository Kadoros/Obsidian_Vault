# 1주차. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> 4차 산업혁명의 핵심자원은 **데이터**, 핵심 역량은 **데이터 리터러시**(읽고·이해·분석·비판·활용). 데이터 자체는 답이 아니며 **맥락과 목적**이 먼저다.

## 무조건 외울 것
1. 데이터 리터러시 = **Data + Literacy**, 읽고 쓰며 소통하는 능력
2. 두 핵심 질문: **Can you read data? / Can you speak data?**
3. 데이터는 답이 아니다 → **맥락 → 목적 → 가설 → 어프로치 → 데이터**
4. 평가: 출결 **10**, 기말 **50**, 중간과제 **20**, 기말과제 **20**
5. 강의방식 = **다빈치러닝**(e-Class 동영상), 실습 = **Excel / TS2000**

## 주요 인물 인용
- 핼 베리안(Google): 가장 중요한 비즈니스 역량 = 데이터 분석·활용
- 브랜트 다이크스: "데이터는 소수에겐 권력, 다수에겐 혁신"
- 가트너 던컨: 회사 80%가 데이터 리터러시 역량 개발 시작

## 강의 일정 큰 그림
- 2~3주: 데이터 리터러시·비판적 사고·엑셀·DB
- 4~5주: 데이터 **시각화**
- 6주: 프로젝트 설명 / 8주: 중간과제(중간고사 대체)
- 7·9~14주: **재무제표·재무비율·원가 데이터**(TS2000)
- 15주: 기말고사

- 기말 = **객관식(4지선다) + 주관식(단답형)**, 서술형 없음, Closed-book
