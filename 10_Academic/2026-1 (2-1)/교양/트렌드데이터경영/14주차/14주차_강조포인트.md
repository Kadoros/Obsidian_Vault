# 14주차. 강조포인트 ⭐ (원가 데이터)

## 🔴 상기업 vs 제조기업 (★★)
| | 상기업 | 제조기업 |
|---|---|---|
| 활동 | 물건 구입→판매(도소매) | 자원 투입→직접 생산→판매 |
| 판매 대상 | **상품** | **제품** |
| 재고자산 | 상품 | **원재료 + 재공품 + 제품** |

- **재공품** = 생산공정 중 미완성 제품

## 🔴 매출원가 산출 차이 (★★)
- **상기업**: 기초상품재고 + 당기상품매입 - 기말상품재고
- **제조기업**: 기초제품재고 + **당기제품제조원가** - 기말제품재고

## 🔴 당기총제조원가 3요소 (★★)
| 투입 | 원가 |
|---|---|
| 재료 | **재료비** |
| 노동력 | **노무비** |
| 기타 자원 | **제조경비** |

## 🔴 당기제품제조원가 (★★)
- **기초재공품 + 당기총제조원가 - 기말재공품**
- 제조원가명세서로 산출 (예: 100 + 50 - 40 = 110)

## 🟥 제조원가명세서
- 재료비·노무비·경비 → 당기총제조원가 → ±재공품 → 당기제품제조원가
- **재무제표에 포함 X** → 외부 공시 의무 없음

## 🟥 매출원가율 (In Class)
- **매출원가율 = 매출원가 ÷ 매출액** (TS2000으로 산업평균 비교)
