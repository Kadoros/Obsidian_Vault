# 14주차. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **상기업** | 다른 기업이 생산한 물건을 구입해 판매하는 기업(도·소매업). 판매물 = **상품** |
| **제조기업** | 재료·노동력·자원을 투입해 직접 생산·판매하는 기업. 판매물 = **제품** |
| **재공품** | 생산공정 중에 있는 미완성 제품 |
| **제품제조원가** | 제품 제조를 위해 투입·소비한 자원의 금액 |

## 1. 상기업 vs 제조기업
- **상기업**: 상품 구입 → 상품 판매.
- **제조기업**: 재료·노동력·기타자원 구입·투입 → 생산 → 제품 판매.

### 재무상태표(재고자산) 차이
| 상기업 | 제조기업 |
|---|---|
| 상품 | **원재료 + 재공품 + 제품** |
- 기초재공품: 전기말 미완성 → 당기 추가 가공. 기말재공품: 당기말 미완성 → 차기 가공.

## 2. 손익계산서 매출원가 차이
- **상기업 매출원가** = 기초상품재고 + 당기상품매입 - 기말상품재고.
- **제조기업 매출원가** = 기초제품재고 + **당기제품제조원가** - 기말제품재고.
- 상기업은 상품의 수량·단가로 당기매입액 산출, 제조기업은 투입 자원을 집계해 제조원가 산출.

## 3. 제조원가명세서
- 제품 제조를 위해 소비한 자원의 금액을 보여주는 명세서.
- **재무제표에 포함되지 않음 → 외부 공시 의무 없음.**

### 당기총제조원가 3요소
| 투입 | 원가 |
|---|---|
| 재료 | 재료비 |
| 노동력 | 노무비 |
| 기타 자원 | 제조경비(복리후생비·전력비·감가상각비·임차료·외주가공비 등) |

### 당기제품제조원가 산출
> **당기제품제조원가 = 기초재공품재고 + 당기총제조원가 - 기말재공품재고**
- 예: 당기총제조원가 100 + 기초재공품 50 - 기말재공품 40 = **110**.

## 4. 원가 흐름 (예시)
- **상품**: 기초상품 10억 + 당기매입 50억 = 60억 → 매출원가 40억(판매O) + 기말상품 20억(판매X).
- **제품**: 기초제품 30억 + 당기제품제조원가 100억 = 130억 → 매출원가 120억 + 기말제품 10억.
