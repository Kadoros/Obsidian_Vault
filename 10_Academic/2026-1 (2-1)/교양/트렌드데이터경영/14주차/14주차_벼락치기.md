# 14주차. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> 상기업은 **상품**을 사서 팔고, 제조기업은 **제품**을 만들어 판다. 제조기업 재고는 원재료·재공품·제품 3종이며, 매출원가는 **당기제품제조원가**로 계산한다.

## 무조건 외울 것
1. 상기업=상품 / 제조기업=제품
2. 제조기업 재고자산 = **원재료 + 재공품 + 제품**
3. **재공품** = 공정 중 미완성 제품
4. 당기총제조원가 = **재료비 + 노무비 + 제조경비**
5. **당기제품제조원가 = 기초재공품 + 당기총제조원가 - 기말재공품**

## 매출원가 공식 비교
- 상기업: 기초상품 + 당기매입 - 기말상품
- 제조기업: 기초제품 + **당기제품제조원가** - 기말제품

## 헷갈림 방지
- **재공품**으로 더하고 빼면 → **당기제품제조원가**
- **제품(완성품)**으로 더하고 빼면 → **매출원가**
- 제조원가명세서는 **재무제표 아님** (외부 공시 의무 없음)

## In Class
- 매출원가율 = 매출원가 ÷ 매출액. TS2000으로 의약품 제조업 2024·2025 산업평균 비교.
