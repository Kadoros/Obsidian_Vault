# 14주차. 전체정리 📚 — 원가 데이터

> [!summary] 한눈에 보기 (TL;DR)
> 상기업은 **상품**을 사서 팔고, 제조기업은 **제품**을 만들어 판다. 제조기업 재고는 **원재료·재공품·제품** 3종. **재공품**으로 가감하면 당기제품제조원가, **제품(완성품)**으로 가감하면 매출원가가 나온다.

## 1. 상기업 vs 제조기업
| | 상기업 | 제조기업 |
|---|---|---|
| 활동 | 물건 구입 → 판매(도·소매) | 자원 투입 → 직접 생산 → 판매 |
| 판매물 | **상품** | **제품** |
| 예 | 백화점·서점·할인점 | 자동차·전자제품·식품가공 |

## 2. 재무상태표(재고자산) 차이
| 상기업 | 제조기업 |
|---|---|
| 상품 | **원재료 + 재공품 + 제품** |

- **재공품**: 생산공정 중 미완성 제품 (자원이 투입됐으나 100% 완성 안 됨).
  - 기초재공품: 전기말 미완성 → **당기** 추가 가공.
  - 기말재공품: 당기말 미완성 → **차기** 추가 가공.

## 3. 손익계산서(매출원가) 차이
| 상기업 매출원가 | 제조기업 매출원가 |
|---|---|
| 기초**상품**재고 + 당기상품매입 - 기말상품재고 | 기초**제품**재고 + **당기제품제조원가** - 기말제품재고 |

- 상기업은 상품의 수량·단가로 매입액을 산출하지만, 제조기업은 투입 자원을 집계해 제조원가를 산출.

## 4. 제조원가명세서
- 제품 제조에 소비한 자원 금액을 보여주는 명세서. **재무제표에 포함되지 않음 → 외부 공시 의무 없음.**

### 당기총제조원가 3요소
| 투입 | 원가 | 세부 예 |
|---|---|---|
| 재료 | **재료비** | 원재료 |
| 노동력 | **노무비** | 임금 |
| 기타 자원 | **제조경비** | 복리후생비·전력비·가스수도비·감가상각비·임차료·보험료·외주가공비 |

### 당기제품제조원가 산출
> **당기제품제조원가 = 기초재공품재고 + 당기총제조원가 - 기말재공품재고**

| 항목 | 금액(예) |
|---|---|
| 당기총제조원가 (재료비60+노무비10+경비30) | 100 |
| + 기초재공품 | 50 |
| - 기말재공품 | (40) |
| **= 당기제품제조원가** | **110** |

## 5. 원가 흐름 (예시)
| 구분 | 사용가능액 | 매출원가(판매O) | 기말재고(판매X) |
|---|---|---|---|
| 상품 | 기초 10억 + 매입 50억 = 60억 | 40억 | 20억 |
| 제품 | 기초 30억 + 당기제품제조원가 100억 = 130억 | 120억 | 10억 |

> 핵심 구분:
> - **재공품**으로 가감 → 당기제품제조원가
> - **제품(완성품)**으로 가감 → 매출원가

> [!important] 시험 출제 포인트
> - 상기업=상품 / 제조기업=제품, 재고 3종(원재료·재공품·제품)
> - **재공품** = 공정 중 미완성
> - 당기제품제조원가 = 기초재공품 + **당기총제조원가**(재료비+노무비+제조경비) - 기말재공품
> - 매출원가(제조) = 기초제품 + 당기제품제조원가 - 기말제품
> - 제조원가명세서는 **재무제표 아님**(공시 의무 없음)
