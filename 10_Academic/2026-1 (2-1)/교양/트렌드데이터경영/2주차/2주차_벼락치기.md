# 2주차. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> 데이터 리터러시는 **수집→관리→가공·분석→시각화→기획** 5단계로 이루어지고, 그 바탕에는 **비판적 사고**(베이컨 4대 우상 극복)가 있다.

## 무조건 외울 것
1. 리터러시 5단계: **수집 / 관리 / 가공·분석 / 시각화 / 기획**
2. 베이컨 **4대 우상**: 종족 · 동굴 · 시장 · 극장
3. 비판적 사고 체크리스트: 사실/의견 구분, 신뢰성, 정확성, 편견, 비인과성, 강도
4. **인포데믹스** = 정보 + 전염병
5. 데이터 ≠ 만능 → 최종 결정은 **사람** (넷플릭스 vs 아마존)

## 4대 우상 암기법
- **종족** = 인류 공통 본성/편견 (확증편향·반향실효과)
- **동굴** = 나만의 경험 (우물 안 개구리)
- **시장** = 말·소문·잘못된 명명 (카더라)
- **극장** = 권위·전통 맹신

## 비판적 사고의 정의
- 존 듀이: 수동적 수용이 아닌 **능동적**으로 생각·문제제기·정보발견하는 과정
- 배리 베이어: 진술·논증·경험을 평가하고 **오류를 찾아내는** 사고

## 사례 키워드
- ZARA = "옷장사=생선장사"(신선도) 데이터 회사 / 쿠팡 = 데이터 기반 물류+결제
- 소크라테스의 **세 개의 체**: 진실인가 / 선의인가 / 중요한가
