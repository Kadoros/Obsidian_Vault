# 2주차. 전체정리 📚 — 데이터 리터러시 · 비판적 사고

> [!summary] 한눈에 보기 (TL;DR)
> 데이터 리터러시는 **수집 → 관리 → 가공·분석 → 시각화 → 기획** 5단계로 이루어지고, 그 바탕에는 **비판적 사고**가 있다. 베이컨의 **4대 우상**(종족·동굴·시장·극장)을 경계하고, **6가지 체크리스트**로 사실·근거를 따져야 한다. 데이터는 만능이 아니며 **최종 결정은 사람**이 한다.

## 1. 데이터 회사 사례
| 기업 | 핵심 | 시사점 |
|---|---|---|
| **ZARA** | "옷장사 = 생선장사" → **신선도(빠른 회전)** 중시, 42개 자회사 | 업의 본질을 데이터로 재정의 |
| **쿠팡 로켓배송** | **데이터 기반 물류 + 결제**, AI·빅데이터로 수요예측·재고·물류 최적화 | 적자에도 인프라 투자로 효율·수익성 강화 (NYSE 상장 2021) |

## 2. 데이터 리터러시란
- 데이터에 대한 지식을 **생산·소비·비판적으로 수용**하고, 개인·사회의 **문제해결**을 위해 분석·활용하는 능력.

| 학자 | 정의 |
|---|---|
| Earl & Katz (2002) | 데이터를 읽고 이해하는 능력 |
| Hallinger 외 (2012) | 자료 수집 → 패턴 발견 → 구조화하는 사고 |
| Wanner (2015) | 이해·획득·해석·관리·활용 능력 |

## 3. 데이터 리터러시 하위 역량 5단계 ★★
| 단계        | 핵심 활동                             | 홍길동 사례 주의점                    |
| --------- | --------------------------------- | ----------------------------- |
| **수집**    | 목적에 맞는 데이터 확보, 유형별 장단점, 비정형 선별 추출 | 양이 많다고 **월별로만 묶으면** 일별 패턴 손실  |
| **관리**    | 노이즈 제거(정제), 자동 입력, 통합             | 매출만 남기고 **다 지우면** 분석 변수 상실    |
| **가공·분석** | 목적에 맞게 가공, 쿼리 설계, 해석·보고           | 3년치 중 **최근 4개월만** 추출 → 대표성 훼손 |
| **시각화**   | 그래프·차트로 직관적 표현, 패턴 추출             | 막대그래프로 맥주 판매량 추이 파악           |
| **기획**    | 데이터 종류·양·관계 파악, 전 과정 기획·개선        | —                             |

> 각 단계의 잘못된 선택이 **정보 손실·왜곡**으로 이어진다. → 그래서 **비판적 사고**가 필요하다. (시각화는 [[4주차_전체정리]]·[[5주차_전체정리]]에서 심화)

## 4. 비판적 사고
- **어원**: 그리스어 kriticos/kriterion = "판단할 수 있는". 일정 기준에 근거한 분별있는 판단.
- **소크라테스의 세 개의 체**: ① 진실인가 ② 선의인가 ③ 중요한가 — 셋 다 아니면 전할 필요 없다.

| 학자 | 비판적 사고의 정의 |
|---|---|
| **존 듀이** | 수동적 수용이 아닌, 스스로 생각·문제제기·정보발견하는 **능동적 과정** |
| **배리 베이어** | 진술·논증·경험을 평가하고 **오류를 찾아내는** 사고 |

## 5. 프랜시스 베이컨 4대 우상론 ★★
| 우상 | 정의 | 핵심 예시 |
|---|---|---|
| **종족의 우상** | 인간 본성·정서·편견으로 세상을 봄 | 반향실 효과(echo chamber), **확증편향** |
| **동굴의 우상** | 자신의 경험에 비춘 편견 | 우물 안 개구리, 장님 코끼리 만지기 |
| **시장의 우상** | 직접 관찰 없이 말·소문만 믿음, 잘못된 명명 | 카더라 통신 |
| **극장의 우상** | 권위·전통을 비판 없이 맹신 | 연극을 사실로 착각 |

- **반향실 효과**: 기존 신념과 같은 정보만 반복 수용되며 증폭·강화 → 확증편향 유발.

## 6. 비판적 사고 체크리스트 6
| # | 체크리스트 | 예시 |
|---|---|---|
| 1 | 사실/의견 구분 | "기온 1.1도 상승"(사실) vs "가장 큰 위기"(의견) |
| 2 | 정보원 신뢰성 | 공식 보도·국회 발표 vs 미검증 블로그·유튜브 |
| 3 | 진술 정확성 | 수치·근거 검증 |
| 4 | 편견 탐지 | "저출산 = 여성 탓" 같은 치우친 주장 |
| 5 | 논리적 비인과성 | "매출 감소 = 코로나만 탓" 단일원인 오류 |
| 6 | 주장의 강도 | 통계·정부자료로 뒷받침된 주장이 더 설득력 |

## 7. 인포데믹스 & 데이터 맹신 경계
- **인포데믹스(infodemics)** = information + epidemics: 거짓 정보·루머가 전염병처럼 확산. (가짜뉴스, '프로듀스X101' 투표 조작 의혹 — 디시 갤러리 데이터 수집→관리→분석 과정 사례)
- **데이터 ≠ 만능**:

| 기업 | 작품 | 결과 |
|---|---|---|
| 넷플릭스 | 하우스 오브 카드 | 성공 (빈지워칭 유행) |
| 아마존 | 알파 하우스 | 실패 |
- 베르니케(데이터 과학자): "데이터는 중요하지만 **최종 결정은 사람**이 내린다."

> [!important] 시험 출제 포인트
> - 리터러시 5단계 **순서**(수집→관리→가공·분석→시각화→기획)
> - 베이컨 **4대 우상** 이름·정의·예시 매칭 (특히 동굴 vs 시장)
> - 체크리스트 6개, 사실 vs 의견 구분
> - 인포데믹스 = 정보 + 전염병
> - 넷플릭스 vs 아마존 → 최종 결정은 사람
