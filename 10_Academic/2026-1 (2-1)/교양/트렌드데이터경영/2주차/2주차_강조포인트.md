# 2주차. 강조포인트 ⭐

## 🔴 데이터 리터러시 하위 역량 5단계 (★★ 단골)
1. **수집** — 목적에 필요한 데이터 확보, 유형별 장단점 이해, 비정형 소스 선별 추출
2. **관리** — 노이즈 제거(정제), 신규 데이터 자동 입력, 다른 형태 데이터 통합
3. **가공 및 분석** — 분석 목적에 맞게 가공, 쿼리 설계, 결과 해석·보고
4. **시각화** — 그래프·차트·인포그래픽으로 직관적 표현, 패턴 추출
5. **기획** — 데이터 종류·양 파악, 관계 유추, 수집~분석 과정 기획·개선

## 🔴 베이컨 4대 우상론 (★★ 시험 단골)
| 우상 | 의미 | 키워드 |
|---|---|---|
| **종족의 우상** | 인간 본성·정서·편견으로 보는 오류 | 반향실효과, 확증편향 |
| **동굴의 우상** | 개인 경험에 비춘 편견 | 우물 안 개구리, 장님 코끼리 |
| **시장의 우상** | 잘못된 언어·명명, 소문으로 인한 오류 | 카더라, 잘못된 명명 |
| **극장의 우상** | 권위·전통을 맹신 | 연극을 사실로 착각 |

## 🔴 비판적 사고 체크리스트 6 (★)
- 사실/의견 구분 · 정보원 신뢰성 평가 · 진술 정확성 평가 · 편견 탐지 · 논리적 비인과성 평가 · 주장의 강도 평가

## 🔴 비판(criticism)의 어원
- 그리스어 **kriticos/kriterion** → "판단할 수 있는", 기준에 근거한 분별있는 판단

## 🔴 인포데믹스 (infodemics)
- **information + epidemics** = 거짓 정보·루머가 전염병처럼 퍼지는 현상 (예: 가짜뉴스)

## 🟥 데이터 맹신 경계
- 넷플릭스(하우스 오브 카드) 성공 vs 아마존(알파 하우스) 실패 → **최종 결정은 사람**
