# 2주차. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **데이터 리터러시** | 데이터에 대한 지식을 생산·소비·비판적으로 수용하고, 문제해결을 위해 분석·활용하는 능력 |
| **비판(criticism)** | 그리스어 kriticos/kriterion 유래. 일정 기준에 근거한 분별있는 판단 |
| **인포데믹스** | information + epidemics. 거짓 정보·루머가 전염병처럼 확산되는 현상 |
| **반향실 효과(echo chamber)** | 기존 신념과 같은 정보만 반복 수용되며 증폭·강화되는 현상 → 확증편향 유발 |

## 데이터 리터러시 하위 역량 5단계
| 단계 | 핵심 활동 |
|---|---|
| **수집** | 목적에 필요한 데이터 파악, 유형별 장단점 이해, 비정형 소스에서 선별 추출 |
| **관리** | 원시데이터 노이즈 제거(정제), 신규 데이터 자동 입력, 다른 형태 데이터 통합 |
| **가공·분석** | 분석 목적에 맞는 데이터셋 가공, 쿼리 설계, 결과 해석 후 보고서 작성 |
| **시각화** | 그래프·차트·인포그래픽으로 직관적 표현, 패턴·특이사항 추출, 시계열 표현 |
| **기획** | 데이터 종류·양 파악, 데이터 간 관계 유추, 수집~분석 전 과정 기획·실행·개선 |

> 홍길동 사례: 수집(월별로 묶음)→관리(매출만 남기고 삭제)→분석(최근 4개월만 추출) 각 단계에서 **정보 손실** 발생 가능 → 단계별 주의점 학습.

## 비판적 사고
- **존 듀이**: 정보를 수동적으로 받는 게 아니라 스스로 생각·문제제기·정보발견하는 **능동적 과정**.
- **배리 베이어**: 진술·논증·경험을 평가하고 오류를 찾아내는 사고.

### 베이컨 4대 우상론
| 우상 | 원인 | 예시 |
|---|---|---|
| **종족의 우상** | 인간 생물학적 특징·정서·편견으로 세상을 봄 | SNS 확증편향, 반향실 효과 |
| **동굴의 우상** | 개인 경험에 비춘 편견 | 우물 안 개구리, 장님 코끼리 |
| **시장의 우상** | 직접 관찰 없이 말·소문만 믿음, 잘못된 명명 | 카더라 통신 |
| **극장의 우상** | 권위·전통을 비판 없이 맹신 | 연극을 사실로 착각 |

## 비판적 사고 체크리스트 6
1. 사실과 의견 구분하기 (예: "기온 1.1도 상승"=사실 / "가장 큰 위기"=의견)
2. 주장·정보원의 신뢰성 평가 (공식 보도 vs 검증 안 된 SNS)
3. 진술의 정확성 평가
4. 주장·진술의 편견 탐지
5. 논리적 비인과성 평가 (코로나로만 단정 → 오류)
6. 주장의 강도 평가 (근거·통계가 있는 주장이 강함)
