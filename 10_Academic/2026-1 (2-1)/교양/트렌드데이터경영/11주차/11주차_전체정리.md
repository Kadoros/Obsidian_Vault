# 11주차. 전체정리 📚 — 재무제표 분석 (1)

> [!summary] 한눈에 보기 (TL;DR)
> 재무제표는 4가지로 분석한다: **비교(단기 3년 이내)·구성비율(총액 대비)·지수추세(기준=100, 장기 3년 이상)·재무비율**. 분석할 땐 과거정보 한계·업종·성장단계를 감안하고 **산업평균/경쟁사와 비교**해야 의미가 산다. 데이터는 **TS2000**에서 받는다.

## 1. TS2000으로 재무제표 데이터 다운로드
| 단계 | 내용 |
|---|---|
| 접속 | 중앙대 도서관(library.cau.ac.kr) → 자료검색-학술DB → **TS2000** 바로 실행 |
| 조건 | 법인구분(KOSPI), 업종(제조업), 결산기·결산월(2024, 12월) → Search |
| 선택 | 전체선택·회사추가, 자료기간 지정 |
| 항목 | 재무사항 Tab — 재무상태표(자산·부채·자본·유동자산·유동부채·재고자산), 손익계산서(매출액·매출원가·판관비·영업이익·당기순이익) → 항목추가 → Submit |
| 다운로드 | "Excel" 버튼 (파일명: TS2000연습) |

## 2. 재무제표 분석 방법 4가지 ★★
| 방법 | 핵심 | 적합 기간 |
|---|---|---|
| **비교재무제표 분석** | 기업 간·기간 간 항목을 비교형식으로 검토 | **3년 이내 단기** |
| **구성비율 분석** | 각 항목을 총액 대비 비율(공통형)로 내부구조 검토 | — |
| **지수추세 분석** | 기준연도=100, 비교연도÷기준연도로 추이 파악 | **3년 이상 장기** |
| **재무비율 분석** | 관련 항목 대응 비율로 수익성·재무위험 평가 | — |

### 구성비율 분석 (Common-size) 예시
- 기준 총액: **재무상태표 = 총자산 / 손익계산서 = 매출액**.

| 손익 항목 | 금액 | 비율 |
|---|---|---|
| 매출액 | 100,000 | 100% |
| 매출원가 | 80,000 | 80.0% |
| 매출총이익 | 20,000 | 20.0% |
| 영업이익 | 5,000 | 5.0% |
| 당기순이익 | 8,000 | 8.0% |

### 지수추세 분석 예시
| 항목 | 20x1 | 20x2 | 20x3 |
|---|---|---|---|
| 매출액 | 100% | 120% | 200% |
| 당기순이익 | 100% | 80% | 160% |

### 재무비율 분석
- 수익성: **ROA(총자산수익률)**, **ROE(자기자본수익률)**.
- 부채상환능력: 유동비율, 부채비율. (전체 비율 → [[12주차_전체정리]]·[[13주차_전체정리]])

## 3. In Class — 산업 내 재무비율 비교
- 의료용 물질·의약품 제조업 기업들의 재무비율 계산:

| 비율 | 공식 |
|---|---|
| 유동비율 | 유동자산 ÷ 유동부채 |
| 부채비율 | 부채총액 ÷ 자본총액 |
| 영업이익률 | 영업이익 ÷ 매출액 |
| 당기순이익률 | 당기순이익 ÷ 매출액 |
- 산업평균치 산출 후 개별 기업과 비교.

## 4. 재무비율 분석 시 고려사항 7
| # | 고려사항 | 예시 |
|---|---|---|
| 1 | 재무제표는 **과거 정보** | 현재 아님 |
| 2 | **비계량정보** 고려 | 조직·경영자·종업원 |
| 3 | **분석 목적** 파악 | 은행=유동성·수익성 / 투자자=수익성·성장성 |
| 4 | **성장단계** | 신생=활동성, 성장=성장성, 성숙=안정·수익성 |
| 5 | **업종 특성** | 전자=비유동자산↑, 건설=이자부채↑ |
| 6 | **미래 추정** | 시장환경·신기술·경쟁사 |
| 7 | **산업평균·경쟁사 비교** | 규모 유사 기업과 |

## 5. 학기말 과제
- 2026년 현재 **KOSPI/KOSDAQ 1개 산업·1개 기업** 선택, 직전 **3개년(2023~2025)** 자료 확보 가능.
- 대기업(삼성전자·SK하이닉스·현대차·POSCO·NAVER 등)은 권장 X (선택 시 심층 분석 필요).

| 포함 내역 |
|---|
| ① 선택 이유 ② 시장·설립연도·결산월 ③ 산업분류(대·중·소) ④ 3개년 감사의견 |
| ⑤ 사업내용·산업특성 ⑥ 2024·2025 재무비율(증감, 주가비율 제외, 엑셀) ⑦ 2025 종합분석(산업평균·경쟁사 비교 시 가산점) |
