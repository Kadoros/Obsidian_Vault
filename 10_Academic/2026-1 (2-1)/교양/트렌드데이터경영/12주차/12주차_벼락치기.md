# 12주차. 벼락치기 ⚡ (공식 암기)

## 한 줄 요약
> 재무비율 4그룹: **유동성(단기지급)·지급능력(장기)·수익률(ROA/ROE)·수익성(매출 대비)**. 분모가 무엇인지로 구분하라.

## 공식 총정리 (무조건 암기)
| 비율 | 공식 |
|---|---|
| 유동비율 | 유동자산 ÷ 유동부채 (200%↑ 양호) |
| 당좌비율 | 당좌자산 ÷ 유동부채 |
| 부채비율 | 부채총액 ÷ **자기자본** |
| 부채자산비율 | 부채총액 ÷ 자산총액 |
| 자기자본비율 | 자기자본 ÷ 자산총액 |
| 차입금의존도 | 차입금 ÷ 자산총액 |
| 이자보상비율 | (순이익+법인세+이자) ÷ 이자비용 |
| ROA | 당기순이익 ÷ 평균총자산 |
| ROE | 당기순이익 ÷ 평균자기자본 |
| 매출총이익률 | 매출총이익 ÷ 매출액 |
| 영업이익률 | 영업이익 ÷ 매출액 |
| 당기순이익률 | 당기순이익 ÷ 매출액 |
| EPS | (순이익-우선주배당) ÷ 가중평균보통주식수 |

## 헷갈리기 쉬운 것
- **당좌자산** = 유동자산 - 재고자산·선급금·선급비용 (현금화 어려운 것 제외)
- **당좌비율 > 유동비율보다 엄격** (재고 빼니까)
- **평균** = (기초+기말)÷2 → ROA·ROE에만
- 이자보상비율 분자 = **EBIT**(이자·법인세 차감 전 이익), 영업현금흐름으로 대체 가능

## In Class
- TS2000으로 의약품 제조업 기업의 2024·2025 비율 계산 → 증감·산업평균 비교 (EPS는 TS2000에서 다운로드)
