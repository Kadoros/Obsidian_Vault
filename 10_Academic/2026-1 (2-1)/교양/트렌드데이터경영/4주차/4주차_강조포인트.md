# 4주차. 강조포인트 ⭐

## 🔴 카너먼 - 2개의 시스템 (★)
- **시스템 1**: 빠르고 직관적(Intuition) → 시각화가 활용하는 인지 경로
- **시스템 2**: 느리고 논리적(Thinking) → 계산(예: 17×54)
- 감각정보의 **80%가 시각** → 시각화는 시스템1의 빠른 인지를 이용

## 🔴 시각화를 하는 이유 (★)
1. 많은 양의 데이터를 **한눈에** 요약
2. 전문지식 없이도 **시각적 패턴**으로 인사이트 획득
3. **요약 통계보다 정확** (앤스컴/DataSaurus: 통계량 같아도 분포 다름)
4. 인사이트 공유 → **효과적 의사결정·커뮤니케이션**

## 🔴 시각화 = 양날의 검
- 잘못 만들면 **왜곡·오류** 전달, 오히려 **인지적 부하(cognitive load)** 증가

## 🔴 차트 선택 = 질문이 결정 (★★)
| 목적(질문) | 강조 |
|---|---|
| 순서 | 개별 점 비교·정렬 |
| 진화 | 시간에 따른 변화 |
| 관계 | 변수 간 관계 |
| 경쟁 | 전체 속 개별 비중 |
| 예외 | 정규 범위 밖 관측치 |
| 프로파일링 | 대상의 특징 정의 |

## 🔴 차트 유형별 용도 (★★)
| 차트 | 용도 |
|---|---|
| 막대 | 항목 비교·순위 (많으면 수평막대) |
| 선 | 시간 흐름 추세 (선 너무 많이 X, 세로축 범위 주의) |
| 분산형(산점도) | 변수 간 관계·분포 (추세선) |
| 파이 | 비율·구성비 (조각 많이 X, 큰 순서) |
| 워드클라우드 | 서술형 텍스트 빈도 강조 |

## 🟥 추세선 (★)
- `Y = a + b·X` (a=절편, b=기울기, X=시간순서)
- **절편 INTERCEPT 함수**, **기울기 SLOPE 함수**로 예측

## 🟥 데이터 전처리
- 분석 시간의 **약 80%**가 데이터 수집·정제(전처리)에 소요
