# 4주차. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **시스템 1** | 빠르고 직관적인 사고(Intuition). 시각화가 활용하는 인지 경로 |
| **시스템 2** | 느리고 논리적·분석적 사고(Thinking). 계산·추론 |
| **데이터 시각화** | 복잡한 자료를 쉽게 이해할 수 있는 형태(그래프·차트·이미지)로 바꾸는 것 |
| **콤비네이션 차트** | 한 차트에 막대+선 등 다른 차트 종류를 결합 |
| **보조축** | 단위·크기가 다른 두 데이터를 한 차트에 표현하기 위한 두 번째 세로축 |

## 다니엘 카너먼
- 1934- 이스라엘 출신 미국 심리학자, **행동경제학 창시자**, 2002년 노벨경제학상(전망이론).
- 인간 사고를 **시스템 1(빠름·직관)**과 **시스템 2(느림·논리)**로 구분.
- 감각정보의 **80%가 시각** → 시각화는 시스템1로 빠르게 처리됨.

## 시각화를 하는 이유
1. 많은 데이터를 **한눈에** 요약.
2. 통계·수학 전문지식 없이도 **시각적 패턴**으로 인사이트 획득.
3. **요약 통계보다 정확** — 앤스컴(F.J. Anscombe, 1973)/DataSaurus: 평균·분산 등 통계량이 같아도 분포는 완전히 다름.
4. 인사이트 **공유·커뮤니케이션**으로 효과적 의사결정.

## 시각화는 양날의 검
- 장점: 정보처리 능력 확장, 다양한 계층 접근, 다량 데이터 차별 표현, 지각적 추론, 주목성↑.
- 단점: 제공자가 오류·왜곡을 범하거나 가치 없는 정보면 오히려 **인지적 부하**와 불편 유발.

## 차트 효과 — Visual Vocabulary
- Financial Times 팀이 74개 차트를 **9개 범주**로 분류: Deviation, Correlation, Ranking, Distribution, Change over time, Part-to-whole, Magnitude, Spatial, Flow.
- 차트는 **목표(질문)에 따라** 선택: 순서/진화/관계/경쟁/예외/프로파일링.

## 차트 유형별 사용법
| 차트 | 사용법 | 팁 |
|---|---|---|
| **수직막대** | 항목 트렌드·순위 비교 | 순위 강조 시 정렬, 색상 구분 |
| **수평막대** | 목표 대비 달성도, 항목 많을 때 | — |
| **선차트** | 시간 흐름·트렌드 변화 | 선 너무 많이 X, 세로축 범위 과장 X |
| **분산형(산점도)** | 변수 간 관계·분포 | 추세선, 2개 이상은 색 구분 |
| **파이차트** | 비율·상대적 크기 | 조각 많이 X, 큰 순서대로 |
| **워드클라우드** | 서술형 텍스트 빈도 강조 | 무의미·저빈도 단어 제외 |

## 시각화 과정 (전 세계 자살률 사례)
1. 데이터 수집(위키피디아 복사)
2. **데이터 정제**: 한 셀에 한 정보, 문자→숫자, 불필요 정보 제거, 정렬
3. 단순 통계량 확인(Min/Max/Mean/Median)
4. 차트화
- 전체 흐름: 수집 → 관리 → 분석 → 모델링 → 예측 → 시각화. **약 80% 시간이 전처리.**

## 추세변동 분석 (실습)
- 추세식: **Y = a + b·X** (a=절편, b=기울기, X=시간순서)
- 절편 = **INTERCEPT 함수**, 기울기 = **SLOPE 함수**
- 예: 온라인 매출 = 34.80 + 1.98 × 시간순서 → 미래 매출 예측
