# 4주차. 전체정리 📚 — 데이터 시각화 I

> [!summary] 한눈에 보기 (TL;DR)
> 시각화는 카너먼의 **시스템1(직관)**을 이용해 많은 데이터를 한눈에 보여준다(감각정보의 80%가 시각). 차트는 **목적(질문)에 따라** 선택해야 하며, 잘못 쓰면 왜곡을 부르는 **양날의 검**이다. 추세선 `Y=a+bX`는 INTERCEPT·SLOPE로 예측한다.

## 1. 2개의 시스템 (다니엘 카너먼)
| 시스템 | 특징 | 예 |
|---|---|---|
| **시스템 1** | 빠르고 **직관적**(Intuition) | 큰 글자·도형을 즉시 인지 |
| **시스템 2** | 느리고 **논리적**(Thinking) | 17 × 54 계산 |

- 감각정보의 **80%가 시각**을 통해 입력 → 시각화는 시스템1을 자극해 데이터를 빠르게 처리하게 한다.
- 카너먼: 행동경제학 창시자, **전망이론(Prospect Theory)**으로 2002년 노벨경제학상.

## 2. 데이터 시각화란
- 어려운 언어·복잡한 자료를 **이해하기 쉬운 형태(목록·다이어그램·이미지)**로 "번역"하는 일.
- 큰/복잡한 데이터를 쉽게 보이도록 이미지화.

## 3. 왜 시각화를 하는가
| 이유 | 설명 |
|---|---|
| 한눈에 요약 | 많은 데이터를 한 번에 파악 |
| 인사이트 | 통계·수학 지식 없이 **시각적 패턴**으로 발견 (시스템1의 속도) |
| 정확성 | **요약 통계보다 정확** — 앤스컴/DataSaurus |
| 의사결정 | 인사이트 공유·커뮤니케이션 |

- **앤스컴(F.J. Anscombe, 1973) / DataSaurus**: 평균·분산 등 요약통계가 같아도 분포(차트)는 완전히 다름 → "요약통계만으론 데이터를 충분히 알 수 없다."

## 4. 시각화 — 양날의 검
| 순기능 | 역기능 |
|---|---|
| 정보처리 능력 확장, 직관적 이해 | 제공자가 **오류·왜곡** 범할 수 있음 |
| 다양한 계층 접근, 지각적 추론 | 무의미한 정보면 **인지부하(cognitive load)**↑ |
| 다량 데이터 차별 표현, 주목성↑ | 면적·축 조작으로 착시 유발 |

## 5. 차트 효과 (Visual Vocabulary)
- Financial Times 팀: 74개 차트를 **9개 범주**로 분류 — Deviation, Correlation, Ranking, Distribution, Change over time, Part-to-whole, Magnitude, Spatial, Flow.
- 차트는 **목적(질문)에 따라** 선택:

| 질문 유형 | 강조 | 예시 |
|---|---|---|
| 순서 | 개별 점 비교·정렬 | 내 판매량 vs 경쟁자 |
| 진화 | 시간에 따른 변화 | 시장 점유율 추이 |
| 관계 | 변수 간 관계 | 이벤트가 판매에 미친 영향 |
| 경쟁 | 전체 속 비중 | 현재 시장 점유율 |
| 예외 | 정규 범위 밖 관측치 | 일별 불량률 |
| 프로파일링 | 대상 특징 정의 | 지역별 고객 특성 차이 |

### 차트 유형별 사용법 ★
| 차트 | 용도 | 팁 |
|---|---|---|
| 막대(수직/수평) | 항목 비교·순위 / 목표 대비 달성도 | 정렬·색상, 항목 많으면 수평 |
| 선 | 시간 흐름·추세 | 선 과다 X, **세로축 범위** 과장 X |
| 분산형(산점도) | 변수 관계·분포 | 추세선, 2개 이상 색 구분 |
| 파이 | 비율·구성비 | 조각 많이 X, **큰 순서**대로 |
| 워드클라우드 | 서술형 텍스트 빈도 | 무의미·저빈도 단어 제외 |

## 6. 시각화 과정 (전 세계 자살률 실습)
1. **수집**: 위키피디아에서 복사.
2. **정제**: 한 셀에 한 정보, 문자→숫자, 불필요 정보 제거, 순위 정렬.
3. **통계 확인**: Min/Max/Mean/Median (예: Total Mean 9.54, Max 82.80 그린란드).
4. **차트화**.

- 전체 파이프라인: 수집 → 관리 → 분석 → 모델링 → 예측 → 시각화. **약 80%의 시간이 전처리**(Forbes 2016).

## 7. 엑셀 시각화 실습
| 실습 | 문제 | 해결 |
|---|---|---|
| 1. 목표 대비 실적 | 꺾은선형은 비교 어려움 | 실제 계열을 막대로 → **콤비네이션 차트** |
| 2. 개수 vs 매출액 | 단위 차이로 무의미 | 매출액에 **보조축** 적용 |
| 3. 추세변동 | 미래 매출 예측 | `Y=a+bX`, INTERCEPT·SLOPE |
| 4. 산점도 | 분포 차이 확인 | DataSaurus 13개 세트 |

- **실습3 예시**: 온라인 매출 = 34.80 + 1.98 × 시간순서 (절편 34.80, 기울기 1.98) → 13월차 예측.

> [!important] 시험 출제 포인트
> - 시스템1(직관) vs 시스템2(논리), 시각정보 **80%**
> - 앤스컴/DataSaurus = 요약통계가 같아도 분포 다름
> - 차트는 **목적(질문)에 따라** 선택 / 차트별 용도 매칭
> - 콤비네이션 차트, **보조축**(단위 다를 때)
> - 추세선 절편=INTERCEPT, 기울기=SLOPE → [[5주차_전체정리]]로 연결
