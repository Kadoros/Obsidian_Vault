# 6주차. 전체정리 📚 — 데이터 리터러시 프로젝트 (중간과제)

> [!summary] 한눈에 보기 (TL;DR)
> 자율 주제로 **수집 → 관리 → 분석 → 시각화** 4단계를 **Excel로** 수행하고, **엑셀 파일 + 보고서 PDF** 2개를 기한 내 제출하는 종합 프로젝트. **중간고사를 대체**한다.

## 1. 과제 성격
- **데이터 리터러시 프로젝트** = 개인 중간과제(20%), **중간고사를 대체**.
- 1~5주차에서 배운 데이터 리터러시 전 과정(수집·관리·분석·시각화)을 실제로 수행하는 종합 과제.

## 2. 진행 4단계
| 단계 | 핵심 활동 | 연결 학습 |
|---|---|---|
| **Ⅰ. 데이터 수집** | 분석 목표/질문 설정, 데이터 수집, 출처 명시 | [[2주차_전체정리]] 수집 |
| **Ⅱ. 데이터 관리** | 텍스트→숫자 변환, 불필요 항목 삭제, 셀 통합 해제(정제) | [[3주차_전체정리]] 테이블 규칙 |
| **Ⅲ. 가공·분석** | 데이터 탐색, 기초통계량(평균·표준편차), 피벗·선형(추세)분석 | [[5주차_전체정리]] 예측 |
| **Ⅳ. 시각화** | 학습한 차트로 시각화, 분석 목표에 대한 답변 도출 | [[4주차_전체정리]] 차트 |

> 예시 주제: "서울에서 1인 가구 대상 아침식사 전문숍을 운영하려면 어느 지역이 좋을까?"
> → 지역별 인구수·점포수·임대시세(상권분석서비스) + 상권 추정매출(공공데이터포털) 수집·분석.

## 3. 규칙
| 항목 | 내용 |
|---|---|
| 주제 | **자율 선정**. 단, **추세·선형 분석**이 가능한 주제·자료 |
| 분석 도구 | **MS-Excel만** (Python 등 불가) |
| 생성형 AI | 사용 가능(감점 없음). 단 **수치 분석은 Excel**로, 사용 시 보고서에 "보고서 작성에 생성형 AI를 활용하였음" 표기 |

## 4. 제출물 (2개 모두)
| # | 파일 | 형식 | 요건 |
|---|---|---|---|
| #1 | 엑셀 활용 자료 | XLSX | 원본·**수식**·분석결과·차트가 그대로 보이게 |
| #2 | 최종 보고서 | PDF (HWP/WORD 작성 후 변환) | A4 **4~5장**(초과 가능), 글꼴·크기 자율 |

- **제출**: e-class "과제 및 평가" 메뉴. 기한 후 제출은 성적에 반영하지 않음.

## 5. 데이터 수집 참고 사이트
| 분야 | 사이트 |
|---|---|
| 공공데이터 | 공공데이터포털(data.go.kr), 서울 열린데이터광장, 서울시 상권분석서비스(golmok) |
| 통계 | KOSIS(kosis.kr), 국가데이터처(통계청), 국세통계포털 |
| 경제·재정 | 한국은행 ECOS, 열린재정 |
| 부동산·관광 | 부동산통계정보(REB), 관광지식정보시스템 |
| 트렌드·뉴스 | 네이버 데이터랩, 빅카인즈, 대학알리미 |

> [!important] 제출 전 최종 체크
> - [ ] 분석 목표/질문 명확, 출처 명시
> - [ ] 정제(텍스트→숫자, 불필요 삭제, 셀 통합 해제)
> - [ ] 추세·선형 분석 등 실습 반영, 수식·피벗·차트가 엑셀에 표시
> - [ ] 보고서 A4 4~5장 PDF, (AI 사용 시) 문구 표기
> - [ ] 기한 내 e-class 제출 (지각 = 미반영)
