# 3주차. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **데이터베이스(DB)** | 특정 목적하에 서로 관련 있는 데이터를 **최소한의 중복**으로 통합한 데이터(정보)의 집합체 |
| **테이블** | 행과 열로 구성된 데이터 집합체 (예: 사원목록, 판매현황) |
| **필드(Field)** | 테이블의 **열**. 하나의 정보 속성 (이름, 지역, 판매년도 …) |
| **레코드(Record)** | 테이블의 **행**. 각 필드에 채워진 구체적 내용 |

## 엑셀 기본 기능
- 셀(Cell)·열(Column)·행(Row)·시트(Sheet)
- 셀 병합, 눈금선, 서식 복사, 셀 서식 `Ctrl+1`(숫자형식·테두리·맞춤)
- 자동 채우기(요일·날짜·월 연속 입력), 틀 고정([보기]-[틀 고정]: 첫 행/첫 열 고정)

## 주소 방식
- **상대주소** `A1`: 수식 복사 시 참조가 함께 이동
- **절대주소** `$A$1`: 행·열 모두 고정 (예: 수당% 셀을 모든 사원에 곱할 때) — **F4**로 전환
- 혼합주소 `$A1`, `A$1`: 한쪽만 고정

## 주요 함수
| 함수 | 기능 |
|---|---|
| AVERAGE | 산술평균 |
| MEDIAN | 중앙값 |
| MODE.SNGL | 최빈값 |
| MAX / MIN | 최대 / 최소 |
| LARGE(범위,n) / SMALL(범위,n) | n번째로 큰/작은 값 |
| RANK.EQ(값,범위) | 순위(석차) |
| **VLOOKUP**(기준값,범위,열번호,논리값) | 검색범위 첫 열에서 기준값 찾아 같은 행의 n번째 열 반환 (False=정확, True=유사) |
| **WEEKDAY**(날짜,타입) | 날짜의 요일을 1~7 숫자로 |

## 테이블 작성 시 주의사항
1. 필드명은 **첫 행에 하나의 행**으로 기입
2. 하나의 열에는 **하나의 정보 속성**만 (이름·직위 분리, 날짜는 '년-월-일' 한 열)
3. 숫자·금액·일자는 **단위를 Text로 쓰지 말고 숫자만** (360000원 X → 360000 O)
4. 대표 필드(학번·사번·아이디)는 가장 **왼쪽**
5. 중간에 **빈 행·빈 열 지양**

## 데이터베이스 관리 3대 기능
- **정렬**: [데이터]-[정렬], 특정 필드 기준 오름/내림차순
- **필터**: [데이터]-[필터], 조건별 추출 (특정 이름, 성씨, 상위 N위, 금액 범위)
- **피벗테이블**: [삽입]-[피벗테이블], 행/열/값 구성으로 교차 집계
  - 값 필드를 한 번 더 추가 → [값 표시 형식]-[총합계 비율]로 **비중(%)** 표시

## 실습 사례 (쁘띠베이커리)
- WEEKDAY + VLOOKUP으로 날짜 → 요일코드 → 요일명 생성
- 피벗테이블(값=평균)로 **요일별 평균 판매량**, 프로모션 유무별 판매량 비교
- 차트: **표식 있는 꺾은선형**으로 시각화
