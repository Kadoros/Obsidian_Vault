# 3주차. 강조포인트 ⭐

## 🔴 엑셀 단축키 (★)
- 전체 선택 `Ctrl+A` · 복사 `Ctrl+C` · 잘라내기 `Ctrl+X` · 붙여넣기 `Ctrl+V`
- 셀 서식 `Ctrl+1` · 끝 셀 이동 `Ctrl+화살표`
- 행-열 바꿈: 복사 후 **선택하여 붙여넣기 → 행/열 바꿈(전치)**

## 🔴 절대주소 vs 상대주소 (★★)
- **상대주소** `A1`: 수식 복사 시 자동 변함
- **절대주소** `$A$1`: 복사해도 고정 (예: 수당 % 10% 셀 고정) → `F4`로 전환

## 🔴 통계 함수 (★)
| 함수 | 기능 |
|---|---|
| AVERAGE | 산술평균 |
| MEDIAN | 중앙값 |
| MODE.SNGL | 최빈값 |
| MAX / MIN | 최대 / 최소 |
| LARGE / SMALL | n번째 큰/작은 값 |
| RANK.EQ | 순위(석차) |

## 🔴 데이터베이스 구성요소 (★★ 단골)
| 용어 | 의미 |
|---|---|
| **테이블** | 행과 열로 구성된 집합체 |
| **필드(열)** | 하나의 정보 속성 (이름, 지역 등) |
| **레코드(행)** | 각 필드에 채워진 구체적 내용 |

## 🔴 테이블 작성 규칙 (★)
- 필드명은 **첫 행에 하나의 행**으로
- 한 열에는 **하나의 정보만** (이름+직위 분리)
- 숫자/금액/일자에 **단위 Text 금지** (360000원 X → 360000 O)
- 대표 필드(학번·사번)는 **가장 왼쪽**, 빈 행/열 지양

## 🔴 VLOOKUP & WEEKDAY (★★)
- `VLOOKUP(기준값, 검색범위, 열번호, 논리값)` — 기준값은 검색범위 **첫 열**에 / False=정확, True=유사
- `WEEKDAY(날짜, 타입)` — 요일을 1~7 숫자로

## 🟥 피벗테이블
- [삽입]-[피벗테이블], 행/열/값 구성으로 집계
- 값 표시 형식 → **총합계 비율**로 비중(%) 표시 가능
