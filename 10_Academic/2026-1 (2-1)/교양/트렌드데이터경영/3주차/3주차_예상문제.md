# 3주차. 예상문제 ✏️

> 답은 `> [!success]- 정답` 토글 안에 숨김.

## ⭕❌ OX 문제

**1.** 테이블에서 열은 레코드, 행은 필드를 의미한다. (   )
> [!success]- 정답
> ❌ — 열 = 필드, 행 = 레코드.

**2.** 금액 데이터는 "360,000원"처럼 단위를 붙여 입력하는 것이 좋다. (   )
> [!success]- 정답
> ❌ — 단위를 Text로 쓰면 계산이 안 된다. 360000처럼 숫자만 입력한다.

**3.** 절대주소는 수식을 복사해도 참조가 고정된다. (   )
> [!success]- 정답
> ⭕ — `$A$1` 형태로 행·열을 고정한다.

## 🔤 빈칸 채우기

**4.** 최빈값을 구하는 함수는 ________, 순위를 구하는 함수는 ________이다.
> [!success]- 정답
> MODE.SNGL / RANK.EQ

**5.** VLOOKUP에서 정확히 일치하는 값을 찾으려면 검색논리값에 ______를 쓴다.
> [!success]- 정답
> False

**6.** 상대주소를 절대주소로 바꾸는 단축키는 ____이다.
> [!success]- 정답
> F4

## 📝 단답·서술형

**7.** 데이터베이스의 정의를 쓰시오.
> [!success]- 정답
> 특정 목적하에 서로 관련 있는 데이터를 최소한의 중복으로 통합해 놓은 데이터(정보)의 집합체.

**8.** 테이블 작성 시 "한 열에는 하나의 정보만" 규칙을 지켜야 하는 이유를 예로 설명하시오.
> [!success]- 정답
> "김하늘, 과장"처럼 이름과 직위를 한 열에 넣으면 이름·직위별 정렬·필터·집계가 불가능해진다. 이름과 직위를 별도 열로 세분화해야 분석이 가능하다.

## 💻 함수 적용

**9.** `VLOOKUP(2, 요일표, 2, FALSE)`가 하는 일을 설명하시오.
> [!success]- 정답
> 요일표의 첫 열에서 값 2를 정확히 찾아, 그 행의 2번째 열 값(예: "화요일")을 반환한다.

**10.** 판매사원별·제품별 판매금액을 한눈에 보려면 어떤 기능을 어떻게 구성해야 하는가?
> [!success]- 정답
> 피벗테이블을 사용한다. 행 레이블=사원, 열 레이블=제품명, 값=합계:판매금액으로 구성하면 사원×제품 교차 집계표가 만들어진다.
