# 3주차. 벼락치기 ⚡ (시험 직전 5분)

## 한 줄 요약
> 엑셀 기본 기능·함수로 데이터를 다루고, 데이터를 **테이블(필드·레코드)** 형태로 정리하는 규칙을 익힌다. 정렬·필터·피벗으로 분석한다.

## 무조건 외울 것
1. DB 구성: **테이블 = 필드(열) + 레코드(행)**
2. 절대주소 `$A$1`(고정) vs 상대주소 `A1`(이동), 전환키 **F4**
3. 통계함수: AVERAGE, MEDIAN, MODE.SNGL, MAX/MIN, LARGE/SMALL, **RANK.EQ(순위)**
4. **VLOOKUP**: 기준값은 검색범위 첫 열, False=정확/True=유사
5. **WEEKDAY**: 날짜 → 요일 숫자(1~7)

## 테이블 작성 규칙 5
- 필드명 = 첫 행 한 줄 / 한 열 = 한 정보 / 단위 Text 금지 / 대표필드는 왼쪽 / 빈 행·열 지양

## 데이터 관리 3대 기능
- **정렬**: [데이터]-[정렬] (오름/내림차순)
- **필터**: [데이터]-[필터] (조건 추출, 상위 N, 범위 조건)
- **피벗테이블**: [삽입]-[피벗], 행·열·값으로 교차 집계 + 비율(%) 표시

## 셀 단축키
- `Ctrl+1`(셀서식), `Ctrl+A`(전체), `Ctrl+화살표`(끝 이동), 행/열 바꿈(전치)
