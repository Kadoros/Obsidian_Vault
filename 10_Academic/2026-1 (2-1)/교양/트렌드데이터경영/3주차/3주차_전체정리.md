## 1. 엑셀 기본 기능
- 구성: **셀(Cell)·열(Column)·행(Row)·시트(Sheet)**.

| 단축키 | 기능 |
|---|---|
| `Ctrl+A` | 전체 선택 |
| `Ctrl+C / X / V` | 복사 / 잘라내기 / 붙여넣기 |
| `Ctrl+1` | 셀 서식(숫자형식·테두리·맞춤) |
| `Ctrl+화살표` | 데이터 끝 셀로 이동 |
| `F4` | 절대주소 ↔ 상대주소 전환 |

- **자동 채우기**: 1월·2월…, 날짜, 요일 등 연속 데이터 자동 입력.
- **행-열 바꿈(전치)**: 복사 후 선택하여 붙여넣기에서 행/열 전환.
- **틀 고정**([보기]-[틀 고정]): 데이터 많을 때 첫 행/첫 열 또는 지정 행·열 고정.

## 2. 수식과 주소 (★)
| 종류 | 표기 | 특징 |
|---|---|---|
| 상대주소 | `A1` | 복사 시 참조가 함께 이동 |
| **절대주소** | `$A$1` | 행·열 모두 고정 (예: 수당% 셀) |
| 혼합주소 | `$A1`, `A$1` | 행 또는 열 한쪽만 고정 |

> 예: 사원별 판매실적 × 수당 10%(고정 셀)를 계산할 때, 수당% 셀을 절대주소로 잡아야 복사해도 어긋나지 않는다.

## 3. 통계 함수
| 함수 | 기능 |
|---|---|
| AVERAGE | 산술평균 (개인평균·과목평균) |
| MEDIAN | 중앙값 |
| MODE.SNGL | 최빈값 |
| MAX / MIN | 최대 / 최소 |
| LARGE(범위,n) / SMALL(범위,n) | n번째 큰/작은 값 |
| **RANK.EQ(값,범위)** | 순위(석차) |

## 4. 데이터베이스 개념 ★
- **DB 정의**: 특정 목적하에 관련 데이터를 **최소한의 중복**으로 통합한 데이터(정보)의 집합체.
- **구성요소**:

| 용어 | 의미 | 예 |
|---|---|---|
| 테이블 | 행·열로 구성된 집합체 | 판매현황 |
| **필드(열)** | 하나의 정보 속성 | 이름, 지역, 판매년도 |
| **레코드(행)** | 각 필드에 채워진 구체적 내용 | "김하늘, 중부, 2017…" |

### 테이블 작성 규칙 (★)
| 규칙 | 잘못된 예 → 올바른 예 |
|---|---|
| 필드명은 첫 행 한 줄 | 제목+필드명 2줄 → 필드명 1줄 |
| 한 열 = 한 정보 | "김하늘, 과장" → 이름 / 직위 분리 |
| 날짜는 한 열 | 년·월·일 따로 → '년-월-일' 한 열 |
| 단위 Text 금지 | 360,000원 → **360000** |
| 대표 필드는 왼쪽 | 학번·사번·아이디를 맨 앞 |
| 빈 행·열 지양 | 중간 빈 줄 제거 |

## 5. 데이터베이스 관리 실습 (지역별 대리점 판매현황)
| 기능 | 경로 | 예시 |
|---|---|---|
| **정렬** | [데이터]-[정렬] | 제품명 기준 오름차순 |
| **필터** | [데이터]-[필터] | '김하늘'만, 성씨 '이'씨, 상위 5위, 30만~100만원 |
| **피벗테이블** | [삽입]-[피벗테이블] | 사원별 총액 / 사원×제품 / 지역×제품 교차 |

- 피벗 값 필드를 한 번 더 추가 → [값 표시 형식]-[**총합계 비율**]로 비중(%) 표시 (백분율·소수 1자리).

## 6. 함수 응용 실습 (쁘띠베이커리)
| 함수 | 구문 | 설명 |
|---|---|---|
| **WEEKDAY** | `WEEKDAY(날짜, 타입)` | 날짜 → 요일 숫자(1~7) |
| **VLOOKUP** | `VLOOKUP(기준값, 범위, 열번호, 논리값)` | 범위 첫 열에서 기준값 찾아 n번째 열 반환 |

- VLOOKUP 핵심: 기준값은 검색범위 **첫 열**에 있어야 하며, **False=정확 / True=유사** 일치.
- 절차: 날짜 → WEEKDAY로 요일코드 → VLOOKUP으로 요일명 매핑 → 피벗(값=평균)으로 **요일별 평균 판매량**, 프로모션 유무별 판매량 비교 → **꺾은선형 차트**로 시각화.
  - (예: 토요일 쿠키 평균 654.7 vs 평일 ~480, 프로모션 시 전 품목 판매량↑)

> [!important] 시험 출제 포인트
> - 테이블 = **필드(열) + 레코드(행)**, DB 정의(최소 중복)
> - 테이블 작성 규칙 (특히 단위 Text 금지, 한 열 한 정보)
> - 절대주소 `$A$1` vs 상대주소, F4
> - VLOOKUP 인수 순서 + False/True 의미
> - 재고/순위 함수: RANK.EQ, MODE.SNGL
