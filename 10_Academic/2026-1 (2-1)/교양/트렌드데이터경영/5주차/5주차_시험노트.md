# 5주차. 시험노트 📝 (개념 정밀 정리)

## 용어 정의

| 용어 | 정의 |
| --- | --- |
| **스파크 라인** | 하나의 셀 안에 표시되는 작은 차트 |
| **CAGR** | 연평균성장률. 매년 일정 성장률(기하평균)을 가정해 환산한 평균 성장률 |
| **이동평균법** | 최근 M개 기간 실적의 평균으로 다음 기간을 예측하는 시계열 기법 |
| **MAE** | 평균절대오차. (실제-예측)의 절대값 평균. 작을수록 좋은 예측 |
| **계절지수** | 해당 계절 평균 ÷ 전체기간 평균. 계절적 변동 반영 지표 |

## 1. 스파크 라인
- [삽입]-스파크라인 → 종류 선택 → 데이터 범위 지정.
- 종류: **꺾은선형**(추세), **열**(막대형), **승패**(양수·음수/위·아래).

## 2. CAGR (연평균성장률)
- 수년간 성장률을 매년 동일하다고 가정한 **기하평균** 성장률.
- 엑셀: `=RATE(기간, 0, -최초값, 최종값)`
  - 예) `=RATE(4, 0, -2020년소득, 2024년소득)`
- 활용: 서울시 업종별 매출 CAGR로 성장/쇠퇴 업종 식별(상·하위 5%).

## 3. 예측(Forecasting) 개요
- 예측은 경영 의사결정의 핵심(매출전망·환율·원자재 등).
- 전제: **과거 실적이 미래에 연장·영향**을 미친다.

### 예측기법 분류
| 분류 | 기법 |
|---|---|
| **정성적(Qualitative)** | 소비자 서베이, 델파이 조사 |
| **시계열분석(Time Series)** | 이동평균법, 지수평활법, 추세변동분석, 계절요인분석 |
| **인과분석(Causal)** | 단순회귀분석, 다중회귀분석 |

## 4. 이동평균법
- `M기간 예측값 = ∑(이전 M개 기간 실적) ÷ M`
- 단순·유용하지만 **최적 M 선택**이 관건.
- 최적 M = **MAE가 최소**가 되는 값.
  - `오차절대값 = ABS(실제값 - 예측값)`, MAE = 오차절대값들의 평균.
- 사례: 강수량 예측 시 3년 vs 7년 → MAE 작은 **7년** 채택.

## 5. 계절요인 분석
- 월·분기 등 **계절적 변동**이 있는 데이터에 사용.
- `계절지수 = 해당 계절 자료 평균 ÷ 전체기간 자료 평균`
- 절차: ① 평균 산출 ② 비율 = 해당분기/평균 ③ 같은 분기끼리 비율 평균 = 계절지수.

## 6. 추세변동 + 계절요인 결합 (킨들 사례)
1. **추세**: `매출 = 절편 + 기울기×시간` (INTERCEPT·SLOPE) → 예: 302.38 + 9.83×시간.
2. **계절지수**: 월별 실제/평균 비율을 같은 월끼리 평균.
3. **결합**: `계절 고려 예상 = 추세 예상 × 계절지수`.
   - 여름(비수기) 낮고 11~12월(성수기) 높은 변동을 반영해 장기 예측.

## 차트 작성 팁
- Y축 최소값 조정(예: 600)으로 변동 부각, X축 텍스트 45도 회전, 선 색상 구분.
