# 5주차. 전체정리 📚 — 데이터 시각화 실습 및 확장

## 1. 스파크 라인 (Spark Line)
- **하나의 셀 안에 그리는 작은 차트**. 표 옆에서 추세를 즉시 파악.

| 종류 | 표현 |
|---|---|
| 꺾은선형 | 데이터 추세 |
| 열 | 막대 형태 |
| 승패 | 양수·음수 / 위·아래 부동값 |

- 생성: 셀 클릭 → [삽입]-스파크라인 종류 선택 → 데이터 범위 지정.

## 2. 연평균성장률 (CAGR)
- 수년간 성장률을 **매년 일정(기하평균)**하다고 가정해 환산한 평균 성장률.
- 엑셀: `=RATE(기간, 0, -최초값, 최종값)`
  - 예) 2020~2024(4년): `=RATE(4, 0, -2020값, 2024값)`. (최초값에 **음수** 주의)
- **활용**: 서울시 업종별 매출 CAGR로 성장/쇠퇴 업종 식별.

| 업종 | CAGR | 해석 |
|---|---|---|
| 골프연습장 | +27.7% | 고성장 |
| 당구장 | +21.3% | 고성장 |
| 핸드폰 | -11.4% | 쇠퇴 |
| 컴퓨터·주변장치 | -7.8% | 쇠퇴 |
- 상·하위 5% 확인으로 트렌드 업종 도출.

## 3. 예측(Forecasting)
- 경영 의사결정의 핵심(매출전망·환율·원자재 가격 등).
- **전제**: 과거 실적이 미래에 연장·영향을 미친다.

### 예측기법 분류 ★★
| 분류 | 기법 |
|---|---|
| **정성적(Qualitative)** | 소비자 서베이, 델파이 조사 |
| **시계열분석(Time Series)** | 이동평균법, 지수평활법, 추세변동분석, 계절요인분석 |
| **인과분석(Causal)** | 단순회귀분석, 다중회귀분석 |

## 4. 이동평균법 (Moving Average)
- 최근 **M개 기간 실적 평균**으로 다음 기간 예측.

$$\text{M기간 예측값} = \frac{\sum(\text{이전 M개 기간 실적})}{M}$$

- 단순·유용하지만 **최적 M 선택**이 관건.
  - `오차절대값 = ABS(실제 - 예측)`, **MAE = 오차절대값들의 평균**.
  - **MAE가 최소**인 M이 최적.
- **강수량 예측 사례**: 1973~2021 자료로 2022 예측. 3년 vs 7년 비교 → MAE 작은 **7년** 채택. 실제·3년·7년 이동평균을 한 차트로 비교 (Y축 최소 600).

## 5. 계절요인 분석
- 월·분기 등 **계절적 변동**이 있는 데이터에 적용.

$$\text{계절지수} = \frac{\text{해당 계절 자료 평균}}{\text{전체기간 자료 평균}}$$

- 절차(입사지원 사례, 전체평균 1,175):
  1. 평균 지원자 수 산출.
  2. 비율 = 해당분기 / 평균.
  3. 같은 분기끼리 비율 평균 → 계절지수.

| 분기 | 계절지수 | 의미 |
|---|---|---|
| 1/4 | ≈1.29 | 성수기 |
| 2/4 | ≈0.53 | 비수기 |
| 3/4 | ≈0.32 | 최저 |
| 4/4 | ≈1.86 | 최고 성수기 |

## 6. 추세변동 + 계절요인 결합 (아마존 킨들)
킨들은 여름 비수기, 11~12월 성수기. 장기 매출 변동 예측:
1. **추세**: `매출 = 절편 + 기울기×시간` (INTERCEPT 302.38, SLOPE 9.83).
2. **계절지수**: 월별 실제/평균(425) 비율을 같은 월끼리 평균 (예: 11월 ≈ 2.08, 7월 ≈ 0.40).
3. **결합**: `계절 고려 예상 = 추세 예상 × 계절지수`.

| 시점 | 추세 예상 | 계절지수 | 계절 고려 예상 |
|---|---|---|---|
| 2023.1 | 548 | 1.29 | ≈ 704 |
| 2023.11 | 646 | 2.08 | ≈ 1,344 |
| 2023.7 | 607 | 0.40 | ≈ 243 |

## 7. 차트 작성 팁
- Y축 최소값 조정(예: 600)으로 변동 부각.
- X축 텍스트 45도 회전, 세로 맞춤 가운데.
- 선 색상 구분으로 계열 차별화.

> [!important] 시험 출제 포인트
> - **CAGR = RATE(기간, 0, -최초값, 최종값)** (기하평균)
> - 예측 3분류 + 각 기법 소속(델파이=정성, 회귀=인과)
> - 이동평균 최적 M = **MAE 최소**
> - 계절지수 = 해당 계절 평균 ÷ 전체 평균
> - 계절 고려 예상 = **추세 × 계절지수** (계산 문제 대비)
