# 11주차 시험노트: 성균관

## 1. 관학(官學) vs 사학(私學) — 비교

| 구분 | 관학(官學) | 사학(私學) |
|---|---|---|
| 운영 주체 | 국가(정부) | 개인 |
| 비용 | 국비 지원(등록금 無) | 자비 부담 |
| 해당 기관 | 성균관, 사학(四學/사부학당), 향교 | 서당, 서원 |
| 단계 | 성균관(고등) - 사학·향교(중등) | 서당(초등), 서원(중등+α) |
| 기타 기능 | - | 서원: 도서관 + 사림 여론 결집 거점(16세기 이후) |

- **헷갈리기 쉬운 포인트**: "사학(私學)"과 "사학(四學)"은 한자도 발음도 다름!
  - **사학(四學)** = 사부학당 = 한양의 중부·동부·서부·남부학당 → **관학**에 속함
  - **사학(私學)** = 서당·서원 → 개인이 세운 **사립** 교육기관
- **향교**: 군현마다 1개씩, **일읍일교(一邑一校)** 원칙. 중등교육기관, 관학.
- **서원**: 16세기 이후 본격화. 사림의 여론 결집 거점 + 도서관 기능. 주세붕이 세운 백운동서원(소수서원)이 시초로 거론됨.

## 2. 성균관(成均館) 핵심 정보

### 2-1. 명칭 (한자 병기 필수!)
- 태학(太學), 반궁(泮宮), 근궁(芹宮), 현관(賢關), 수선지지(首善之地)
- 공통점: "인재 배양 + 풍속 교화"의 이념 담김

### 2-2. 연혁 (연도 암기)
| 연도 | 사건 |
|---|---|
| 1394년(태조 3) 10월 | 문묘·성균관 건립 **지시** |
| 1397년 | 숭교방에 본격 건축 **시작** |
| 1398년 7월 | **완성** |
| 1400년 | **소실** |
| 태종 대 | 재건(중건) |
| **성종 대** | **전성기** (존경각=도서관 완성, 서적 지원) |
| 연산군 대 | 탄압 (대성전에 호랑이 사건 등) |
| 임진왜란~선조 대 | 소실 → 중건 |
| **정조 대** | **대대적 중수** |

### 2-3. 성균관 관원의 이중 역할
- 성균관 관원 = ① 사부학당 교육 담당 + ② 과거 시험 출제위원
- 인기 관원의 강의는 유생들이 연장을 청원하기도 함 (사례: 중종 대 대사성 **유숭조**)

## 3. 입학 자격과 신분 구분

| 신분 | 자격 요건 | 비용 부담 | 비고 |
|---|---|---|---|
| **상재생(上齋生)** | 생원시·진사시 합격자 | 국비(무상) | 성균관 정식 유생 |
| **청강생(聽講生)** | 합격 없이 청강 | 자비(사량기재) | 정식 유생과 구분 |

- **생원시**: 사서오경 등 경학(經學) 시험 → 강경 위주
- **진사시**: 문장 작성(제술) 시험 → 제술 위주
- 응시자는 본인의 강점(경학 vs 문장)에 따라 둘 중 선택
- 성균관 입학 자격은 정해져 있지만 **졸업(재학연한) 규정은 없음** → 70대까지 재학 가능

## 4. 원점(圓點) 제도 — 작동 방식 (시험 빈출!)

```
아침 식당 출석 + 저녁 식당 출석 → 원점 1점
30일(1개월) 개근 → 약 30점
10개월 개근 → 300점
원점 300점 이상 → 館試(관시) 응시 자격 획득
```

- **관시(館試)**: 성균관에서 자체적으로 실시하는 과거 관련 시험(응시 자격을 위한 통과 절차)
- **부정행위 문제**: 원점을 채우기 위해 식사를 거를 때 동료에게 대리 출석(원점 표시)을 부탁하는 폐단 발생
  - 예: 100인분 식사 준비 → 실제 식사 인원 20명인데 출석부엔 100명 표시
- **대응책**: 성균관 관원이 직접 인원을 점검, 실제 식사 인원과 출석부 대조 후 도장 날인

## 5. 교육과정: 강경(講經) vs 제술(製述)

| 구분 | 일강(日講) | 통독(通讀) | 순제(旬製) |
|---|---|---|---|
| 분류 | 강경 | 강경(개편형) | 제술 |
| 주기 | 매일 | 정해진 날(부정기) | 열흘마다(초·중·하순) |
| 방식 | 경서 강독 | 관원+유생이 한 텍스트를 함께 읽고 해석(세미나식) | 글짓기(작문) 시험 |
| 담당 | - | 대사성(정3품) 이하 관원 + 유생 | - |
| 변천 | **폐지됨** → 통독으로 전환 | 일강 대체 | 문과 시험 과목과 연계 |

- **헷갈리기 쉬운 포인트**:
  - "일강 → (폐지) → 통독"의 흐름을 순서대로 기억할 것
  - 통독은 "세미나식 윤독"이라는 점이 핵심 — 단순 암기 확인이 아님
  - 순제는 "旬(열흘 순)" 한자에서 주기를 추론 가능

### 강경 채점 등급 (구술시험)
| 등급 | 한자 | 의미 | 합격 여부 |
|---|---|---|---|
| 통 | 通 | 완전 통과 | 합격 |
| 약 | 略 | 약간 부족하나 통과 | 합격 |
| 조 | 粗 | 최소 수준 | **불합격** |
| 불 | 不 | 통과 못함 | **불합격** |

→ "통·약"은 합격, "조·불"은 불합격으로 암기.

## 6. 성균관 유생의 정치활동: 유소(儒疏)

| 용어 | 한자 | 의미 |
|---|---|---|
| 유소 | 儒疏 | 유생들이 집단으로 왕에게 올리는 상소 |
| 장의 | 掌議 | 성균관 유생 대표(오늘날의 학생회장 격) |
| 권당 | 捲堂 | 식당 출석 거부(동맹 단식·항의의 1단계) |
| 공관 | 空館 | 성균관을 비우고 떠남(동맹휴학에 해당, 2단계) |

- 항의 단계: **유소 제출 → (받아들여지지 않으면) 권당 → (그래도 안되면) 공관**
- 유생은 미래의 관료(예비 관료)로서 국정에 대한 발언권을 인정받았음

## 7. 성균관 유생의 숙식

| 구분 | 내용 |
|---|---|
| **동재(東齋)** | 기숙사. 전언상 소론·남인·동인 계열 유생이 주로 거처 |
| **서재(西齋)** | 기숙사. 전언상 노론 계열 유생이 주로 거처 |
| **반촌(泮村)** | 성균관 인근 마을. 일부 유생이 하숙 |
| 식사·원점 | 아침·저녁 식당 출석 = 원점 부여 시점 |
| 특식 | 1·6일=대별미(大別味), 3·8일=소별미(小別味), 삼복 특식(닭/참외/수박 등) |
| 술 | 원칙적 반입 금지, 명절 등 예외적 허용 |
| 사료 | 윤기 『반중잡영(泮中雜詠)』 — 성균관 식단·생활 기록 |

## 8. 사례 연결 — 이정보(李鼎輔) 호패
- **나무 호패(유생 시절)**: 앞면 "東部 李鼎輔 癸酉生 東學生" / 뒷면 "壬辰 崇敎坊 一契 第六統 第四家"
- **상아 호패(관직 진출 후)**: 앞면 "李鼎輔 癸酉生 壬子文科" / 뒷면 "戊辰-"
- 포인트: 호패의 재질(나무→상아)이 신분(품계) 변화를 반영, 호패 기록으로 학적(동학생)·과거 합격 시점(임자문과)까지 추적 가능
