# 12주차 시험노트 - 조선의 과학수사 『無寃錄』

## 1. 핵심 키워드 한 줄 정의

| 용어 | 한자 | 정의 |
|---|---|---|
| 검험(檢驗) | 檢驗 | 시신을 검사하는 검시 절차 전반 |
| 검안(檢案) | 檢案 | 검시문안(檢屍文案)의 줄임말. 시체검안서+심문기록+발사+시장식을 포함한 일체의 조사보고서 |
| 시장(屍帳) | 屍帳 | 알몸이 된 시신의 상태를 기록한 법의학적 검시서 (오늘날 부검소견서 격) |
| 발사(跋辭) | 跋辭 | 수령의 최종 판결 의견서 (사망원인+처벌방향, 오늘날 판결문) |
| 응용법물(應用法物) | 應用法物 | 검시에 활용하는 도구·재료(술, 식초, 소금, 닭, 은비녀, 감초즙 등) |
| 부민척리(府民戚里) 회피 | - | 수령이 사건 관련자와 친인척이면 검시 배제, 인근 수령이 대신 검시 |
| 면검권(免檢權) | 免檢權 | 양반 여성이 시신 검시(특히 옷을 벗기는 절차)를 면제받을 수 있는 권리 (평민 여성에게는 없음) |

## 2. 무원록 계보 - 헷갈리기 쉬운 서명·연도 정리

```
[송대]  洗寃錄(세원록) ─┐
       平寃錄(평원록) ─┼─→ [원대, 왕여 편찬] 無寃錄(무원록)
                        │
                        ▼
              [1438, 세종] 新註無寃錄(신주무원록)  ← 조선식 주석(註) 추가
                        │
                        ▼
              [1748, 영조] 增修無寃錄(증수무원록)  ← 조선 실정에 맞게 약재 등 증보
                        │
                        ▼
              [1792, 정조] 增修無寃錄諺解(증수무원록언해) ← 한글 풀이
```

| 서명 | 연도 | 시기 | 핵심 포인트 |
|---|---|---|---|
| 洗寃錄(세원록) | - | 송대 | 무원록의 원전 ① |
| 平寃錄(평원록) | - | 송대 | 무원록의 원전 ② |
| 無寃錄(무원록) | - | 원대(왕여 편찬) | 세원록·평원록의 우수한 점을 뽑아 편찬 |
| 新註無寃錄(신주무원록) | **1438** | 세종대 | 조선이 처음 들여와 **주석**을 단 책 (몽골어+한문 혼용으로 어려운 원문 해설) |
| 增修無寃錄(증수무원록) | **1748** | 영조대 | 조선에서 안 나는 약재 등을 **조선 실정에 맞게 교체·증보** |
| 增修無寃錄諺解(증수무원록언해) | **1792** | 정조대 | **한글(언문)로 풀이** - 더 많은 사람이 활용 가능 |

> 암기 팁: **세평무신증증언** (세원록-평원록 → 무원록 → 신주무원록(1438) → 증수무원록(1748) → 증수무원록언해(1792))
> 연도순: 1438 < 1748 < 1792 (세종 → 영조 → 정조)

- 정조대 형사판례집: **『審理錄(심리록)』** (검안과 함께 검험 절차가 나타나는 사료)

## 3. 검안(檢案)의 4가지 구성요소 비교표

| 구성요소 | 한자 | 작성자/내용 | 비유 |
|---|---|---|---|
| ① 사건의 개요와 조사경위 | - | 사건 발생일시·경위, 보고체계, 목격자 정보 | 사건 보고서 서두 |
| ② 관련자 심문기록 | - | 사건 관련자 진술을 **이두(吏讀)**로 그대로 기록(윤색 금지) | 진술조서 |
| ③ 발사(跋辭) | 跋辭 | **수령**의 최종 판결 - 사인 + 처벌(예: 곤장 100대) | 오늘날 **판결문** |
| ④ 시장식(屍帳式) | 屍帳式 | 알몸 시신 상태 기록, 사람 그림에 상처 표시 | 오늘날 **법의학 부검소견서** |

> ③+④ 합쳐서 "법의학자의 검안서 + 판사의 판결문"이 결합된 것이 바로 **검안**

## 4. 응용법물(應用法物) 정리표

| 법물 | 용도 | 과학성 |
|---|---|---|
| 닭 | 시신 입에 밥을 채웠다가 닭에게 먹여 닭이 죽으면 독살 판정 | 부작용(닭 사체 섭취로 2차 사망)으로 사용 중단 |
| 은비녀 | 인후/콧구멍에 넣었다 빼서 변색되면 독살 판정 | **오늘날도 통용** (단, 식초·산성 음식에도 변색 가능 - 한계 있음) |
| 감초즙 | 의심 부위에 발라 1시간 후 숨은 상처 확인 | 비교적 합리적 |
| 술/지게미/식초/소금/산초/파/매실 등 | 시신을 부드럽게 하거나 닦아 상처 노출 | 화학적 시료 처리에 해당 |
| 숯+거적+물 | 굳은 시신을 부드럽게 만드는 절차 (1시간 경과 후 살이 부드러워짐) | 합리적 |
| 관척(官尺) | 상처 크기 측정 도구 | 측정 도구 |
| 들보의 먼지 흔적 | 자살/타살 구분 - 한 줄 흔적이면 위장(타살) 가능성 | 합리적 |
| 합혈법(合血法) | 형제 여부를 피를 섞어 판정 | **비과학적** |
| 적골법(滴骨法) | 뼈에 피를 떨어뜨려 친자 확인 | **비과학적** |

> 시험 포인트: "은비녀를 통한 중독 판정"과 "합혈법/적골법"을 **과학적 vs 비과학적**으로 구분하는 문제 출제 가능성 높음

## 5. 안색(顔色)에 따른 사인 추정표

| 안색 | 추정 사인 |
|---|---|
| 검은색/자흑색 | 독살(毒殺) 의심 |
| 얼굴이 심하게 부음 | 두부 손상 |
| 목 부위 핏자국 | 교살/액사(목맴) |
| 노란색 | 황달 등 다른 사인 |

- 핵심 원리: **부검(해부) 없이 육안 관찰**로 사인 추정 (무원록 검시의 근본 원칙)
- 사례: **소현세자** 시신 - 몸 전체가 검은색, 일부만 검은천으로 가려짐 → 독살 가능성 시사

## 6. 검안 작성·보고 절차 (1차~다차)

```
사건 발생 → 고발(인장/연장) → 1차 검시(사또+오작) → 시장 작성
   → 2차 검시(인근 고을 사또, 결탁 방지) 
   → (불일치 시) 3차 → 4차 → 최대 5차 사례 존재
   → 관찰사 보고 → 형조 보고 → 국왕 재가
   (정조는 직접 검토 → 『심리록』 편찬)
```

- **부민척리 회피**: 수령이 친인척 관련 사건이면 인근 수령이 대신 검시
- **시장 3부**: ① 검시관 보관 ② 가족 전달 ③ 상부 보고
- **여성 검시 차등**: 양반 여성 = 면검권(O), 평민 여성 = 면검권(X, 전원 검시)

## 7. 영·정조대 법률 정비 흐름

| 시기 | 내용 |
|---|---|
| 영정조 이전 | 사적 제재(私刑) 만연, 양반의 사적 처벌 묵인 |
| 영조·정조대 | 법률 대폭 정비·증보(증수), 사적 제재 금지 → **공적 제재** 강화, 신문(고문) 부위·규격·횟수 법으로 명시 |
| 1748 | 증수무원록 |
| 1792 | 증수무원록언해 |
| 1905 | 최초의 근대 법전(사법행정 분리 시작) |
| 1908 | 수령의 재판권 **완전 상실** |

## 8. 검안에 나타난 조선후기 사회상 - 사례 정리

### ① 가정폭력·강간·명예살인
| 사례 | 연도/지역 | 내용 |
|---|---|---|
| 김은하 사건 | 1882년, 신천 | 정을 통했다는 누명 → 오빠가 명예살인 |
| 김아끈 사건 | - | 처가 외간남자와 정을 통했다 의심 → 남편+시동생이 살해 |
| 이연 사건 | 강원도 안협 | 친척 관계 여성 살해 |

- 메커니즘: 거짓 소문(정을 통했다는 소문) → 여성의 명예 실추(소박 위협) → 명예살인 또는 자살

### ② 신분질서 해체
- **1797년(정조대), 충청도 영기**: 가난한 양반 박씨가 부유한 상민의 딸과 혼인 시도 → 거절당하자 강간했다는 거짓 소문 유포 → 처녀 자살
- 박씨 진술: "양반이지만 가난하여 천민과 다름없다"
- → **신분과 경제력의 불일치** + **반상 통혼 시도** = 신분질서 해체의 단적 사례

## 9. 가상 사례를 통한 정리 (강의 중 다큐 형식 사례)

- 황씨 부인 사망 사건: 정의문이라는 인물의 집 앞에서 사망
- 들보의 먼지 흔적이 **한 줄로만** 남음 → 자살 위장(타살) 가능성 제기
- 남편이 "처가 정의문과 간음 후 자살했다"고 주장했으나, 들보 흔적의 부자연스러움으로 **타살(남편이 범인)**로 결론
- 시사점: 자백보다 **객관적 물증(들보 먼지 흔적 등) 확보가 우선**되어야 한다는 원칙
