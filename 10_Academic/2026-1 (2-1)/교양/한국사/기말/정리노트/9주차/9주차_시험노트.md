# 9주차 시험노트 - 임진왜란과 재조지은(再造之恩)

## 1. 핵심 개념: 재조지은(再造之恩)
- **뜻**: '다시(再) 만들어준(造) 은혜(恩)' — 명나라가 임진왜란 때 조선을 도와줘서 "거의 망할 뻔한 나라를 다시 세워줬다"고 주장하는 논리
- **왜 중요한가**: 이후 조선 정치사 전체를 관통하는 키워드.
  - 광해군 시기: 명의 원병 요청을 거절하지 못하게 만드는 압박 논리
  - 인조반정 이후: '친명배금' 노선의 명분적 근거 → **10주차 호란**의 배경
- **다른 개념과의 관계**: 명이 임진왜란 참전을 정당화하는 명분(=동원지역) ↔ 광해군의 등거리외교(현실론)는 이 명분론을 거스르는 노선이었기 때문에 갈등 발생

## 2. 임진왜란 삼국 명칭 비교 (★빈출)
| 국가 | 명칭 | 한자 | 핵심 키워드 |
|---|---|---|---|
| 조선 | 임진왜란 | 壬辰倭亂 | 왜(倭)가 일으킨 난(亂) |
| 명 | 동원지역 | 東援之役 | 동국(조선)을 도운 전쟁 → 재조지은과 연결 |
| 일본 | 문록의 역 | 文禄の役 | 일본 연호(분로쿠) 사용 |

- **출제 포인트**: "명나라의 입장에서 임진왜란을 부르는 명칭은?" → 동원지역(東援之役). "이 명칭이 함의하는 논리는?" → 재조지은

## 3. 가도입명(假道入明)
- 도요토미 히데요시의 발언: "**길을 빌려(假道) 명나라로 들어가겠다(入明)**"
- **왜 중요한가**: 임진왜란이 단순히 조선만을 노린 전쟁이 아니라 **명 정벌이 최종 목표**였음을 보여줌 → 명이 참전할 수밖에 없었던 직접적 이유
- 헷갈리기 쉬운 점: '가도'는 "길을 빌리다"이지 "거짓 길"이 아님 (假=빌리다)

## 4. 붕당 계보 정리 (★최빈출)

### 동서분당(東西分黨, 1575)
| 항목 | 내용 |
|---|---|
| 발생 연도 | 1575년 (광해군 출생 연도와 같은 해) |
| 발단 | 이조전랑(吏曹銓郞) 후임 인선 갈등 |
| 쟁점 인물 | 심충겸(심의겸의 동생, 명종비 인순왕후의 동생=외척) |
| 동인(東人) | 외척 등용 반대(원칭/원칙론) → 영남 출신 다수, 소배당(젊은층) |
| 서인(西人) | 외척이라도 능력 있으면 등용 → 기호(경기·충청) 출신 다수, 선배당(연장자) |

### 이조전랑(吏曹銓郞)이 왜 핵심 쟁점이었나
- 이조(吏曹) = 6조 중 **인사(관리 선발·인사고과)** 담당 (병조=군사와 구분 주의!)
- 이조전랑(정랑+좌랑, 정5~6품): 품계는 낮지만 **삼사(홍문관·사헌부·사간원) 인사에 강한 영향력**
- 삼사 = **왕을 견제하는 언론 기구** → 이조전랑을 장악하는 것이 곧 정국 주도권 장악

### 붕당 계보도 (★표로 암기)
| 대분류 | 중분류 | 소분류 | 비고 |
|---|---|---|---|
| 동인 | 북인 | **대북** | **광해군 옹립** (정인홍, 이이첨, 이경전) |
| 동인 | 북인 | **소북** | **영창대군 옹립** |
| 동인 | **남인** | - | 광해군대 연립정국에 등용 (이원익, 이항복, 이덕형) → 후대 북학파·실학과 연결 |
| 서인 | - | - | **인조반정** 주도 |
| 서인 | (이후 분화) | **노론** | 송시열 |
| 서인 | (이후 분화) | **소론** | - |

- **헷갈리기 쉬운 포인트**:
  - "대북=광해군 지지" / "소북=영창대군 지지" → 이름이 비슷해서 혼동 주의
  - 광해군 즉위 후에도 대북만 중용한 게 아니라 **남인을 적극 등용**(연립정국) → 시험에서 "광해군이 자신을 옹립한 대북만 등용했다"는 진술은 **틀린 설명**

## 5. 광해군의 즉위 과정

| 시점 | 사건 |
|---|---|
| 1575 | 광해군 출생 (선조의 서자, 둘째 아들, 모친 공빈 김씨) |
| 1592.4.13 | 임진왜란 발발 |
| 1592.4.29 | **왕세자 책봉** |
| 1592.6.14 | **분조(分朝) 활동 시작** (인사권·상벌권 위임받음) |
| 1602 | 선조, 인목왕후와 혼인 (계비) |
| 1606 | **영창대군 출생** (정비 소생 적자=대군) |
| 1608.2.1 | 선조 붕어 |
| 1608.2.2 | **광해군 즉위 (34세)** |

- **왜 광해군이 세자가 될 수 있었나**: 본래 서자+둘째라 계승서열 매우 불리. 그러나 ① 선조에게 적자(대군)가 없었고 ② 임진왜란 발발로 후계자를 즉시 정해야 하는 비상상황 ③ 형 임해군의 평판 문제 → 광해군이 세자로 결정
- **명나라의 세자 책봉 미승인(1592~1608, 약 16년)**: 명 황실도 황후 소생 적자가 없어, 조선이 서자를 세자로 인정하면 명 자신의 후계 문제에도 영향 줄 것을 우려해 추인을 미룸
- **영창대군의 등장(1606)이 만든 균열**: 정통성 있는 적자(대군)의 탄생 → 광해군의 지위를 명분상 위협 → 이후 계축옥사의 배경

## 6. 명·청 교체와 등거리외교

| 개념 | 설명 |
|---|---|
| 누르하치 | 1580년대부터 여진 부족 통합 |
| 후금(後金) 건국 | **1616년(광해군 8년)** |
| 후금 → 청(淸) 국호 변경 | **1636년** (인조 14년, 병자호란 발발 연도와 동일! 같은 정치체) |
| 등거리외교(等距離外交) | 명·후금 사이에서 어느 한쪽에 치우치지 않고 같은 거리를 유지하는 외교 |

- **광해군이 등거리외교를 할 수 있었던 배경**: 분조 활동 시기 평안도·압록강 인근(여진과의 접경)에 머물며 누르하치 세력에 대한 **현장 정보·식견을 직접 축적**했기 때문 → 다른 왕들과 달리 궁궐 밖/현장 경험이 풍부한 이례적 군주
- **다른 개념과의 관계**: 등거리외교(공) ↔ 인조반정 세력은 이를 "사대 의리를 저버린 것"(과)으로 재해석 → 친명배금(親明排金) 노선으로 전환 → 10주차 호란

## 7. 사르후 전투(1619)와 강홍립

| 항목 | 내용 |
|---|---|
| 배경 | 후금이 명의 요충지 **무순(撫順)** 함락 → 1619년 명에 선전포고 |
| 명의 요구 | 조선에 원병 파병 요청 (재조지은 명분 동원) |
| 광해군 입장 | 파병 최소화/회피 시도 (전쟁 후유증 미회복을 명분으로) |
| 비변사 관료 입장 | "소국이 대국에 이래라저래라 할 수 없다", 사대명분론 강조 → 적극 파병 주장 |
| 파견 인물 | **강홍립** (도원수) — 문과 출신, 어전통사(중국어 통역) 경력 |
| 결과 | 1619년 **사르후 전투**에서 조선군이 **후금에 투항** |

- **강홍립 인선의 의미**: 무관이 아닌 외교 협상력 있는 문관 통역 출신을 보냄 → 처음부터 '명에는 파병했다는 명분, 후금에는 적대하지 않았다는 명분' 둘 다 챙기려는 의도로 해석됨 (단, 광해군의 직접 지시를 명시한 사료는 없음)
- **왜 중요한가**: 등거리외교의 **실제 사례**이자, 이후 인조반정 세력이 광해군을 비판하는 **핵심 근거**(명에 대한 의리를 저버렸다)
- **출제 포인트**: "강홍립이 파병된 군대는 어느 전투에서 후금에 투항했는가?" → 사르후 전투(1619)

## 8. 광해군의 공(功) - 표로 정리
| 공적 | 핵심 내용 | 시험 포인트 |
|---|---|---|
| 등거리외교 | 명분보다 정세 판단, 명에 대한 일방적 사대 거부 | 인조반정 세력은 이를 '과'로 재평가 |
| 연립정국 운영 | 당파 불문 인재 등용, 남인(이원익·이항복·이덕형) 삼정승 임명 | 대북=옹립세력이지만 남인도 중용했다는 점 주의 |
| 대동법 실시 | 공납(방납)의 폐단 시정, 토지 결수 기준 부과 | 방납의 폐단(원가의 몇 배 폭리) 설명 가능해야 함 |
| 동의보감 반포 | 허준 저술, 전국 수령에 배포 | 수령의 의료행정 보조 역할과 연결 |
| 사고(史庫) 정비 | 임란으로 소실된 사고 재정비, 분산 보관 | 신형 화포 개발(국방 강화)과 함께 출제 가능 |

### 대동법 핵심 - 방납(防納)의 폐단
- 기존: 지방 특산물(공납)을 직접 구하기 어려운 백성을 대신해 상인이 구해주고 **몇 배의 대가**를 요구 → 백성 부담 심화
- 개혁: 현물 대신 **토지 결수 기준 쌀(또는 베·동전)** 납부 → "선혜법(宣惠法)"이라고도 불림
- **추진 인물**: **이원익**(남인) — 광해군대 영의정

## 9. 광해군의 과(過) - 표로 정리
| 잘못 | 핵심 내용 | 시험 포인트 |
|---|---|---|
| 폐모살제(廢母殺弟) | 인목대비 폐위(서궁 유폐) + 영창대군(8세) 사사 | 1613년 계축옥사가 직접 원인 |
| 무리한 궁궐 영건 | 임란으로 소실된 궁궐(법궁 등) 재건에 과도하게 집착, 재정 파탄 | 공명첩, 속죄은 등 무리한 재정 확보 수단과 연결 |

### 계축옥사(癸丑獄事, 1613) - 사건의 본질 변질 과정 (★중요)
1. **원래 사건**: 명문가 서얼들의 **'서얼허통(庶孼許通)'** 요구 (서얼도 관직 진출 허용 요구)
2. **비화**: 대북 세력(이이첨 등)이 이를 **"영창대군 옹립을 위한 역모"**로 확대·조작
3. **배후 지목**: 인목대비의 친정아버지 **김제남**이 사주했다는 혐의
4. **결과**:
   - 김제남 등 인목대비 친정 멸문
   - 인목대비 → 서궁 유폐 (폐위)
   - 영창대군(8세) 사사
- **왜 중요한가**: 사건의 본질(서얼허통)과 결과(폐모살제)가 완전히 다른 layer라는 점, 그리고 이것이 인조반정의 핵심 명분(패륜)이 된다는 점

### 궁궐 영건과 재정 확보 수단
- **공명첩(空名帖)**: 이름을 비워둔 관직 임명장을 판매하여 재정 확보
- **속죄은(贖罪銀)**: 죄를 지은 자가 은을 바치면 죄를 면제 (면죄부 성격)
- 학계 해석: 광해군이 궁궐 '크기'에 유난히 집착 → 서자 출신·정통성 시비에 따른 **왕권 강화 강박/콤플렉스**로 해석

## 10. 정묘호란 vs 병자호란 (예고 - 10주차 본격 학습, 9주차에서는 흐름만)
| 구분 | 정묘호란(1627) | 병자호란(1636) |
|---|---|---|
| 상대국 | 후금 | 청(국호 변경 후) |
| 배경 | 인조반정 후 친명배금 노선 | 청의 군신관계 요구 거부(척화) |
| 9주차에서의 위치 | 다루지 않음 | 다루지 않음 |
- 9주차에서 기억할 것은 **"광해군의 등거리외교 → 인조반정의 친명배금 비판 → 호란으로 이어지는 흐름"**의 인과관계 정도. 세부 비교는 10주차 노트 참고.

## 11. 인조반정으로의 연결 (간단히)
- 인조반정(1623) 세력은 광해군의 '공'(등거리외교)을 **"사대 의리 저버림"**으로, '과'(폐모살제)를 **패륜**으로 규정 → 반정의 명분으로 사용
- 새 정권의 외교 노선: **친명배금(親明排金)** — 명을 가까이하고 후금을 배척
- → 결과적으로 정묘호란·병자호란을 자초하는 배경이 됨 (10주차에서 본격 학습)
