# 13주차 시험노트 — 일제의 고적조사사업과 간송 전형필

## 1. 헷갈리기 쉬운 시기 구분 비교

### (1) 일제강점기 4시기 구분 vs (2) 고적조사사업 3단계 구분
→ **두 구분은 서로 다른 기준이며, 시기가 일부 겹친다.** 시험에서 혼동하기 쉬우므로 반드시 구분해서 암기.

| 구분 기준 | 시기 구분 (일제강점기 통치방식) | 시기 구분 (고적조사사업) |
|---|---|---|
| 1단계 | 식민통치 준비기 (1894~1910) | 고건축·고적조사시기 (1902~1915, 세키노 다다시 주도) |
| 2단계 | 무단통치 구축기 (1910~1919) | **고적조사위원회 설립·고적조사사업 (1916~1930)** |
| 3단계 | 문화통치 표방기 (1919~1931) | (2단계와 일부 겹침) |
| 4단계 | 민족말살정책 강행기 (1931~1945) | 조선고적연구회 중심 사업 (1931~1945) |

**암기 포인트**
- 일제강점기 구분의 분기점: **1910(병합)** / **1919(3·1운동)** / **1931(만주사변)**
- 고적조사사업 구분의 분기점: **1916(고적조사위원회 설립)** / **1931(조선고적연구회로 전환)**
- 1902~1915는 "세키노 다다시 개인(동경제대) 주도", 1916~1930은 "총독부 직속 위원회 주도"라는 **주체의 변화**가 핵심 차이.

## 2. 「古蹟及遺物保存規則」(고적 및 유물 보존 규칙) — 1916년 7월

### 자주 출제될 수 있는 포인트: "왜 일본 본토(1919)보다 조선(1916)에서 먼저 시행되었는가?"

| 항목 | 내용 |
|---|---|
| 제정 시기 | 1916년 7월 (조선) |
| 일본 본토 시행 | 1919년 (조선보다 3년 늦음) |
| 법적 의미 | **일본 최초의 사적(史蹟) 보호법** |
| 핵심 내용 | 유물의 발굴·조사·이전·수선 등을 모두 **조선총독부의 허가** 하에서만 가능하도록 규정 |
| 실질적 효과 | 총독부 허가만 받으면 **유물의 일본 반출이 합법적·체계적으로 가능**해짐 |

**정답 포인트**: "보존 규칙"이라는 명칭과 달리, 실제로는 **유물 반출(약탈)을 합법화·관리하는 장치**로 기능했다는 점을 서술할 수 있어야 함. 식민지에서 먼저 법을 만든 이유는, 총독부 허가 시스템을 통해 문화재를 일본으로 이전하는 통로를 먼저 구축하기 위함.

## 3. 고적조사위원회 설립 (★최강조)

| 항목 | 내용 |
|---|---|
| 설립 시점 | **1916년 4월 26일** (고적조사위원 임명) |
| 사업 기간 | 1916~1930 |
| 실시 방식 | 1916년부터 **5개년 계획**으로 본격 실시 |
| 조사 대상 시대 | **고대~고려시대** (조선시대 유적은 제외) |
| 핵심 관심 지역 | **낙랑군(평양, 한사군)**, **가야 지역** |
| 이론적 목적 | **타율성론** 증명 시도 |

→ "조선시대 유적은 조사 대상에서 제외"되었다는 점, "낙랑군·가야"가 핵심 키워드라는 점을 빈칸/단답형으로 출제 가능.

## 4. 고적조사사업의 목적 2가지 (단답/서술 빈출)

1. **식민사관의 고고학적 증명**
   - 대상: 한사군, 가야
   - 논리: 타율성론 (한반도는 고대부터 외세 지배를 받음)
2. **식민통치의 문화적 성격 과시 (대외 선전)**
   - 결과물: 『朝鮮古蹟圖譜(조선고적도보)』 간행

## 6. 세키노 다다시(関野貞)의 고건축 조사 (1902~1915)

| 항목 | 내용 |
|---|---|
| 조사 명령 | **1902년 6월**, 동경제국대학 조교수였던 세키노 다다시에게 명령 |
| 조사 대상 | 신라·고려·조선의 수도 — **경주·개성·서울**과 주변 |
| 결과물 | **1904년** 『한국건축조사보고』(동경제국대학공과대학학술보고 제6호) |
| 성격 | "넓게, 얇게" — 학문 연구가 아닌 **침략정책용 정보 수집** 목적, 국가 차원의 명령 |

## 7. 간송 전형필 핵심 연표

| 연도 | 사건 |
|---|---|
| 1906 | 서울 종로 출생 (중추원 의관의 아들, 대부호 집안) |
| 1929 | 와세다대학 3학년 재학 중 토지 10만 석 재산 상속 → 한남서림(漢南書林) 인수 |
| 1938 | **보화각(葆華閣)** 설립 (현 간송미술관의 전신) |
| 1942 | (배경) 조선어학회 사건 발생 → 한글 탄압 극심 |
| **1943.6** | **훈민정음 해례본** 입수 (안동에서 발견, 김태준 중개, 만 원에 구입 — 책값 천 원 + 수고비) |
| 1945 | 광복 이후 훈민정음 해례본 세상에 공개 |
| 1950 | 한국전쟁 발발, 피난길에 훈민정음 해례본을 직접 챙겨 보존 |
| 1962 | 훈민정음 해례본 **국보 제70호** 지정 |
| 1997 | **유네스코 세계기록유산** 등재 |

### 인물·용어 정확한 표기 정리
- 간송 전형필(澗松 全鎣弼, 1906~1962)
- 한남서림(漢南書林) — 전형필이 인수한 고서점
- 보화각(葆華閣) — 1938년 설립한 개인 박물관, 간송미술관의 전신
- 훈민정음 해례본 — 김태준이 중개, 안동에서 발견, 만 원에 구입
- 스승: 오세창
