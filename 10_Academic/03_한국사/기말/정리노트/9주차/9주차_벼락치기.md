# 9주차 벼락치기 - 임진왜란과 재조지은(再造之恩)

## 핵심 한 줄
- **재조지은(再造之恩)** = "다시 만들어준 은혜" → 명이 임진왜란 참전을 생색내는 논리 → 이후 조선 정치(친명배금→호란)를 관통하는 키워드

## 임진왜란 연표
- **1592.4.13**: 일본군 부산 상륙 (조총=텟뽀로 승승장구, 부산→서울→평양)
- **1592.4.29**: 광해군 왕세자 책봉
- **1592.6.14**: 분조(分朝) 활동 시작 (인사권·상벌권 위임)

## 삼국 명칭 비교 (★)
| 조선 | 명 | 일본 |
|---|---|---|
| 임진왜란(壬辰倭亂) | 동원지역(東援之役) | 문록의 역(文禄の役) |

- 명 참전 명분 = **가도입명(假道入明)**: "길을 빌려 명으로 들어가겠다"(도요토미 히데요시)

## 일본 빠른 진격 이유
조총(텟뽀) / 대마도 출신 길잡이 / (명군 화포는 평양 탈환 기여) / 이순신 수군이 장기전 가능케 함
→ 끌려간 도공 **이삼평** = 일본 아리타야키 시조

## 동서분당(1575) ★최빈출
- 원인: **이조전랑** 후임 인선(심충겸=외척 문제)
- 동인(외척 반대, 영남) / 서인(외척도 능력있으면 OK, 기호)

## 붕당 계보 ★최빈출
```
동인 → 북인(대북=광해군 옹립 / 소북=영창대군 옹립), 남인(이원익·이항복·이덕형, 광해군대 등용)
서인 → 인조반정 주도 → 노론(송시열)/소론
```

## 광해군 즉위 연표
| 연도 | 사건 |
|---|---|
| 1575 | 광해군 출생(선조 서자 둘째, 모친 공빈김씨), 동서분당 |
| 1602 | 선조-인목왕후 혼인 |
| 1606 | 영창대군 출생 |
| 1608.2.2 | 광해군 즉위(34세) |
| 1616 | 누르하치 후금 건국 |
| 1619 | 사르후 전투, 강홍립 후금 투항 |
| 1636 | 후금→청 국호 변경 |

## 등거리외교
- 명·후금 사이 어느 한쪽에 안 치우침. 분조 시기 평안도·압록강 현장 경험이 토대
- 강홍립(문과·통역 출신) 파병 → 사르후 전투에서 **후금 투항** = 등거리외교 실제 사례 = 인조반정의 비판 근거

## 광해군 공(功)
- 등거리외교 / 연립정국(남인 중용) / **대동법**(이원익) / **동의보감**(허준) / **사고(史庫)** 정비

## 광해군 과(過)
- **폐모살제**: 1613 계축옥사(서얼허통→영창대군 역모로 비화→인목대비 서궁유폐+영창대군 사사)
- 무리한 궁궐 영건(공명첩, 속죄은으로 재정 충당)

## 인조반정으로 연결
- 등거리외교 → "사대 저버림" / 폐모살제 → "패륜" → **친명배금** 노선 → 10주차 호란
