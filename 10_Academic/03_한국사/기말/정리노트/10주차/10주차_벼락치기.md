# 10주차 벼락치기 - 호란 / 붕당에서 탕평으로

## Ⅰ. 호란

- **인조** = 선조의 손자, 정원군(광해군 이복동생)의 아들 = **광해군의 조카**. 1623 인조반정.
- 인목대비 교서: 폐모살제(패륜) + **재조지은 배신** + 무리한 궁궐영건 비판
- 인조 즉위교서: "적신 **이이첨**"이 모후 유폐 → **대명의리** 위반이 핵심 명분
- 결과: **북인 소멸**(이이첨·정인홍 처형) / **남인 이원익** 영의정 / 서인64%·남인27%·북인9% (서인 주도)
- ★raw_md 강조: "중요하다 호란과 관련해서" → 인조반정 명분(친명배금)이 호란의 직접 배경

### 정묘호란(1627) vs 병자호란(1636~37)
| | 정묘호란 | 병자호란 |
|---|---|---|
| 상대 | 후금 | 청(국호변경) |
| 계기 | 모문룡 원조 | 축하사절 미파견+군신요구 거부 |
| 협상 | 강홍립 | 최명길(주화)vs김상헌(척화) |
| 결과 | **형제관계** | **군신관계** |

- 병자호란: 인조 남한산성 45일 농성 → 삼전도 항복
- 정축화약: 군신관계 / 청 연호 사용 / 소현세자·봉림대군 인질 / 군사지원·축성금지

### 삼전도비
- 정식명: 대청황제공덕비, **1639년** 건립, 작성자 **이경석**
- 앞면 우=만주문자20행/좌=몽골문자20행, 뒷면=한문 → **3개국 문자**
- 인조의 굴욕 = **삼배구고두례**(3배×3고두=9고두)

### 북학(소현세자) vs 북벌(효종)
- 둘 다 심양 인질 1637~1645(9년)
- 소현세자: 청과 교류, 화포·망원경 수입, **아담 샬** 교류 → 북학론 단초 → **1645 의문사**(온몸 검은빛, 칠규 출혈, 약물중독 추정)
- 봉림대군(효종): 형 대신 세자책봉(적장자 원손 배제) → 즉위 후 **북벌(복수설치)**
- 좌절원인: 명망 상실(명 멸망1644) / 청의 우위·견제 / 뒷받침 세력 부재
- 신하(송시열·송준길): 북벌보다 **내수(內修)** 우선
- **대보단**: 숙종대(1704경) 창덕궁, **명 신종(만력제)** 제사 → 의리 차원의 북벌 계승

## Ⅱ. 붕당 → 탕평

- "당쟁" = 붕당 파쟁성만 강조한 후대 용어, **1907 시데하라 다이라 《한국정쟁지》**에서 시작 (식민사학)
- 당대(唐): 붕당=금기 / 송대: 필수요소 — **구양수**: 군자당=진붕 vs 소인당=위붕

### 성호 이익 붕당정치 3시기
| 시기 | 기간 | 키워드 |
|---|---|---|
| 붕당성립기 | 1575~ | 동서분당, 이조전랑 |
| 붕당공존기 | 1623~1674경(50년) | 서인+남인, 인조·효종·현종, 이상적 |
| 일당전제기 | 1674~1729 | 환국정치 |

### 3대 환국
| 환국 | 연도 | 집권 | 키워드 |
|---|---|---|---|
| 경신환국 | 1680 | 서인 | 허견 역모→남인몰락, 노론/소론 분화 |
| 기사환국 | 1689 | 남인 | 희빈장씨 원자책봉, 인현왕후 폐위, 송시열 사사 |
| 갑술환국 | 1694 | 서인 | 인현왕후 복위, 희빈장씨 강등 |

### 탕평
- 근거: 《서경》「홍범」 "無偏無黨 王道蕩蕩, 無黨無偏 王道平平"
- **탕평의 주체=군주**
- 박세채(1683, 숙종9): 탕평론 선구
- 영조 탕평교서(1727, 신임옥사 배경): "옥석 안가림도 당습" / 탕평비: "周而弗比=군자, 比而弗周=소인"
- 영조 군자소인론(1749, 사도세자): 당파 아닌 **개인 자질**이 기준
- 탕평 본질 = 붕당소멸X, **왕권강화 통한 균형**
