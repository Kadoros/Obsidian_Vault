# 10주차 시험노트 - 호란의 경험(북벌과 북학) / 붕당에서 탕평으로

## Ⅰ. 호란의 경험

### 1. 인조반정(1623)의 명분
- **반정(反正)**: 그릇된 것을 바로잡아 정상으로 되돌림 = 광해군 정치를 '잘못'으로 규정, 능양군(인조)이 바로잡음
- 인조 = 선조의 손자, **정원군(광해군의 이복동생)의 아들** = **광해군의 조카**
- **인목대비 교서**: 광해군의 폐모살제(인목대비 부모 처형, 영창대군 살해)를 패륜으로 규정 + **'재조지은' 배신**(명의 구원요청 외면, 후금에 성의) 비판 + 무리한 궁궐영건 비판
- **인조 즉위교서**: "적신 **이이첨**이 임금의 마음을 현혹...모후(인목대비)를 별궁(서궁)에 유폐" + **대명의리(對明義理)** 위반을 핵심 명분으로 강조
- **왜 중요한가**: 9주차의 광해군 '공/과'가 그대로 인조반정의 명분 재료가 됨 (등거리외교→사대 저버림, 폐모살제→패륜)

### 2. 인조반정 이후 정권 구도
| 붕당 | 결과 |
|---|---|
| 대북(이이첨, 정인홍) | 처형/숙청 → **북인은 붕당으로서 소멸** |
| 남인 | **이원익**이 영의정 등용 (대동법으로 명망 높음) |
| 서인 | 정권 주도 |

- **실록 분석**: 인조 정권기 당색 확인 가능 인물 129명 중 **서인 64% / 남인 27% / 북인 9%** → 서인 주도+남인 협력 구도를 수치로 확인
- ★ raw_md 명시 강조: **"중요하다 호란과 관련해서"** → 인조반정의 명분(친명배금·대명의리)이 곧 호란 발발의 직접 배경

### 3. 정묘호란(1627) vs 병자호란(1636~37) ★최빈출 비교
| 구분 | 정묘호란(1627) | 병자호란(1636~37) |
|---|---|---|
| 상대국 | 후금(後金) | 대청(大淸, 국호 변경 후) |
| 직접 계기 | **모문룡(毛文龍)** 원조 문제로 후금과 갈등 | 청 태종 즉위에 축하사절 미파견 + 군신관계 요구 거부 |
| 조선 협상대표 | **강홍립** (재파견) | 주화파(최명길) vs 척화파(김상헌) 논쟁 끝 항복 |
| 결과(관계) | **형제(兄弟) 관계** | **군신(君臣) 관계** |
| 인조 행적 | - | 남한산성 피난(45일 농성) → 삼전도 항복 |

- 친명배금(親明排金) 노선: 인조 정권은 자신들이 비판한 광해군의 등거리외교를 인정할 수 없는 구조 → 현실(후금 군사력 성장)을 도외시
- 강홍립을 정묘호란 협상에 다시 보낸 것은, 1619년 사르후 투항이 후금과의 신뢰관계 형성으로 작용했음을 보여주는 정황

### 4. 정축화약(병자호란 강화조건, 1637)
1. 청과 **군신(君臣)** 의리
2. 명의 연호 폐지, **청의 연호 사용**
3. 소현세자·봉림대군 등 인질로 심양 압송
4. 청의 명 정벌 시 군사 지원, 성곽 수리 금지 등 군사적 자립 제약

### 5. 삼전도비(三田渡碑) ★빈출
| 항목 | 내용 |
|---|---|
| 정식명칭 | 대청황제공덕비(大淸皇帝功德碑) |
| 건립 | **1639년**(숭덕 4년, 인조 17) |
| 비문 작성자 | **이경석(李景奭)** (이조판서·홍문관/예문관 대제학) — 신하들이 작성을 서로 미루다 결국 떠맡음 |
| 문자 구성 | 앞면 우측 절반: **만주문자 20행** / 좌측 절반: **몽골문자 20행** / 뒷면: **한문** → 3개국 문자 |
| 핵심 내용 | 청의 출병 이유, 조선의 항복, 청 황제의 회군(은혜 강조 수사) |
| 인조의 굴욕 | **삼배구고두례(三拜九叩頭禮)** = 3번 절, 매번 3번씩 머리를 땅에 찧음(=9고두) |

- 수난사(참고): 1895년 고종이 매립 지시 → 일제강점기 재발굴 → 1963년 사적 지정 → 2007년 빨간 페인트 훼손, 문화재청 복원

### 6. 북학(소현세자) vs 북벌(효종) ★최빈출 비교
| 구분 | 소현세자(昭顯世子) - 북학(北學) | 봉림대군/효종 - 북벌(北伐) |
|---|---|---|
| 심양 인질기간 | 1637~1645 (약 9년, 둘 다 동일) | 1637~1645 (약 9년, 둘 다 동일) |
| 청에 대한 입장 | 청과 폭넓게 교류, 청의 선진문물 수용 주장 | 청 정벌(복수설치復讐雪恥) 주장 |
| 가져온 문물 | 화포, 망원경(망원경/천리경), 서양 문물 | - |
| 교류 인물 | **아담 샬(Adam Schall)** 등 서양 선교사 | - |
| 결말 | **1645년 의문사**(《인조실록》: 온몸이 검은빛, 칠규에서 선혈, "약물 중독된 사람과 같았다") | 세자 책봉(적장자 원손 배제, 인조의 둘째아들로 책봉) → 즉위 후 북벌 추진 |

- 소현세자 죽음 관련: 행희 **조소용(趙昭容)**이 세자빈을 평소 무함했다는 정황 함께 기록
- 효종의 북벌 의지는 형의 의문사와 무관하지 않을 것이라는 해석 → 정치적으로도 친청 노선과 거리를 둘 수밖에 없었음

### 7. 북벌 추진의 좌절
- **송시열·송준길** 등 산림 신하: 북벌 자체보다 **내수(內修)** 강조 (북벌의 '준비단계'론)
- 좌절 원인 3가지:
  1. 명나라 멸망(1644) 이후 "명을 위한 복수"라는 명분의 호소력 상실
  2. 청의 군사적 우위·감시·견제
  3. 북벌을 뒷받침할 정치세력 부재
- **대보단(大報壇)**: 효종 사후 **숙종대(1704년경)** 창덕궁 후원에 설치, **명 신종(만력제)** 제사 → 군사적 북벌은 좌절했지만 '의리(대명의리)' 차원에서는 지속됨을 보여주는 상징

## Ⅱ. '붕당'에서 '탕평'으로

### 1. '당쟁' 용어 비판 ★중요
- **붕당(朋黨)** = 조선 당대 실제 사용된 역사 용어 / **'당쟁'** = 붕당의 **파쟁성만 강조**한 후대(특히 식민사학) 용어
- **1907년 시데하라 다이라(幣原坦)**가 《한국정쟁지》에서 '당쟁' 프레임 사용 시작 → 식민사학의 정체성론·당파성론과 연결
- 핵심 논지: 환국정치(일당전제기)처럼 격렬한 시기는 실재하지만, 그것만으로 조선 정치 전체를 '당쟁'으로 규정하는 것은 왜곡

### 2. 붕당에 대한 유교적 인식 변화
| 시기 | 인식 |
|---|---|
| 당대(唐代)까지 | 붕당 = **금기(禁忌)**, 부정적 |
| 송대(宋代) | 주자성리학 발달과 함께 **필수불가결**한 요소로 재인식 |

- **구양수(歐陽修)의 붕당론**: **군자당=진붕(眞朋)**(의리로 뭉침) vs **소인당=위붕(僞朋)**(사익으로 뭉침) → 군주는 진붕(군자당)을 등용해야 함
- 영조대 와서 이 이분법 자체("당 전체가 군자/소인일 수 없다")가 비판됨

### 3. 성호 이익의 붕당정치 3시기 ★최빈출
| 시기 | 기간 | 내용 |
|---|---|---|
| ① 붕당성립기 | **1575년 동서분당**~ | 이조전랑직 임명권 갈등 → 동인/서인 분화, 이후 계속 분화 |
| ② 붕당공존기 | **인조반정(1623)~숙종 즉위(1674) 전후, 약 50여 년** | 인조·효종·현종 3대, **서인+남인** 공존, 이상적/모범적 붕당정치, 당색 초월 사제·혼인관계 |
| ③ 일당전제기 | **숙종(1674)~영조 탕평선언(1729)** | **환국정치(換局政治)** 반복, "오늘은 이쪽 내일은 저쪽" |

### 4. 3대 환국 ★최빈출
| 환국명 | 연도 | 집권 붕당 | 핵심사건 |
|---|---|---|---|
| **경신환국** | 1680(숙종6) | 서인 | 허적의 서자 **허견** 역모 연루 → 남인 몰락. 이후 서인이 **노론(송시열, 강경)/소론(윤증, 온건)**으로 분화 |
| **기사환국** | 1689(숙종15) | 남인 | **희빈 장씨** 소생 왕자(경종) **원자 책봉** 문제 → 서인(송시열) 반대 → 인현왕후 폐위, **송시열 사사** |
| **갑술환국** | 1694(숙종20) | 서인(재집권) | **인현왕후 복위** 운동 → 남인 실각, 희빈 장씨 강등(1701 사사) |

- 환국정치 = 숙종이 왕권 강화를 위해 붕당 대립을 정치적 수단으로 활용한 것

### 5. 탕평론 ★최빈출
- 사상적 근거: 《서경》 「홍범」 **"無偏無黨 王道蕩蕩, 無黨無偏 王道平平"** = 치우침·무리 없으면 왕도가 넓고 공평함
- **탕평의 주체 = 군주(국왕)** ← 신하/서민 아님 (★출제포인트)
- **박세채(朴世采)**: 1683년(숙종9) 《남계집》에서 탕평론 선구적 제기 — "동서 색목은 선조 때 시작, 처음엔 백흑/음양처럼 절대적 군자·소인 구별 아니었다", "현명한 자는 등용, 미련한 자는 멀리하여(黜陟) 황극지도(皇極之道)를 세워야"
- **영조 탕평교서(1727)**: 신축·임인옥사(1721~22) 배경 → "옥석을 가리지 않고...이 또한 당습이다" / **탕평비**: "두루 사귀고 편당 짓지 않음은 군자, 편당 짓고 두루 사귀지 않음은 소인(周而弗比 乃君子之公心, 比而弗周 寔小人之私意)"
- **영조의 군자·소인론(1749, 사도세자에게)**: "이 당 중에도 군자·소인이 있고 저 당 중에도 군자·소인이 있다" → **당파가 아닌 개인 자질**이 기준 → 구양수식 이분법 수정
- 탕평의 본질: 붕당 자체의 소멸이 아니라 **왕권 강화를 통한 붕당 간 균형 유지**
