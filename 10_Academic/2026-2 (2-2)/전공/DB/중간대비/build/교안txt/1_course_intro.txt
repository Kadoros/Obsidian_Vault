What is a Database System?
q Database (DB)
  ■ A logically coherent collection of inter-related data
     q   Managed by a Database Management System


q Database Management System (DBMS)
  ■ A software that is designed to efficiently “manage”
    data in a structured way
     q Defining, constructing, manipulating, and sharing databases
     q e.g., IBM DB2, Oracle, MS SQL Server, MySQL, SQLite, …



q Database System
  ■ Databases + DBMS software

2) Data Abstraction
q Insulation between Programs and Data
  ■ A database system provides a conceptual representation (logical level) of data
    q   e.g., objects, their properties, and their interrelationship
  ■ It does not include the complex structures of a database (physical level)
    q   e.g., how the data is stored or how the operations are implemented
  ■ A change of data structure does not affect programs (program-data independence)

When Not to Use a DBMS?
q Overheads of DBMS
  ■ High initial investment in hardware, software, and training
  ■ The generality that a DBMS provides for defining and processing data
  ■ Security, concurrency control, recovery, and integrity functions                    Too heavy..😭

q More Desirable to Use Customized Databases
  ■ Simple and well-defined applications that are not expected to change at all
  ■ Strict real-time requirements that may not be met
  ■ Embedded systems with limited storage capacity (no need general-purpose DBMS)
  ■ No multiple-user access to data

  No Addition
  No Deletion
  No Update
