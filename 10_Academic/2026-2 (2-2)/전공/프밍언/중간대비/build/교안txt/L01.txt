    • Sebesta, Robert W. Concepts of programming

§ Prerequisites
    • This course assume that each student is an expert
      in one or more high-level programming languages
      - e.g., C/C++, Java, Python

§ Course Description
    • The fundamental concepts of computer programming languages
    • Formal methods used to describe the syntax and semantics of
      programming languages, implementation techniques for various
      language constructs, and implementation of subprogram linkage



Chung-Ang University CSE 22405: Principles of Programming Languages   3
Course Overview
§ Course Objectivies
    • Understand core principles
      - Syntax, semantics, types, scoping, control structures
    • Compare major paradigms
      - Imperative, functional, and logic programming
    • Gain hands-on experience
      - Implement a mini language (syntax and semantics)
    • Reason about language design
      - Trade-off in readability, writability, and etc.
    • Connect to modern platform
      - See how paradigms appear in GPU programming and frameworks like
        PyTorch
