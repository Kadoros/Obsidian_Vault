## 문제 유형

### 1. T/F
- 맞으면 **+2**, 안 쓰면 **0**, 틀리면 **−1**. 감점은 다른 문항 점수에서도 깎임 (예: 전체 50점인데 T/F에서 −10이면 40점)
- 모르면 **비워두는 것도 좋은 선택**
- 문장이 여러 절로 되어 있으면 하나라도 틀리면 F (예: "Stack is a FIFO architecture …" → 뒤가 맞아도 F)
- 중간 범위 전체에서 출제

### 2. 성능 계산
- 수업에서 다룬 예시 위주
- **Execution time = 1 / Performance**. "실행시간이 길다 = 성능이 낮다" 같은 말장난 조심
- CPI, clock cycles, clock rate 공식을 문제에 맞게 쓸 것
- 문제에 안 나온 값이 두 프로그램에서 같다고 하면 변수(예: instruction count = I)로 놓고 풀어도 됨
- 명령어 class가 여러 개일 때 Average CPI: class별 CPI → 전체 instruction count로 가중평균
- MIPS 같은 성능 지표 공식은 문제에서 줌. **외울 건 execution time뿐**
- 지표에 따라 A가 B보다 좋기도 하고 반대이기도 할 수 있다는 결론이 나올 수 있음

### 3. C 코드나 다이어그램을 MIPS 코드로
- C 프로그래밍을 시키지는 않음. C 코드나 알고리즘 다이어그램을 주고 MIPS로 옮기게 함
- 옆에 주석으로 각 줄에 뭘 써야 하는지 설명이 있음
- ⚠️ **문제 아래에 준 instruction set만 써야 함.** 다른 명령어를 쓰면 예외 없이 0점, 부분점수 없음 (예: bne, add, sub, j만 쓰라고 했는데 beq를 쓰면 0점)
- 프로그램 전체가 안 돌아갈 정도의 치명적 오류가 있으면 중간에 맞은 줄이 있어도 0점

### 4. Leaf procedure, stack
- stack pointer로 변수, return address, argument 공간을 확보. **각 값의 타입과 크기를 파악할 것** (예: `$ra` 4바이트 + int 인자 4바이트 = `$sp -= 8`). 인자 타입이 바뀌면 필요한 공간도 바뀜
- 코드 중간중간 빈칸 채우기. 주석이 없는 빈칸은 앞뒤 맥락으로 반드시 알 수 있는 것만 뚫어놓음. 함수 호출 부분은 통째로 비워놓을 수도 있음
- ⚠️ **offset은 저장과 로드가 일관돼야 함** (0번 offset에 저장했으면 0번에서 로드). 일관성이 없으면 0점

### 5. 레지스터·메모리 추적
- 왼쪽은 레지스터 값, 오른쪽은 메모리 주소 표가 주어짐
- `jal`을 하면 argument가 들어가고, `$ra`에는 자동으로 **PC+4**가 들어감. 단계마다 레지스터에 뭐가 들어 있는지 물어봄
- stack pointer를 빼고 더하면서 stack 메모리가 어떻게 바뀌고 유지되는지 물어봄
- 작은 실수로 한 칸씩 밀린 정도(예: −8을 −12로)는 정답으로 인정. 원리를 이해 못 한 걸로 보이면 0점

### 6. 곱셈·나눗셈 회로
- 회로를 직접 줌. **비트 수를 꼭 확인할 것** (비트 수에 따라 과정이 달라짐)
- 답안에 **어떤 시점의 상태를 쓰라고 명시함** (예: shift *이후* 값). shift 이전 값을 쓰면 점수 없음
- 나눗셈: 초기화하면 Remainder에 dividend가 들어감 → 빼보고, 음수면 다시 더해서 복구하고, 양수면 그대로 둔 다음 quotient를 늘려가는 순서 → shift
- 작은 실수로 밀린 건 인정, 원리를 모르면 0점

### 7. Floating point
- **single: sign 1 + exponent 8 + fraction 23**, **double: sign 1 + exponent 11 + fraction 52** (외우라고 함)
- 포맷 칸에 숫자 개수를 정확히 채워야 함. 자릿수가 하나라도 틀리면 오답

### 8. Datapath 다이어그램
- 연결선이 다 끊어진 채로 알파벳으로 표시돼 나옴. 어디가 어디에 연결되는지 찾기
- 특정 연산을 할 때 **MUX, ALU control 등에 들어가는 값** 맞히기 (마지막 문제)

- lw/sw의 offset은 반드시 상수 (06주-2에서 교수님이 여러 번 강조)
