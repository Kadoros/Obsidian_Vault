흑석동 9 — 정리본 (미팅 요약)

■ 미팅 성격
학생이 해석 가능한 신경망 아키텍처 논문(진행 중)을 지도교수에게 발표하고,
논문 구성·투고 전략·졸업 요건·협업(교신저자) 등에 대해 논의한 지도 미팅.

────────────────────────────────────────────────────
1. 핵심 아이디어 — 아키텍처
────────────────────────────────────────────────────
- 기존 MLP: 하나의 큰 dense 행렬 W로 변환.
- 제안 구조: W의 역할을 세 개로 분리 → V, Λ(람다), U.
    · V : 입력 X를 받아 "모드로 어떻게 섞을지"의 레시피 생성 (LDA로 anchoring).
    · φ : 각 모드의 비선형 변환을 학습 (동그란/ sin(x) 등). 비중첩성의 원천.
    · Λ : 각 모드의 중요도 스위치. 강제로 끌 수 있음.
    · U : 라우팅. 출력 F(x) = y (classification).
- V, U, φ, Λ 모두 파라미터로 cross-entropy loss로 학습.
- V·Λ·U 중 나머지는 선행 연구에 존재 → U만 새로운 컨트리뷰션이라 집중.

────────────────────────────────────────────────────
2. 핵심 이론 결과 (메인 컨트리뷰션)
────────────────────────────────────────────────────
"고정확도 임계점에서 U는 signed permutation 행렬이 된다" (조건부 정리)
→ U의 각 row가 하나의 클래스에 대응 → 해석성(interpretability)이 수학적으로 강제됨.

성립 조건 (세 조건 + Assumption 1):
  (조건) 데이터의 클래스가 충분히 분리(separated)되어 있어야 함.
  (Assumption 1) 클러스터 내부 차이는 무관하나, 클러스터 간에는 떨어져 있어야 함.
  (조건) 한 샘플에 한 모드가 지배 → 비중첩성(non-overlap).
  (조건) 학습이 충분히 되어 정확도가 높아야 함.
  (제약) U·V가 Stiefel(직교) 제약 위에 있어야 함. U는 항등행렬 I에서 시작.

증명 스케치:
  Step 1. cross-entropy loss 미분 → 비대각(off-diagonal) gradient가 0으로 수렴
          (비중첩·고정확도 성질이 여기 쓰임).
  Step 2. U가 Stiefel 다양체 위 → gradient가 법선 방향. 좌변의 비대각 성분 =
          앞서 구한 비대각 gradient → 완벽 학습 시 Λ가 블록 대각.
  결론.   Λ가 블록 대각일 때 만족하는 직교 행렬류는 signed permutation뿐.
  ※ 증명 엄밀성은 아직 보강 중.

Bound:
  분자 = B2, B3 (학습 정확도 관련), 분모 = 데이터 성질.
  순환 논리(circular)를 최대한 제거함. 아직 공부 더 필요.
  B1(데이터 품질), B2(비중첩성, φ로 학습), B3(고정확도, LDA anchoring으로 달성).
  ※ 정리는 "임계점이면 permutation" 이라는 조건부 결과이지, 학습이 무조건 된다는 보장은 아님.
     그 임계점에 도달시키기 위한 장치가 이 아키텍처 + LDA anchoring.

────────────────────────────────────────────────────
3. 실험 결과
────────────────────────────────────────────────────
- Ablation: 요소를 하나씩 제거해도 accuracy는 동일 → 요소들은 성능이 아니라 해석성 장치.
            단, 제거 시 interpretability는 크게 감소.
- 물리 진자: 물리적 의미와 완벽히 일치.
- EEG: 사전 정보 없이도, 신경과학적으로 알려진 패턴과 일치하는 결과 발견 (흥미로운 결과).
- OOD/구조 일관성 확인 → 기저가 물리적으로 유의미.
- LDA anchoring: 정확도는 불변, one-to-one 매칭만 향상 → anchoring 효과 검증.
- ImageNet: 정확도 동일, interpretability만 깔끔하게 향상.
- Shortcut(워터마크) 제거: 워터마크에 반응하는 모드를 Λ로 비활성화 → ImageNet 성능 향상
            (ResNet-50 동결 상태 실험이라 절대 학습도는 안 오르지만 성능 개선 확인).
- CV(비전) 확장: 나오긴 하는데 아직 불확실 → 분석/엔지니어링 진행 중.

셀링 포인트:
  ① Stiefel 제약 + 비선형성 → U가 우연이 아닌 수학적으로 강제된 signed permutation → 해석성.
  ② 모드 단위로 클래스를 하나씩 읽을 수 있어 모델 예측 신뢰도↑.
  ③ 특정 모드 비활성화로 shortcut 억제 → 성능↑, 딴짓 방지.

학습 팁: 큰 모델에서는 동시 학습이 잘 안 됨.
  U 동결 → V 먼저 학습 → 동시 학습 → V 동결 후 U 추가 학습 시 더 깔끔.
