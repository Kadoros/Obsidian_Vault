## 5. 연구 로드맵 (2026-10-09)
| 단계 | 내용 | 보여주는 것 | 상태 |
|---|---|---|---|
| **1** | 푸리에 고정 + 최소제곱, PDE 5개 (Burgers, KdV, KS, Fisher, E4 가변 점성) | 정답 텐서 복원, 오염 두 종류와 처방, eddy viscosity 해석, 함수 입력·OOD | ✅ 2026-10-10 (5개 PDE 같은 결론, KS 680×) |
| **2** | 어려운 PDE: 2D NS(주기), Darcy(2D, 함수 입력), Allen–Cahn/NLS(4차 텐서) — GPU·경사하강법, 저랭크 압축 | 같은 구조가 큰 규모에서도 통함 | 🔄 서버로 (스모크: NS·Darcy·AC closed 정확, NS 큰 스케일 0.15%, Darcy는 LS만으론 단순 절단 못 이김→경사하강법) |
| **3** | 기저 고정 풀기: M6 POD(1D Burgers) → 체비쇼프(벽) → 기저+텐서 동시 학습(좌표 자유 묶기) | 방정식·대칭을 미리 안 알려줘도 됨 | 🔄 M6a 서버로 (스모크: A 고유기저가 푸리에 복원, 순도 0.98~1.0) |
| (a) | neural operator 비교: DeepONet, FNO, NIGO — 정확도, OOD, 학습 시간 | ML 학회 필수 | ⏳ |
| (b) | 기존 NO 검사: 학습된 FNO/DeepONet의 암묵 텐서를 뽑아 정답과 비교 | "정확도 높아도 물리 규칙은 이만큼" | ⏳ |
| (c) | 이론: 대칭→선택 규칙, 식별 조건, closure 오차 | 함수해석학 공부 연결 | ⏳ |

**순서 제안**: 1 → **M6** (1D라 쌈) → (a)(b)를 1D Burgers로 작게 → 2단계 2D 하나
**첫 논문 범위 (수정, 2026-10-09)**: **1단계 + 3단계(M6a·b·c) + (a)(b) 1D** 가 핵심. 2D는 NS 하나를 푸리에 고정으로라도 (ML 학회 "1D뿐" 약점 방어). → 교수님·선배와 확정
- 기저 풀기를 넣는 이유: ① "푸리에로 답을 알려준 것 아니냐" 공격 방어 ② 기저 학습 = 트렁크 학습 → DeepONet과 직결 ③ 경사하강법 단계라 ML 색이 강해짐
- 3단계 구체안: **M6a** POD 기저(Burgers/KdV/KS) — POD가 푸리에를 스스로 찾나 / **M6b** 벽 있는 영역(디리클레 Burgers, 체비쇼프 또는 POD) / **M6c** 기저(신경망 트렁크)+텐서 번갈아 학습, 좌표 자유 묶기, DeepONet 트렁크와 비교
- 함정: 균일 매질의 POD는 cos/sin **짝**(같은 에너지)으로 나와 짝 안 회전 자유가 남음 → 복소 모드로 합쳐 위상만 남기기
**전제 정리**: 아는 것 = 영역 모양·경계 종류, 매질 균일성(대칭), 비선형 차수 / 모르는 것 = 방정식 형태·계수·어떤 모드끼리 상호작용하는지. 푸리에는 PDE가 아니라 "주기 + 균일"에서 나옴. 균일 매질이면 POD가 저절로 푸리에가 됨 → M6로 확인

## 4. 결정 기록
- 2026-10-09: "Frozen-PINN → DeepONet 이식"은 새로움 약함 (RandONet, NODE operator nets 존재) → 폐기
- 2026-10-09: "$A(a)=S(a)-D(a)$ 구조 보장"은 **NIGO (ICML 2026)** 가 이미 함 → 그대로는 폐기, 비선형 텐서·비이차 엔트로피로 확장하는 방향으로
- 2026-10-09: 3차 텐서 결합 아이디어 채택 → 실험 E1부터
- 2026-10-09: 주장 정정 — 기존 NO도 비선형은 잡음, 차이는 "숨김 vs 명시". 주장은 "이차 PDE에서 정확 + 해석 + 보장" (성능 우위 주장 ✗). KAN과는 해석 축이 다름 (함수 vs 상호작용)
- 2026-10-09: 선행 정독 — Tensor parametric H-OpInf가 "입력-모드 텐서"(§3)를 이미 함(스칼라 3~4개, 선형). NODE-ONet은 함수 입력+계수 ODE지만 원소별 곱, 해석·보장 ✗. → 새로움은 4성질 통합 + 해석 검증. E1이 기둥
- 2026-10-09: E1 스모크 — closed 텐서 정확 복원(1e-8), full은 closure 오염(on-rule 13~31%, 전체 150~300%). 본 실험은 서버 에이전트로 → `experiments/E1/`
- 2026-10-09: E1 본 실험 — closed 정확 복원(1e-13), full은 ν에 따라 완만 열화(sel 0.94→0.51), STLSQ로 약한 closure에선 sel 1.0. **예측 정확도 ≠ 해석 가능성** 확인. 다음: E1 v2 (closure 분리, 대칭 제약, STLSQ 수정)
- 2026-10-09: E1 v2 스모크 — 누수의 정체는 closure가 아니라 회귀의 가짜 성분. **평행이동 대칭 사전지식만으로 텐서 오차 1.5→0.015**. cubic closure 가설은 기각. 본 실험 서버로
- 2026-10-09: 현황 판단 — 신호 좋음, 단 Burgers는 쉬운 경우. SINDy/PDE-FIND와 겹침 리스크 확인 → 승부처는 E4(함수 입력) + 2D NS/Darcy 벤치마크 비교 + 분포 밖 입력
- 2026-10-09: E1 v2 본 실험 — 스모크 결론 두 개 정정. 오염 = ① 가짜(→대칭) ② 진짜 closure(→대칭+cubic). V2g가 최고, rollout도 3.7배 개선. 에너지 제약은 "거의 공짜 보장". 다음: eddy viscosity 분석 → E4
- 2026-10-09: 다중 PDE 프레임워크(tco_pde.py) — Burgers/KdV/KS/Fisher/E4 + closure 자동 분석. 스모크: 구조 모델은 closure를 A+C에 담고 T를 깨끗하게 유지(eddy viscosity 오차 0.9% vs 25%). E4 OOD 롤아웃 1~2%. 본 실험 서버로
- 2026-10-10: M 시리즈 완료 — 5개 PDE 모두 closed 정확 복원, 구조 효과 일반화(KS 680×). 한계: E4 OOD 예측 이점 작음(입력 무관 closure 가설), KS 롤아웃 지표 무의미(카오스), Fisher 약절단에선 cubic 불필요. 다음: M6a(POD)
- 2026-10-10: M6a(POD) 스모크 — 기저 안 줘도 closed 정확 복원, POD는 데이터 많으면 푸리에에 수렴(0.96), **학습된 A 고유기저 = 푸리에 (순도 ~1.0)**. KS는 고윳값 겹침에서 한계. 다음: 고유기저 + 희소 회귀로 선택 규칙 발견
- 2026-10-10: 2단계+M6c 스모크 — 2D NS(대칭 없인 규모 불가), Darcy(LS 학습 연산자 < 단순 절단 → 해 오차 경사하강법 필요 = ML 지점), Allen–Cahn(대칭 없이 진짜 식별 불가), 트렁크(푸리에 재발견). 서버로
