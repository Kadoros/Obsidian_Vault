# TCO PDE 후보와 대칭 조건

## 대칭 → 선택 규칙 (일반 원리)
선택 규칙 $p+q=k$ 는 Burgers 고유가 아니라 **평행이동 대칭 + 주기 영역 + 푸리에 기저**에서 나옴. "대칭이 있으면, 그 대칭에 맞는 기저에서 어떤 모드끼리 만날 수 있는지가 정해진다" (양자역학 선택 규칙과 같은 원리).

| 상황 | 대칭 | 선택 규칙 |
|---|---|---|
| 주기 영역, 균일 매질 (Burgers, KdV, KS, 2D NS) | 평행이동 | ✓ $p+q=k$ (2D: $\mathbf p+\mathbf q=\mathbf k$) |
| 입력이 계수 함수 ($\nu(x)$, Darcy $a(x)$) | 입력+상태 **동시** 이동 | ✓ $i+j=k$ ($L_{kji}$) |
| 구 위 (대기, 얕은 물) | 회전 | ✓ 구면조화 삼각형 규칙 (Gaunt 계수, 각운동량 합성과 같음) |
| 벽 있는 영역 (채널, 디리클레) | 평행이동 깨짐 | △ 체비쇼프 $k=m+n$ 또는 $\lvert m-n\rvert$ (느슨), 좌우 대칭이면 짝홀 규칙 |
| 복잡한 영역 | 없음 | ✗ 희소성 등 다른 사전지식 필요 |

- 대칭이 많을수록 규칙도 많음. 예: 2D NS는 에너지 + enstrophy 보존 → 삼체 계수 사이 관계식 추가
- E1 v2 스모크: 대칭 사전지식만으로 오염된 텐서 오차 1.5 → 0.015 ([[TCO 실험 계획]])
- 대칭 사전지식 = "PDE를 앎" ✗, "매질이 균일함" ✓ (약한 지식, 정당한 귀납 편향)

## 1단계: 기본 (1D, 주기, 정답 텐서를 공식으로 앎)
| PDE | 왜 | 텐서 특징 | 상태 |
|---|---|---|---|
| **Burgers** | 기준점 | 이차, 소산 | ✅ E1, V2 진행 |
| **KdV** | 에너지 보존계(분산, 솔리톤) → 보존 구조 테스트 | 선형부 반대칭 $ik^3$, 삼체는 Burgers 꼴 | ⏳ |
| **Kuramoto–Sivashinsky** | 카오스, 장시간 롤아웃, 단골 벤치마크 | 선형부 저주파 불안정·고주파 감쇠 + 이차 삼체 | ⏳ |
| **Fisher–KPP** ($u-u^2$) | 미분 없는 비선형 | 삼체 계수가 $k$ 비례 아님 | ⏳ |
| **가변 점성 Burgers** $\nu(x)$ | **함수 입력 → 함수 출력** 첫 실험 (E4) | 입력 텐서 $L_{kji}$ + 삼체 $T$ | ⏳ |

## 2단계: 되면 좋은 것
| PDE | 왜 좋나 | 어려운 점 |
|---|---|---|
| **2D Navier–Stokes** (주기, Kolmogorov 강제) | FNO 대표 벤치마크, 역캐스케이드를 텐서로 읽기 | 모드 많음 → 저랭크 압축 |
| **Darcy** (2D) | operator learning 표준 벤치마크, Tensor parametric H-OpInf와 직접 비교 | 정상상태 = 텐서 방정식 풀기 |
| **Allen–Cahn / 비선형 슈뢰딩거** | 4차 텐서 확장, NLS는 보존계 | 칸 수 증가 |
| **구 위 얕은 물** | 기상·기후, 회전 대칭 규칙 | 구현 큼, 장기 |
| **벽 있는 Burgers** (체비쇼프) | 대칭이 깨질 때 한계 보이기 | 느슨한 규칙 |

## 추천 순서
Burgers → **KdV, KS** (E1 코드에서 선형부·계수만 교체) → **가변 점성 Burgers (E4)** → **2D NS, Darcy** (벤치마크 비교)
