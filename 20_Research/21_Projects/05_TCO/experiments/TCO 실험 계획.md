# TCO 실험 계획

**대상 모델:** DeepONet, HyperDeepONet, (NIGO형 $S-D$), NODE-ONet, Tensor parametric H-OpInf, TCO
**데이터셋:** 1D 주기 advection-diffusion, 1D Burgers, 2D Darcy

### 1. 실험 개요 및 가설
> 가설: 입력 의존 3차 텐서로 모드 결합을 모델링하면 ① 학습된 텐서가 **알려진 물리 텐서를 복원**하고(해석 가능성), ② 대칭 구조로 **분포 밖 입력·장시간 롤아웃에서 에너지가 안 터진다**(안정성).

| ID | 문제 | 목적 | 성공 기준 |
|---|---|---|---|
| **E0** | 기존 모델 실패 재현 | 동기 그림 | DeepONet이 비선형/분포 밖에서 깨지는 모습을 깔끔하게 |
| **E1** ⭐ | 1D Burgers, 푸리에 기저 | **텐서 복원 (해석 가능성)** | 데이터만으로 학습한 $T_{kij}$ 가 선택 규칙 $i+j=k$ 를 스스로 찾음, 해석적 $T$ 와 상대오차 |
| E2 | 1D 주기 advection-diffusion, $\nu(a), c(a)$ 입력 의존 | 제약 없는 $A(a)$ vs $S(a)-D(a)$ (NIGO 재현) | 분포 밖 입력·긴 롤아웃에서 에너지 곡선 |
| E3 | 2D Darcy | 입력→모드 섞기 텐서 $A(a)=\sum_ia_iT_{\cdot\cdot i}$ — **Tensor parametric H-OpInf를 베이스라인으로** (조각별 상수 → 연속 계수장으로 확장되는지) | 정확도 DeepONet과 동급 + 텐서 해석 |

**순서:** E1 → E2 → E0 정리 → E3

**결론 (예비):**

- E1f 이상: ν=0.02 **closed**에서 STLSQ rel 2.5e-2 (lstsq 1.6e-14). 추정 원인: 임계값이 열별 최대값 기준이라 작은 점성항 $-\nu k^2$ (ν=0.02면 ~0.02)이 잘려나가고, 텐서 규칙 위 성분이 이를 보상 → **확인 필요: 해당 run의 rel_err_A_diag**

**결론**
1. **닫힌 계: 정확 복원(1e-13), 자극·노이즈에 강건** → 해석 가능성 기둥 ✓
2. **절단 데이터: closure 강도에 따라 단조·완만하게 열화.** ν≥0.2에선 lstsq만으로 sel 0.84~0.94, 희소성 넣으면 0.99~1.00 → 약~중간 closure에선 해석 가능성이 실제로 성립
3. **예측 정확도 ≠ 해석 가능성**: ν=0.05 full은 rollout 9e-3로 잘 맞추는데 sel 0.58. E1b kic=2는 미분 예측이 더 좋은데 텐서는 엉망 → **예측 지표로는 해석을 검증할 수 없음 → 텐서 복원 지표(④)가 독립적 기여**
4. 강한 closure(ν≤0.05)가 진짜 숙제 → E1 v2

**핵심 해석 (가설 수정):** ⚠️ 아래 해석 일부는 본 실험에서 뒤집힘 → "E1 v2 본 실험 결과" 참고
- 처음 가설: "누수 = closure, cubic 채널이 흡수할 것" → **틀림**
- Burgers 전체가 평행이동 대칭 → **잘린 모드의 영향(closure)도 선택 규칙을 지킴** → 규칙 밖 성분은 closure가 아니라 **회귀가 만든 가짜**
- 그래서 대칭만 강제하면 누수가 사라짐. 남는 on-rule 오차(1.5~5%)가 진짜 closure 효과 = **유효(재규격화된) 삼체 계수**로 해석 가능
- 대칭 사전지식은 "PDE를 앎"이 아니라 "매질이 균일함"이라는 훨씬 약한 지식 → 정당한 귀납 편향
- 함수 입력으로 확장: 입력 $\nu(x)$ 가 대칭을 깨도, (입력+상태) 동시 이동 대칭은 남음 → $L_{kji}$ 에 선택 규칙 $i+j=k$ → **같은 원리가 E4에도 적용**

#### M 시리즈: 다중 PDE 프레임워크 (2026-10-09) — `M_multi/`
- `tco_pde.py`: Burgers, KdV, KS, Fisher–KPP, **varvisc(E4, 함수 입력)** 를 한 코드로. 모든 run에 **closure 분석 자동** (테스트 데이터에서 정확한 eddy viscosity vs 모델 암묵 eddy viscosity, 블록별 분해)
- 지시문: `M_multi/TCO_MULTI_AGENT_INSTRUCTIONS.md` (M0 재현 확인 → M1~M5)
- 리팩터링 검증: quick 설정에서 V2 숫자 정확히 재현 (1.53e-2, 4.64e-2)

**스모크에서 잡은 것 (돌아간다 확인용, 결론 아님)**
- varvisc: 평균 점성을 고정하면 $\nu_0 z_k$ 와 $z_k$ 가 같은 방향 → 식별 불가 (A 대각과 L이 반반 나눔). **평균도 궤적마다 0.5~1.5배로 바꿔서 해결** (closed L 오차 0.25 → 0.003)
- KS: K=8은 불안정 모드가 거의 다 차서 부족 → K=12. 롤아웃 적분기가 KS의 빠른 감쇠(고윳값 ~−900)에서 불안정 → **IF-RK4로 교체**
- KS ν=0.02: 정확한 모델도 롤아웃 2% 벌어짐 = 카오스 예측 한계
- **closure 분석 (Burgers ν=0.05, 작은 설정)**: 정확한 eddy viscosity가 차단 파수로 갈수록 급증. 대칭+cubic 모델은 테스트에서 스펙트럼 오차 **0.9%**, 기본 회귀는 25%
  - 대칭+cubic: closure를 **선형 A + cubic C**에 담고, 이차 T 오차는 ~0 → 텐서가 깨끗
  - 기본 회귀: closure 상당 부분을 **이차 T 안에 숨김** → 해석 오염, 차단 파수 급증도 놓침

#### M 시리즈 본 실험 결과 (2026-10-10, 서버) — 원본: `M_multi/M_agent_report_raw.md`

- **eddy viscosity**: closure가 의미 있는 곳에서 구조 모델 오차 작음 (Burgers 0.6~2%, KS 1e-5~1e-3, KdV 강절단 9%). 큰 값(0.4~1.4)은 closure≈0인 곳
- **에너지 제약**: 모든 PDE에서 T 오차 10~30% 증가 대신 정확한 보존 → "거의 공짜 보장" 일반화
- **결론: 1단계 결론이 5개 PDE에서 같은 방향** (복원 / 오염 두 종류 / 처방 / closure 해석)

**솔직한 한계 3개**
1. **E4 OOD 예측 이점 작음**: OOD dz가 방법 무관 ~0.10 고정 (분포 안 0.02). closed OOD는 6e-14 → OOD 오차는 전부 closure 기원. 가설: closure(A, C)가 **입력 무관**이라 OOD 입력(국소 점성 작음 → 절단 누수 큼)에 못 따라감. 좁은 입력(0.3)으로 학습해도 OOD 같음, 텐서는 더 깨끗. → 지금 주장 가능: "E4는 **해석**(L 복원)에서 이김", "OOD **예측**"은 아직 ✗. 다음: **입력 의존 closure** + NO와 OOD 비교
2. **KS 롤아웃 지표 무의미**: ν=0.02에서 closed 포함 모든 방법 1.4 (카오스). → 짧은 구간 롤아웃 + 통계량(에너지 스펙트럼)으로 평가
3. **Fisher ν=0.1에서 cubic이 오히려 악화** (closure 8e-5): closure 채널은 closure가 있을 때만 → 검증 데이터로 선택

#### M6a: 데이터로 배운 기저 (POD) — 스모크 (2026-10-10) — `M6a_pod/`
설계: 센서 격자(64점) 값만 줌 → POD 기저 → 그 좌표에서 텐서 학습(대칭·푸리에 없음) → 평가 때만 학습 모델 전체를 실수 푸리에 좌표로 옮겨 정답 비교 (POD 짝 회전 자유와 무관한 공정 비교). `--basis fourier`로 같은 데이터 기준선.

**스모크 결과 (결론 아님)**
- closed: POD 기저로도 정답 텐서 복원 (1e-7~1e-14). POD 공간 ≈ 푸리에 공간 (span 1e-15~1e-3)
- **POD 순도**: quick 0.65~0.86 → Burgers 기본 크기 0.96. 데이터가 많을수록 POD가 스스로 푸리에를 찾음 (M6a-3에서 확인)
- **학습된 A의 고유기저 순도 0.98~1.000** (Burgers, KdV, Fisher, 작은 데이터·잘린 데이터 포함) → **사전지식 없이 모델이 배운 선형부만으로 푸리에 모드 복원**. 원리: 균일 매질이면 A가 평행이동과 교환 → 고유벡터 = 푸리에
- KS는 0.96~0.99: ν=0.05에서 k=2와 k=4의 선형 고윳값이 같음(둘 다 3.2) → 고유벡터 섞임 = **이 방법의 한계가 정확히 드러나는 지점** (논문에 쓸 것)
- full: POD 텐서 오차 ≈ 같은 데이터 푸리에 기본 회귀 (대칭 조건 없으니 예상대로)
- cubic은 quick에서 발산 (데이터 < 특징 수) → 기본 크기에서만

**스모크 결과 (결론 아님)**
- **2D NS**: closed 정확(1e-10~1e-14) → 진리 텐서 공식·솔버 일관. full은 closure가 매우 큼(K=4 46~51%, K=6 13%, K=8 4%). 전체 텐서 오차는 크지만 **큰 스케일 삼체(|k|≤4)는 0.15%**, 오차는 차단선 근처 집중 → **스케일별 오차 지표** 추가. dense(대칭 없음, K=2): full에서 텐서 오차 42·롤아웃 발산 vs mask 0.69·롤아웃 1.8%. K=6 dense는 출력당 특징 14,365개 → **2D에서는 구조 없이 규모를 못 키움**
- **2D Darcy**: closed 정확(1e-13). full에서 **최소제곱 학습 연산자가 단순 절단보다 1.2~1.6배 나쁨** (입력 거칠게·데이터 늘려도). 원인 추정: LS는 "방정식 잔차"를 줄일 뿐 "해 오차"를 안 줄임 + 특징에 절단 오차(errors-in-variables). → **해 오차를 직접 줄이는 경사하강법 다듬기** 추가 (CPU 300번에 3.89%→3.43%, 단순 절단 2.41%) — 서버 3000번으로 확인. **ML(경사하강법)이 자연스럽게 필요해지는 지점**
  - 주의: 강제항 f를 고정하거나 대역이 K보다 좁으면 f_k=0인 모드에서 L=0이 답 → 식별 불가. f도 입력으로, 대역 ≥ K
- **Allen–Cahn**: mask+cubic closed 정확(1e-11), full C 오차 0.17~0.44. **mask 없으면 closed에서도 실패** — SVD로도 학습 데이터 1e-12로 맞추지만 C 오차 122배, 조건수 1e13 → **진짜 식별 불가능** (해가 ±1로 포화되면 u³≈u). "대칭 없이는 3차 물리를 데이터로 못 정한다"
- **M6c 트렁크**: POD/푸리에 공간 재발견(span 1e-5), closed T 2e-5, 고유기저 순도 1.000. 주기 1D에선 POD와 같음(예상). 이득은 벽 있는 영역에서 봐야 함

#### AB: 통제 실험 — DeepONet에서 branch만 3차 텐서로 (2026-10-10) — `AB_ablation/`
**설계**: 세 모델이 같은 진화 연산자 u → u_t를 배운다. 같은 POD trunk, 데이터, 필드 손실, Adam, step, seed를 쓰고 **branch만 바꾼다**: `deeponet`(MLP(센서값)), `coeffmlp`(MLP(c)), `tensor`(A c + T(c,c)). 모든 모델의 생성자에서 0 근처의 Taylor 계수로 "암묵적 텐서"를 뽑아 Galerkin 참값과 비교한다.

**사전 확인 (Burgers ν=0.2, closed, 200개 궤적, 6000 step, seed 0, 결론 아님)**

| 모델 | dz | T 오차 | 선택 규칙 질량 | 파라미터 |
|---|---|---|---|---|
| deeponet | 0.186 | 2.54 | 0.18 | 43,537 |
| coeffmlp | 0.268 | 4.47 | 0.15 | 37,521 |
| tensor (Adam lr 1e-3) | 1.8e-4 | 1.8e-3 | 0.997 | 2,890 |
| tensor (Adam lr 1e-2) | 3e-15 | 5e-13 | 1.000 | 2,890 |

- MLP branch는 예측이 그럭저럭 맞아도(오차 19~27%) 속에 든 텐서는 엉망이다. 선택 규칙 위 질량이 15~18%로, 무작위 수준이다 → ⑤ "기존 모델에선 물리가 안 보인다"를 지지한다.
- 같은 Adam으로 학습한 텐서 branch는 파라미터가 1/15인데도 정확하고, 참 텐서를 그대로 보여준다.
- 주의: quick(40개 궤적)에서는 Adam 텐서가 실패했다(dz 1.7). 잘 들뜨지 않은 모드의 성분을 데이터가 못 정하기 때문이다. 그래서 데이터 양 실험(AB-3)을 넣었다.
- MLP의 lr 1e-2 결과가 아직 없다 → 서버에서 lr {1e-3, 3e-3, 1e-2}를 모든 모델에 똑같이 스윕한다.

#### P1 본 실험 결과 (2026-10-10, 서버) — 원본: `P1_param/P1_agent_report_raw.md`
**closed (기저 안 데이터): TCO가 정답으로 수렴**

| 학습 입력 수 | TCO T 오차 | DeepONet(얼린 trunk) T 오차 | OpInf |
|---|---|---|---|
| 128 | 13% | 36% | 정확 |
| 512 | 1.8% | 9.8% | 정확 |
| 2048 | **0.36%** | 6.3% (멈춤) | 정확 |

- TCO는 입력을 4배 늘릴 때마다 오차가 약 5~7배 줄었다. T_var(입력 따라 T가 변하는 정도)도 9.5% → 1.6% → 0.35%로 줄었다 → "T는 입력과 무관"을 스스로 학습했다.
- DeepONet은 예측 오차가 2.3%까지 내려가는데 T 오차는 6%에서 멈췄다 → "예측은 맞는데 속의 표는 틀림".
- 기저(학습/POD/Fourier)와 lr을 바꿔도 결론이 같았다. 학습 trunk 위의 OpInf T 오차 6e-4는 span 잔차 1e-4 수준이다 → 채점이 일관적이다.

**full (고해상도 데이터): TCO가 짐**
- u_t 오차(span 안): TCO 19.9%, DeepONet 10.3%, OpInf 10.6%, Galerkin 13.4%
- rollout: TCO 15%, 나머지 2~3%
- 입력 2048개에서도 TCO 18%, DeepONet 7%
- 원인 후보 두 가지:
  1. **정보 차이**: DeepONet은 격자 위의 u 전체를 보므로 기저 밖의 작은 파도까지 보지만, TCO는 투영 계수 c만 본다.
  2. **학습 문제**: 같은 c만 쓰는 OpInf가 10.6%이므로, TCO는 같은 정보로도 못 맞추고 있다(branch 출력 2,907개가 closure 잡음에 과적합하는 것으로 추정).
- deeponet_joint는 아직 실행되지 않았다.

**E1 구현 메모:** 푸리에 계수 $c_k(t)$ 를 데이터에서 FFT로 뽑고, $\dot c$ 는 유한차분 → $\dot c \approx Ac + T(c,c)$ 를 least-squares/GD로 피팅. 해석적 $T_{kij} = -\langle\varphi_i\partial_x\varphi_j,\varphi_k\rangle$ 와 비교 (히트맵 그림 = 논문 핵심 그림 후보)
