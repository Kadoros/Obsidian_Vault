# TCO 아이디어 정리

## 1. 출발 직관
> "기본 DeepONet은 대각 메트릭이잖아. 그걸 3차원 텐서로 계수를 주면 각 고유함수들이 다른 쪽에 어떻게 영향을 주는지 설명할 수 있지 않을까?"

$$u(y) = \sum_k b_k(a)\,t_k(y) = b^\top I\, t$$
branch $k$번은 trunk $k$번하고만 짝 → **대각(단위행렬) 결합**.

### 행렬로는 안 되는 이유 (중요)
$b^\top W t$ 는 $b' = W^\top b$ 로 흡수됨 → 같은 $p$차원 공간, **아무것도 안 늘어남**. 2차(행렬)로는 부족하고 **3차 텐서**여야 새로운 게 생김.

## 2. 텐서의 의미 ①: 모드 간 상호작용 (비선형)
$$\frac{dc_k}{dt} = \sum_j A_{kj}c_j + \sum_{i,j} T_{kij}\,c_ic_j, \qquad T_{kij} = -\langle\varphi_i\,\partial_x\varphi_j,\ \varphi_k\rangle \ (\text{Burgers})$$
- $T_{kij}$ = "$i$번·$j$번 모드가 만나 $k$번 모드에 주는 영향" = **삼체 상호작용** → [[Triadic Interaction Tensor]]
- **선택 규칙**: 푸리에면 $i+j=k$ 일 때만 ≠ 0 → 희소 패턴 자체가 물리
- **에너지 흐름 지도**: 캐스케이드 경로를 직접 읽음
- **에너지 보존 = 텐서 대칭**: $\sum T_{kij}c_kc_ic_j = 0$ ⇐ $T_{kij} = -T_{jik}$ (지난번 $B(c)$ 반대칭과 동일)

## 3. 텐서의 의미 ②: 입력이 모드를 섞는 방식 (가변계수)
> ⚠️ 정독 결과: **Tensor parametric H-OpInf (2025)가 같은 형태** $T_{ijk}=(\nabla\phi_i,\nabla\phi_j)_{\Omega_k}$ 를 이미 씀. 단 조각별 상수 3~4개 파라미터 + 선형 동역학만. 이 갈래 단독은 새로움 ✗ → 함수 입력·이차항과 결합할 때만 의미
Darcy $-\nabla\cdot(a\nabla u)=f$, $a = \sum_i a_i\psi_i$:
$$A(a)_{kj} = \sum_i a_i\,\underbrace{\langle\psi_i\nabla\varphi_j,\nabla\varphi_k\rangle}_{T_{kji}}, \qquad c = A(a)^{-1}f$$
- "입력의 $i$번 모드가 해의 $j$번 모드를 $k$번으로 얼마나 섞나"
- $a\mapsto u$ 는 **비선형**인데, 비선형성이 **(텐서 × 입력: 선형) + 역행렬**이라는 투명한 구조에서 나옴
- DeepONet은 이걸 branch 안에 숨김 → TCO는 **비선형성의 출처를 꺼내 보여줌**
- Darcy = 표준 벤치마크 → 비교 쉬움

## 4. 구조로 보장할 것 ([[Dissipative Operator]])
에너지 $E = c^\top c$ (정규직교), $\dot E = c^\top(A+A^\top)c + 2\sum T_{kij}c_kc_ic_j$
- 선형부: $A = S - D$ ($S$ 반대칭, $D\succeq0$) → **고윳값 음수만으로는 부족** (non-normal 과도 성장 반례: $\begin{pmatrix}-1&10\\0&-1\end{pmatrix}$, $t\approx1$ 에서 $\|e^{tA}\|\approx3.7$)
- 비선형부: $T$ 반대칭 → 에너지를 옮기기만 함
- closure (잘린 모드): $-D_{\text{closure}}(c)\,c$ → 에너지를 빼가는 방향만 허용
- 비정규직교 기저: $MA + A^\top M \preceq 0$, $A = M^{-1}(S-D)$
- 시간 적분: implicit midpoint (이차 보존량 정확 보존). explicit Euler는 반대칭계에서 에너지 증가

## 5. 솔직한 한계
- **정적 DeepONet에 붙이면 n-width 벽 그대로**: 출력은 여전히 $t_k$ 의 선형결합 → 텐서가 주는 건 **해석 가능성 + 귀납 편향**이지 표현력 아님 → 텐서는 시간 ODE(§2)나 Galerkin 구조(§3) 안에 있어야 의미
- 파라미터 $p^3$ → CP 저랭크 분해, 선택 규칙 희소성 필요
- 보장 = 안정성·보존이지 **정확도 아님**
- 어떤 구조를 박을지 미리 알아야 함
- 이동하는 해(충격파 이동)는 여전히 어려움 → [[Kolmogorov n-width]]

## 6. 포지셔닝 (정독 후 갱신)
4가지 성질 ① 명시적 교차모드 3차 텐서 ② 입력=함수, 텐서가 입력 의존 ③ 이차항 대칭 보장 ④ 텐서 해석·복원 검증 — **각 쌍은 선행 있음, 넷 동시는 아직 못 찾음** → 표: [[TCO 관련 연구 지도]] "4가지 성질 비교"

예상 리뷰 공격: "TCO = parametric quadratic OpInf + 신경망 인코더 아니냐?" → 방어 포인트: 함수 입력(고차원), 이차항 대칭 보장, 해석 복원 지표. **통합만으론 약하니 ④ 해석 검증(E1)이 기둥**

## 해석 가능성의 조건 (왜 선행연구는 텐서를 못 읽나)
1. **학습 잠재 좌표는 식별 불가능** (NIGO, NODE-ONet): $\psi'=Q\psi$ 로 돌려도 출력 동일, $A' = QAQ^{-1}$ (닮음변환) → 성분 의미 없음. 좌표 불변량(고윳값)만 해석 가능
2. **텐서가 없음** (NODE-ONet): 비선형이 $\sigma$ 안의 원소별 곱
3. **텐서가 있어도 물리 텐서와 어긋남** (OpInf): 절단 오차 흡수 ("OpInf는 intrusive Galerkin ROM 복원 못 함"), POD 모드는 섞인 모드
4. 목표가 정확도·안정성이라 정답 텐서 비교 실험이 없음

→ **TCO 설계 요구사항**
- [ ] 물리적으로 의미 있는 **고정 기저** (푸리에/고유함수) — 학습 잠재 좌표 ✗
- [ ] **표준형**: $T_{kij}$ 를 $(i,j)$ 대칭화 ($c_ic_j=c_jc_i$ 라 비대칭 부분 식별 불가)
- [ ] **closure 분리** ($-D_{\text{cl}}c$) — 텐서가 절단 효과를 흡수하지 않게
- [ ] **식별 가능한 데이터** (모든 모드 쌍 자극) 또는 선택 규칙 희소성 정규화
- [ ] **정답 텐서 비교 지표** (E1)

대가: 고정 기저 → 이동하는 해에서 n-width 벽. **표현력 ↔ 해석 가능성** 트레이드오프에서 해석 쪽 선택. 절충안: 고정 물리 기저 + 작은 학습 잔차 디코더 (잔차가 해석을 얼마나 흐리는지 따로 검증)

## 7. 기존 NO도 비선형은 잡는다 — 차이는 "숨김 vs 명시"
- **DeepONet**: 마지막 결합은 대각이지만 branch net이 비선형 → 모드 상호작용이 branch 안에 **섞여 있음**
- **FNO**: 스펙트럴 층은 모드별 $R_k$ (대각), 그런데 물리 공간 점별 활성화 $\sigma$ 가 **모든 모드를 섞음** (곱 ↔ 합성곱). $\sigma(u)=u^2$ 였다면 정확히 선택 규칙 $i+j=k$ 의 삼체 텐서
- 즉 **"표현 가능 여부"가 아니라 "명시적이냐 숨어 있냐"**의 차이

| | 모드 간 상호작용 |
|---|---|
| DeepONet, FNO | 비선형 활성화 안에 **암묵적**. 읽을 수 없고 구조를 걸 수 없음 |
| TCO | **입력 의존 3차 텐서로 명시**. 읽을 수 있고 대칭으로 보장 가능 |

> 예상 리뷰: "FNO도 비선형 잡는데?" → "잡는다. 그런데 **어떻게** 잡는지 안 보이고, 그래서 보장도 못 건다."

## 8. 일반성의 범위 (과장 금지)
- **이차 비선형 동역학** (Burgers, NS, KdV 시간 발전): 계수 공간에서 정확히 "행렬 + 3차 텐서" → **근사 아님**
- **고차 비선형** ($u^3$, Allen–Cahn 등): 4차 텐서 필요. 일반적으로 텐서 급수 $T_1c + T_2(c,c) + T_3(c,c,c)+\cdots$ (**Volterra 급수**) → 3차 절단은 근사
- **텐서 차수 = 비선형항 차수 + 1**
- **정적 해 연산자** (Darcy $a\mapsto u$): 다항식 아님 (역행렬) → "텐서 × 입력 + 역행렬" 구조가 정확 (§3)
- 정직한 주장: "이차 비선형 PDE 계열에서는 정확, 그 외엔 텐서 급수로 체계적 확장 가능". 중요한 유체 PDE 대부분이 이차라 범위가 좁지 않음

## 9. 어디서 텐서를 얻나 / OpInf와의 차이
| 상황 | 텐서 |
|---|---|
| PDE 완전히 앎 | 공식으로 계산 (스펙트럴 Galerkin, 학습 불필요) |
| 일부만 앎 | 아는 부분은 공식, **모르는 부분만 학습** (closure, 미지 항) |
| 전혀 모름 | 데이터에서 전체 학습 (Operator Inference, 방정식 발견 계열) |

- OpInf: 기본은 **PDE 하나**. parametric OpInf도 입력이 **스칼라 파라미터 몇 개** (Re 등) 수준 (← 정독으로 범위 확인 필요)
- **TCO: 입력이 함수 전체 $a(x)$** (초기조건, 계수장, 외력) → $T(a)$. operator learning과 OpInf 사이의 빈자리

## 10. KAN과의 비교
같은 철학(블랙박스 비선형성을 해석 가능하게), **다른 해석 축** → [[KAN]]

| | KAN | TCO |
|---|---|---|
| 비선형성 형태 | 단변수 **임의 함수** $\phi(x_p)$ (스플라인) + **덧셈** | 모드 계수끼리의 **곱** $c_ic_j$ |
| 해석 대상 | "**어떤 함수**가 걸리나" → 기호 공식 | "**누가 누구와** 얼마나 상호작용하나" → 상호작용 지도 |
| 물리적 의미 | 공식 발견 | 모드 간 에너지 흐름 (캐스케이드) |
| 보장 | 자연스러운 메커니즘 없음 | 텐서 대칭 → 에너지 보존/소산 |

- KAN은 "단변수 + 덧셈"이라 **곱셈형 상호작용에 서툼** ($xy = \frac{(x+y)^2-(x-y)^2}{4}$ 처럼 우회). PDE 비선형($uu_x$)은 본질적으로 곱 → TCO는 KAN이 약한 지점을 1급으로 다룸
- 계열상 KAN보다 **다항식 네트워크 / 텐서 회귀 / Volterra 네트워크**에 가까움
- **결합 가능성**: 이차 부분은 텐서로, 이차로 안 잡히는 나머지(반응항 $u^3$, 지수항)는 KAN식 단변수 함수로 → 해석 가능성 끝까지 유지 (아이디어 단계, KANO 등 서치 필요)

## 11. 피치
> 함수 → 함수 연산자를 데이터로 배울 때, 기존 neural operator는 고유함수(모드) 간 상호작용을 비선형 활성화 안에 **숨겨서** 표현한다. 우리는 그 상호작용을 **입력 함수에 의존하는 3차 텐서로 명시**한다. 이차 비선형 PDE에서는 이게 정확한 형태이고, 덕분에 상호작용을 **읽을 수 있고**, 텐서 대칭으로 에너지 법칙을 **모든 입력에서 보장**할 수 있다. OpInf는 같은 텐서를 쓰지만 PDE 하나나 스칼라 파라미터에 묶여 있고, 우리는 입력이 함수다.

주장 수위: "성능이 더 좋다" ✗ → **"비슷한 정확도에서 해석 가능 + 안정성 보장 + 분포 밖에서 더 강함(가설, 실험으로 입증)"** ✓

## 12. 어떤 PDE에 적용되나
조건: **비선형항이 다항식(곱셈)** 이고, 경계에 맞는 기저가 있을 것. 텐서 차수 = 비선형 차수 + 1.

| PDE | 비선형 | 필요한 텐서 | 비고 |
|---|---|---|---|
| Burgers, KdV | $uu_x$ (이차) | 3차 | E1 |
| Kuramoto–Sivashinsky | $uu_x$ + 4차 미분 선형 | 3차 | 카오스, 장시간 테스트 |
| Navier–Stokes (2D/3D) | $u\cdot\nabla u$ (이차) | 3차 | 압력은 투영으로 텐서에 흡수 |
| 얕은 물, MHD | 이차 | 3차 | 변수 여러 개 → 텐서 블록 |
| Fisher–KPP | $u^2$ | 3차 | 반응-확산 |
| Allen–Cahn, 비선형 슈뢰딩거 | $u^3$, $\lvert u\rvert^2u$ | 4차 | 차수만 올리면 됨 |
| 가변계수 (확산 $\nu(x)$, Darcy $a(x)$) | 입력×상태 | 3차 ($L_{kji}$) | 함수 입력이 텐서 인덱스 (E4) |
| sine-Gordon $\sin u$, 연소 $e^{-E/u}$ | 비다항식 | ✗ 직접 불가 | 급수 근사 또는 KAN식 단변수 함수와 결합 |

기저/경계: 주기 → 푸리에 (선택 규칙 $p+q=k$). 비주기 → 체비쇼프·르장드르·라플라시안 고유함수 (선택 규칙이 바뀜, 예: 체비쇼프 $T_mT_n = \frac12(T_{m+n}+T_{|m-n|})$ → $k = m+n$ 또는 $|m-n|$). 복잡 영역은 기저부터 구해야 해서 어려움.

## 13. 실험으로 확인된 구조 (E1 v2, 2026-10-09)
잘린 데이터에서 텐서 오염은 두 종류 → 각각의 처방:
1. **가짜 성분** (선택 규칙 밖) → 대칭 조건 (균일 매질 = 약한 사전지식)
2. **진짜 closure** (규칙 위 칸에 섞임) → 대칭이 걸린 cubic closure 채널
3. **에너지 보존** → 정확한 제약, 정확도 손실 작음 (보장용)
→ 셋 다 넣은 구조가 해석성·예측 둘 다 기준선보다 좋음. 남은 불일치(선형 대각)는 eddy viscosity로 해석 가능한지 검증 중
