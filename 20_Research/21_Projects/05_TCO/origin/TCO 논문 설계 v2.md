# TCO 논문 설계 v2 (2026-10-10)

## 주장
> u → u_t를 배우는 신경 연산자에서 결합을 3차 텐서로 두면, 학습된 텐서가 **같은 기저 위의 Galerkin 상호작용 텐서**와 일치한다. 기저 안의 데이터에서는 그대로 일치하고, 해상도 높은 데이터에서는 차이가 closure로 읽힌다. DeepONet은 같은 데이터에서 이걸 주지 않는다.

조건은 주장 안에 넣는다. (1) 배우는 대상은 생성자 u → u_t다. (2) 비선형은 2차다(3차는 4차 텐서). (3) 정답은 모델의 기저 위에서 계산하므로 gauge와 무관하다.

## 비평에서 받아들인 것
- **유한 시간 연산자 u(0) → u(T)는 2차가 아니다** → u_t를 배운다.
- **gauge**: 정답을 학습된 기저 위에서 계산해 채점에서 gauge를 없앤다. gauge 고정(A의 고유기저)은 그림용이다.
- **OpInf / SINDy / Galerkin ROM이 같은 계열이다** → 차별점을 "기존 모델엔 표가 없다"에서 "end-to-end 신경 연산자 안에서, 입력 함수에 따라 바뀌는 해석 가능한 텐서"로 옮긴다.
- **MIONet**: 여러 branch를 성분끼리 곱한다(CP 구조). 모드끼리 섞이는 결합 텐서는 아니다 → 관련 연구 지도에 추가할 것.

## 채점 설계에서 고친 다섯 가지
1. **span 오차**는 POD와의 각도가 아니라, 시험 u와 u_t를 학습 span에 투영했을 때 남는 잔차로 잰다. POD와 Fourier는 같은 r의 비교 대상이다.
2. **"T가 입력과 무관해야 한다"는 closed 데이터에서만 성립한다.** full에서는 closure가 ν에 의존할 수 있다 → ν로 설명되는 비율(R²)을 보고한다.
3. **식별성**: 입력마다 [1, c]가 r+1개 이상의 아핀 독립 상태를 가져야 한다. 강제항 Burgers는 정상해로 수렴하므로 초반 구간에서 샘플링하고, 초기조건을 다양하게 한다. cond([1,c])를 기록한다. T는 입력들 사이에서 공유되는 정보로 정해진다.
4. **같은 이산 연산자**: closed 데이터 생성과 정답 계산에 같은 스펙트럼 미분을 쓴다. 채점용 모델은 u_t 손실로만 학습한다. 직교정규 trunk에서는 이 손실이 Galerkin 투영과 같다.
5. **실험 1은 차별점이 아니라 검증이다.** b는 f에, A는 ν에 아핀이라 parametric OpInf로 그대로 풀린다 → OpInf 기준선을 넣고 "동등하다"를 보이는 것까지가 목표다. 차별점은 실험 3(입력에 비선형으로 의존, 예: 영역 모양)에서 나온다.

## 실험 구성
| 실험 | 역할 | 내용 |
|---|---|---|
| 1 | 검증 | Burgers, 입력 (ν(x), f(x)), 학습 trunk, closed와 full, TCO vs DeepONet vs OpInf vs Galerkin |
| 2 | 현실 조건 | 노이즈, 스냅샷 차분으로 구한 u_t, KS(카오스), 2D NS |
| 3 | 차별점 | 텐서가 입력에 비선형으로 의존하는 문제 (영역 모양 등). OpInf의 아핀 가정이 깨지는 곳 |

## 첫 그림 후보
같은 입력 세 개(ν 낮음, 중간, 높음)에 대한 T 슬라이스. Galerkin과 TCO는 세 칸이 같고 선택 규칙이 보인다. DeepONet은 흐리고 입력마다 다르다. → `experiments/P1_param/`

## 사전 확인 (2026-10-10, 결론 아님)
Fourier 기저, closed, 입력 512개, 3000 step 기준이다.
- TCO: T 오차 6.9%, T_var 7.2%
- DeepONet: T 오차 35%, T_var 24%
- OpInf: 정확

입력이 32개면 TCO도 외워버린다(T 오차 42%) → 입력 수 곡선이 핵심이다.
